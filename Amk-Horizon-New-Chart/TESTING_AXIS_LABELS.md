# Инструкция по тестированию выравнивания подписей левой оси Y

## Цель тестирования
Проверить, что подписи левой оси Y корректно отображаются после исправления выравнивания.

## Что было исправлено
- Подписи левой оси Y теперь используют всё доступное пространство (80 пикселей)
- Текст выравнивается по правому краю и заканчивается в 5 пикселях от оси Y
- Длинные значения (например, "-180000" для фаз в миллиградусах) не обрезаются

## Шаги для тестирования

### 1. Перекомпилировать проект
```
1. Откройте проект в Visual Studio
2. Выберите Build → Rebuild Solution
3. Дождитесь завершения компиляции
4. Убедитесь, что нет ошибок компиляции
```

### 2. Запустить приложение
```
1. Запустите скомпилированное приложение
2. Загрузите данные (если требуется)
```

### 3. Проверить обычные графики
Проверьте графики с одной осью Y:
- **AMPLITUDE_RX1** (значения в мВ, например: 0.5, 1.2, 2.8)
- **PHASE_RX1** (значения в мдег, например: -180000, -90000, 0, 90000, 180000)

**Что проверять:**
- ✅ Все подписи левой оси Y полностью видны
- ✅ Текст не обрезается слева
- ✅ Текст не выходит за пределы оси Y справа
- ✅ Подписи выровнены по правому краю (прижаты к оси)
- ✅ Есть небольшой отступ (5 пикселей) между текстом и осью

### 4. Проверить графики с двойными осями
Проверьте графики с двумя осями Y:
- **Левая ось**: AMPLITUDE_RX1 (мВ)
- **Правая ось**: PHASE_RX1 (мдег)

**Что проверять:**
- ✅ Подписи левой оси Y корректно выровнены
- ✅ Подписи правой оси Y корректно выровнены
- ✅ Нет наложения подписей друг на друга
- ✅ Все значения читаемы

### 5. Проверить разные масштабы
Попробуйте разные диапазоны значений:
- **Маленькие значения**: 0.1, 0.2, 0.3 (мВ)
- **Средние значения**: 10, 20, 30 (мВ)
- **Большие значения**: 1000, 2000, 3000 (мВ)
- **Очень большие значения**: -180000, -90000, 0, 90000, 180000 (мдег)

**Что проверять:**
- ✅ Короткие значения не "прилипают" к левой границе chart
- ✅ Длинные значения не обрезаются
- ✅ Выравнивание одинаково хорошо для всех диапазонов

### 6. Проверить zoom
Используйте функцию zoom для изменения диапазона:
1. Выделите область на графике
2. Проверьте, что подписи осей обновились
3. Убедитесь, что выравнивание осталось корректным

## Возможные проблемы

### Проблема 1: Изменения не применились
**Симптомы**: Подписи всё ещё обрезаются или располагаются неправильно

**Решение**:
1. Убедитесь, что проект был перекомпилирован (Rebuild Solution)
2. Проверьте, что запущена новая версия приложения (закройте старую)
3. Очистите кэш сборки: Build → Clean Solution, затем Build → Rebuild Solution

### Проблема 2: Подписи слишком далеко от оси
**Симптомы**: Между подписями и осью Y слишком большой отступ

**Решение**: Это нормально для коротких значений (например, "0", "1", "2"). Они используют меньше пространства, но выравнивание всё равно корректное.

### Проблема 3: Подписи накладываются друг на друга
**Симптомы**: Подписи разных значений перекрываются

**Решение**: Это не связано с выравниванием. Проверьте логику расчёта шага сетки (`CalculateNiceStep`).
