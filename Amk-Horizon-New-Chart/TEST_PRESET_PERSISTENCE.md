# 🧪 Тестовые сценарии: Сохранение пресетов

## 📋 Цель тестирования

Проверить, что выбранный пресет и его кривые корректно сохраняются и восстанавливаются при повторном открытии Device Schematic.

---

## ✅ Тест 1: Сохранение пресета "Ampl Ratios"

### Шаги:
1. Запустить приложение
2. Открыть Device Schematic (Chart 1)
3. Нажать кнопку "Ampl Ratios"
4. Проверить: отображается 4 чекбокса с кривыми отношений амплитуд
5. Нажать "Apply"
6. Закрыть Device Schematic
7. **Повторно открыть Device Schematic (Chart 1)**

### Ожидаемый результат:
- ✅ Отображается ровно 4 чекбокса
- ✅ Все 4 кривые - отношения амплитуд (T1-T4 Amplitude Ratio)
- ✅ Единицы измерения: V/V
- ✅ Все чекбоксы отмечены
- ✅ Выбраны элементы R1 и R2 на схеме
- ✅ Не отображаются кривые разностей фаз

### Проверка фильтра:
- Внутренний фильтр: `DataTypeFilter::RATIO_ONLY`
- Метод `DetermineDataFilterFromCurves()` должен вернуть `RATIO_ONLY`

## 🔍 Проверка внутреннего состояния

### Метод DetermineDataFilterFromCurves()

Проверить корректность определения фильтра:

| Кривые в конфигурации | Ожидаемый фильтр |
|----------------------|------------------|
| Только T1-T4 Amplitude Ratio | RATIO_ONLY |
| Только T1-T4 Phase Difference | DIFFERENCE_ONLY |
| Только T1-T4 Amplitude R1 | AMPLITUDE_ONLY |
| Только T1-T4 Phase R1 | PHASE_ONLY |
| T1-T4 Amplitude R1 + T1-T4 Phase R1 | ALL |
| T1-T4 Amplitude Ratio + T1-T4 Phase Difference | ALL |

## 🐛 Известные ограничения

1. **Перезапуск приложения**: Конфигурация может не сохраняться между сеансами (зависит от реализации)
2. **Смешанные типы**: Если пользователь вручную создал конфигурацию со смешанными типами, фильтр будет ALL
3. **Обратная совместимость**: Старые конфигурации без фильтра будут работать с фильтром ALL
