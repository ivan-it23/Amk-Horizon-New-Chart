# 📋 Краткая сводка изменений v2.12.0

## 🐛 Исправленные ошибки

### Вертикальный скроллинг не обновлял график
**Проблема:** При движении вертикального scrollbar значения minY/maxY обновлялись, но график не перерисовывался.

**Причина:** В `DrawChartWithCurves` параметры Y zoom использовались для фильтрации данных, а не только для отображения.

**Решение:** Изменена логика - теперь Y zoom используется только для определения диапазона отображения, данные не фильтруются по Y.

**Результат:** ✅ Вертикальный скроллинг работает корректно, график обновляется при движении scrollbar.

## Что изменилось?

### 1. Zoom по обеим осям (X и Y)
**Было:** Выделяю область → приближается только по X  
**Стало:** Выделяю область → приближается по X и Y одновременно

**Как работает:**
- Выделите область мышью (левая кнопка + перетаскивание)
- График автоматически увеличит выбранный участок по обеим осям
- Минимальный диапазон X: 10 точек
- Минимальный диапазон Y: 10 единиц

### 2. Вертикальный scrollbar
**Новое:** Добавлен вертикальный scrollbar для прокрутки по оси Y

**Расположение:**
- Справа от графика
- Появляется только при активном zoom
- Для двойных осей: применяется к обеим осям одновременно

**Управление:**
- Перетаскивание ползунка для плавной прокрутки
- Клик по стрелкам для точной настройки
- Page Up/Page Down для быстрой прокрутки

### 3. Ограничение минимального диапазона Y
**Новое правило:** Нельзя приближать график больше, чем до диапазона в 10 единиц по оси Y

**Примеры:**
- ✅ Диапазон Y: 100 - 150 (диапазон = 50)
- ✅ Диапазон Y: 0 - 10 (диапазон = 10)
- ❌ Диапазон Y: 0 - 5 (диапазон = 5, слишком мал)

### 4. Двойные оси
**Поведение:** Zoom и scroll применяются к обеим осям Y одновременно

**Особенности:**
- Левая ось (фазы) и правая ось (амплитуды) масштабируются пропорционально
- Один вертикальный scrollbar управляет обеими осями
- Сохраняется соотношение между осями

### 5. Сброс zoom
**Обновлено:** Правая кнопка мыши сбрасывает zoom по X и Y одновременно

**Результат:**
- Возврат к полному диапазону данных
- Scrollbar автоматически скрываются
- График отображает все данные

## Технические детали

### Новые элементы управления
- `hChart1VScrollBar` - вертикальный scrollbar для Chart 1
- `hChart2VScrollBar` - вертикальный scrollbar для Chart 2

### Новые методы
- `SetVScrollBarRange()` - настройка диапазона вертикального scrollbar
- `GetVScrollBar()` - получение handle вертикального scrollbar

### Новые константы
- `IDC_CHART1_VSCROLL` (1041) - ID вертикального scrollbar для Chart 1
- `IDC_CHART2_VSCROLL` (1042) - ID вертикального scrollbar для Chart 2
- `MIN_Y_RANGE` (10.0) - минимальный диапазон по оси Y

### Обновлённые методы
- `HandleMouseUp()` - проверка минимального диапазона Y
- `HandleScrollEvent()` - обработка вертикального scrollbar
- `UpdateScrollBars()` - настройка вертикального scrollbar
- `DrawChartWithCurves()` - передача Y параметров в методы отрисовки
