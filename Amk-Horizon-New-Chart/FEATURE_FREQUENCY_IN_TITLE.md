# 📊 Отображение частоты в заголовке графика - Версия 2.6.0

## 📋 Обзор

Данный документ описывает улучшение отображения заголовков графиков с добавлением информации о частоте вместо общей подписи "(Custom Curves)".

## 🎯 Назначение

### Проблема
При отображении графиков с пользовательскими кривыми заголовок всегда содержал подпись "(Custom Curves)", которая:
- **Не несла полезной информации** - итак понятно, что отображаются пользовательские кривые
- **Занимала место** - вместо нее можно показать важную информацию
- **Не помогала в анализе** - не указывала на какой частоте отображаются данные

### Решение
Реализовано отображение частоты в заголовке графика:
- Заголовок теперь показывает частоту: **"Chart 1 (400 kHz)"** или **"Chart 2 (2000 kHz)"**
- Частота берется из конфигурации кривых, выбранной в Device Schematic
- Если данные не загружены, отображается просто **"Chart 1"** без скобок

## 🔧 Техническая реализация

### Изменения в методах

#### DrawChartWithCurves() - формирование заголовка

**Было:**
```cpp
// Формируем заголовок
std::wstring title = L"Chart " + std::to_wstring(chartNumber) + L" (Custom Curves)";
```

**Стало:**
```cpp
// Формируем заголовок с частотой
std::wstring title = L"Chart " + std::to_wstring(chartNumber);

// Добавляем частоту, если есть кривые
if (!config.curves.empty()) {
    FrequencyBand frequency = config.curves[0].frequency;
    title += (frequency == FrequencyBand::FREQ_400_KHZ) ? L" (400 kHz)" : L" (2000 kHz)";
}
```

### Логика определения частоты

1. **Получение конфигурации**: Частота берется из первой кривой в конфигурации `config.curves[0].frequency`
2. **Проверка наличия кривых**: Если `config.curves.empty()`, частота не добавляется
3. **Форматирование**: Частота отображается в скобках после номера графика

### Источник данных о частоте

Частота хранится в структуре `CurveDefinition`:
```cpp
struct CurveDefinition {
    // ... другие поля
    FrequencyBand frequency;    // Частотный диапазон (400 kHz или 2000 kHz)
};
```

Все кривые в одной конфигурации имеют одинаковую частоту, так как она выбирается в Device Schematic для всего графика.

## ✅ Преимущества

### 1. Информативность
- Сразу видно, на какой частоте отображаются данные
- Не нужно открывать Device Schematic для проверки частоты
- Легче сравнивать графики с разными частотами

### 2. Удобство анализа
- При работе с двумя графиками в Dual Mode легко различить частоты
- Быстрая идентификация частоты при экспорте скриншотов
- Улучшенная читаемость при документировании результатов

### 3. Чистота интерфейса
- Убрана избыточная подпись "(Custom Curves)"
- Заголовок содержит только полезную информацию
- Современный и лаконичный вид

### 4. Согласованность
- Частота в заголовке соответствует выбору в Device Schematic
- Автоматическое обновление при изменении конфигурации
- Единый источник информации о частоте

## 🧪 Тестирование

### Тестовые сценарии

#### Сценарий 1: График с частотой 400 kHz
```
Действие: 
1. Открыть Device Schematic для Chart 1
2. Выбрать частоту 400 kHz
3. Выбрать передатчики T1, T2
4. Нажать Apply

Ожидаемый результат:
- Заголовок графика: "Chart 1 (400 kHz)"
- Отображаются кривые для T1, T2 на частоте 400 kHz
```

#### Сценарий 2: График с частотой 2000 kHz
```
Действие:
1. Открыть Device Schematic для Chart 2
2. Выбрать частоту 2000 kHz
3. Выбрать приемники R1, R2
4. Нажать Apply

Ожидаемый результат:
- Заголовок графика: "Chart 2 (2000 kHz)"
- Отображаются кривые Ratios и Differences на частоте 2000 kHz
```

#### Сценарий 3: Смена частоты
```
Действие:
1. График настроен на 400 kHz
2. Открыть Device Schematic
3. Изменить частоту на 2000 kHz
4. Нажать Apply

Ожидаемый результат:
- Заголовок обновляется с "(400 kHz)" на "(2000 kHz)"
- Кривые пересчитываются для новой частоты
```

#### Сценарий 4: Dual Mode с разными частотами
```
Действие:
1. Включить Dual Mode
2. Chart 1: настроить на 400 kHz
3. Chart 2: настроить на 2000 kHz

Ожидаемый результат:
- Chart 1 показывает "(400 kHz)"
- Chart 2 показывает "(2000 kHz)"
- Легко различить графики по заголовкам
```

#### Сценарий 5: График без конфигурации
```
Действие:
1. Запустить приложение
2. Не открывать Device Schematic

Ожидаемый результат:
- Заголовок: "Chart 1" (без скобок)
- Отображается сообщение "Click 'Device Schematic' to configure"
```

## 🔗 Ссылки на код

### Файлы с изменениями
- `ChartManager.cpp` - метод `DrawChartWithCurves()` обновлен для формирования заголовка с частотой

### Связанные структуры
- `ChartConfiguration` - содержит список кривых с информацией о частоте
- `CurveDefinition` - содержит поле `frequency` типа `FrequencyBand`
- `FrequencyBand` - перечисление с вариантами `FREQ_400_KHZ` и `FREQ_2000_KHZ`

- `DrawChartLegacy()` - уже отображает "Chart N" без скобок (корректно)
- `BuildChartTitle()` - используется только в старой системе (не затронут)
