## 🧪 Методика тестирования

### Ручное тестирование
1. Запустите приложение
2. Загрузите тестовые данные
3. Для каждого сценария:
   - Откройте Device Schematic
   - Выберите элементы согласно сценарию
   - Установите частоту
   - Проверьте цвета в легенде графика
   - Сравните с ожидаемыми значениями

### Автоматическое тестирование
```cpp
// Пример unit-теста
void TestSmartColorAssignment_TwoReceivers() {
    CurveSelectionModule module;
    SchematicSelection selection;
    selection.receivers[0] = true;
    selection.receivers[1] = true;
    selection.frequency = FrequencyBand::FREQ_400_KHZ;
    
    auto curves = module.GetAvailableCurves(selection);
    
    // Проверяем левую ось (отношения амплитуд)
    ASSERT_EQ(curves[0].color, RGB(0, 128, 0));   // T1 - Зелёный
    ASSERT_EQ(curves[2].color, RGB(255, 255, 0)); // T2 - Жёлтый
    ASSERT_EQ(curves[4].color, RGB(255, 0, 0));   // T3 - Красный
    ASSERT_EQ(curves[6].color, RGB(0, 0, 255));   // T4 - Синий
    
    // Проверяем правую ось (разности фаз)
    ASSERT_EQ(curves[1].color, RGB(0, 128, 0));   // T1 - Зелёный
    ASSERT_EQ(curves[3].color, RGB(255, 255, 0)); // T2 - Жёлтый
    ASSERT_EQ(curves[5].color, RGB(255, 0, 0));   // T3 - Красный
    ASSERT_EQ(curves[7].color, RGB(0, 0, 255));   // T4 - Синий
}
```
