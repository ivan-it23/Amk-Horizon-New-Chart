## 🎯 Описание проблемы

В интерфейсе приложения отображались квадратики и непонятные символы вместо нормального текста из-за проблем с кодировкой русских строк.

### Проблемные места:
- **Сообщения об ошибках** в диалоговых окнах
- **Подсказки элементов** схемы прибора
- **Информационные сообщения** в ListView
- **Заголовки диалогов** и окон

## 🔧 Технические детали

### Изменённые файлы:
- **SchematicModule.cpp** - все русские строки заменены на английские

### Метод исправления:
1. **Поиск всех русских строк** с помощью regex `L".*[а-яё].*"`
2. **Замена на английские эквиваленты** с сохранением смысла
3. **Проверка компиляции** - нет ошибок и предупреждений

### Кодировка:
- **Исходная**: UTF-8 с русскими символами
- **Результат**: ASCII английские строки
- **Совместимость**: Полная совместимость с Windows API
