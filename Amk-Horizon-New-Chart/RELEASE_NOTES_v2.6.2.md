# 🚀 Релиз AMK-Horizon-New-Chart v2.6.2

**Дата релиза:** 6 ноября 2025

## 🎯 Основные изменения

### ✨ Улучшение порядка отображения кривых в Device Schematic

Реализовано изменение порядка отображения кривых для улучшения эргономики и удобства анализа данных.

#### Что это значит для пользователей?

- **Фазы всегда первыми** - более важные для анализа данные в начале списка
- **Логичная группировка** - все фазы вместе, все амплитуды вместе
- **Удобство работы** - не нужно прокручивать список для поиска нужного типа данных
- **Согласованность** - одинаковый порядок для всех случаев (R1, R2, R1+R2)

#### Новый порядок отображения

**Для одного приёмника (R1 или R2):**
```
☑ T1 Phase R1 (mdeg) [Right Axis]
☑ T2 Phase R1 (mdeg) [Right Axis]
☑ T3 Phase R1 (mdeg) [Right Axis]
☑ T4 Phase R1 (mdeg) [Right Axis]
☑ T1 Amplitude R1 (mV) [Left Axis]
☑ T2 Amplitude R1 (mV) [Left Axis]
☑ T3 Amplitude R1 (mV) [Left Axis]
☑ T4 Amplitude R1 (mV) [Left Axis]
```

**Для двух приёмников (R1+R2):**
```
☑ T1 Phase Difference (mdeg) [Right Axis]
☑ T2 Phase Difference (mdeg) [Right Axis]
☑ T3 Phase Difference (mdeg) [Right Axis]
☑ T4 Phase Difference (mdeg) [Right Axis]
☑ T1 Amplitude Ratio (V/V) [Left Axis]
☑ T2 Amplitude Ratio (V/V) [Left Axis]
☑ T3 Amplitude Ratio (V/V) [Left Axis]
☑ T4 Amplitude Ratio (V/V) [Left Axis]
```

#### Технические детали

- **Изменённые методы**: `AddSingleReceiverCurves()`, `AddTwoReceiversCurves()`
- **Логика**: Два отдельных цикла вместо одного - сначала все фазы, затем все амплитуды
- **Сортировка**: Отключена автоматическая сортировка для сохранения порядка добавления

## 📊 Примеры использования

### Сценарий 1: Анализ фаз приёмника R1
```
1. Открыть Device Schematic
2. Выбрать только R1
3. Результат: Все 4 фазы (T1-T4) в начале списка - легко выбрать нужные
```

### Сценарий 2: Сравнение разностей фаз
```
1. Открыть Device Schematic
2. Выбрать R1+R2
3. Результат: Все 4 разности фаз (T1-T4) в начале списка
```
