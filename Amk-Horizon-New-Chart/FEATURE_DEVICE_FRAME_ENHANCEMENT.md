# ✨ Улучшение: Визуальное выделение рамки прибора

## 📅 Дата изменения
21 октября 2025

---

## 🎯 Описание изменения

Улучшена видимость рамки, которая визуально выделяет основные элементы прибора (передатчики T1-T4 и приемники R1-R2) от молчащих передатчиков (Silent R1, Silent R2) в диалоге Device Schematic.

---

## 🔧 Технические изменения

### Файл: `SchematicModule.cpp`

#### Изменённые константы:

**Было:**
```cpp
const COLORREF FRAME_BORDER = RGB(180, 180, 180);      // Тёмно-серая граница
const int FRAME_BORDER_WIDTH = 1;                      // Толщина границы
```

**Стало:**
```cpp
const COLORREF FRAME_BORDER = RGB(100, 100, 100);      // Тёмно-серая граница (сделано темнее)
const int FRAME_BORDER_WIDTH = 2;                      // Толщина границы (увеличено с 1 до 2)
```

---

## 📊 Визуальные изменения

### До изменений:
- Рамка была слишком светлой (RGB 180, 180, 180)
- Толщина рамки 1 пиксель - практически незаметна
- Рамка сливалась с фоном диалога

### После изменений:
- Рамка стала темнее (RGB 100, 100, 100) - хорошо видна на светлом фоне
- Толщина рамки 2 пикселя - четко различима
- Рамка явно выделяет основные элементы прибора
