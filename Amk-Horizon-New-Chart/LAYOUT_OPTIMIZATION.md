# Оптимизация отступов в интерфейсе - Version 2.9.0

**Дата:** 18 ноября 2025

## 🎯 Цель оптимизации

Переход от фиксированных пикселей к **процентному распределению** пространства для графиков. Это обеспечивает:
- Адаптивность к разным разрешениям экрана
- Минимальные отступы между элементами (2px)
- Максимальное использование доступного пространства для графиков

## 🔄 Эволюция подхода

### Версия 2.8.0 - Фиксированные пиксели
Использовались константы в пикселях, что приводило к проблемам на разных разрешениях.

### Версия 2.9.0 - Процентное распределение
Графики получают процент от доступной высоты, адаптируясь к размеру окна.

## 📊 Проблемные зоны (до оптимизации)

### ЗОНА 1: Между главным меню и панелью управления Chart 1
- **Было:** `MENU_AND_PANEL1_HEIGHT = 60` пикселей, элементы на Y=28-30
- **Стало:** `MENU_AND_PANEL1_HEIGHT = 48` пикселей, элементы на Y=20
- **Выигрыш:** 12 пикселей

### ЗОНА 2: Между панелью управления Chart 2 и графиком Chart 2
- **Было:** `chart1Rect.bottom + PANEL_HEIGHT + (2 * MARGIN)` = +50 пикселей
- **Стало:** `chart1Rect.bottom + PANEL_HEIGHT + PANEL_SPACING` = +43 пикселей
- **Выигрыш:** 7 пикселей

### ЗОНА 3: Общая оптимизация расчёта высоты
- **Было:** `totalFixedHeight` включал `(4 * MARGIN)` = 20 пикселей
- **Стало:** `totalFixedHeight` включает `(2 * MARGIN)` = 10 пикселей
- **Выигрыш:** 10 пикселей

### Дополнительная оптимизация
- **Было:** `PANEL_SPACING = 5` пикселей
- **Стало:** `PANEL_SPACING = 3` пикселей
- **Выигрыш:** 2 пикселя

## 📈 Итоговый результат

**Общий выигрыш в высоте графиков:** ~31 пиксель

В режиме Dual Mode каждый график получает дополнительно ~15-16 пикселей высоты.

## 🚀 Версия 2.9.0 - Процентное распределение

### Новый подход

Вместо фиксированных пикселей используется **процентное распределение** высоты окна:

```cpp
// Фиксированные элементы (в пикселях)
MENU_HEIGHT = 20
PANEL_HEIGHT = 25
STATUSBAR_HEIGHT = 25
ELEMENT_SPACING = 2

// Процентное распределение для графиков
CHART1_HEIGHT_PERCENT = 0.47  // 47%
CHART2_HEIGHT_PERCENT = 0.47  // 47%
```

### Формула расчёта (Dual Mode)

```cpp
availableHeight = windowHeight - (фиксированные элементы)
chart1Height = availableHeight * 0.47
chart2Height = availableHeight * 0.47
```

### Преимущества

1. **Адаптивность** - графики масштабируются автоматически
2. **Универсальность** - работает на любых разрешениях
3. **Минимальные отступы** - всего 2px между элементами
4. **Пропорциональность** - соотношение размеров сохраняется
5. **Предсказуемость** - стабильное поведение

### Результат

- **Single Mode**: График занимает ~96% доступной высоты
- **Dual Mode**: Каждый график получает 48% (всего 96%)
- **Отступы**: Минимальные 2px между всеми элементами
- **Меню**: Уменьшено до 18px для минимального отступа сверху
