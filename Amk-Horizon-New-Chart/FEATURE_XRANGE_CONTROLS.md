# Новая функция: Элементы управления X Range

## Дата
24 октября 2025

## Описание
Добавлены элементы управления для точного задания диапазона отображения по оси X в панели инструментов главного окна. Пользователь может ввести начальную и конечную точки диапазона и применить их к графикам.

## Мотивация
- Необходимость точного задания диапазона отображения без использования мыши
- Возможность ввода конкретных числовых значений
- Удобный сброс к полному диапазону данных
- Дополнение к существующему zoom через выделение мышью

## Интерфейс

### Расположение
Элементы управления размещены в панели инструментов сверху, справа от кнопки "Device Schematic":

```
┌─────────────────────────────────────────────────────────────────┐
│ [Dual Mode ☑] [Device Schematic] │ X Range: [____] to [____] [Apply] [Reset] │
└─────────────────────────────────────────────────────────────────┘
```

### Элементы управления
1. **Метка "X Range:"** - подпись для группы элементов
2. **Поле "From"** - ввод начальной точки диапазона
3. **Метка "to"** - разделитель между полями
4. **Поле "To"** - ввод конечной точки диапазона
5. **Кнопка "Apply"** - применение введённого диапазона
6. **Кнопка "Reset"** - сброс к полному диапазону данных

## Функциональность

### Применение диапазона (Apply)
- Валидация входных данных:
  - "From" должно быть меньше "To"
  - Значения должны быть в пределах загруженных данных (0 до размер_данных-1)
- Применение диапазона к обоим графикам одновременно
- Автоматическое обновление скроллбаров
- Перерисовка графиков

### Сброс диапазона (Reset)
- Возврат к полному диапазону данных
- Отключение zoom режима
- Скрытие скроллбаров
- Перерисовка графиков

### Автоматическое обновление UI
- При загрузке новых данных поля очищаются
- При изменении layout обновляется состояние кнопок
- Кнопка "Reset" активна только при установленном пользовательском диапазоне

## Валидация данных

### Проверки при применении
1. **Логическая валидация**: From < To
2. **Диапазон данных**: 0 ≤ From < To ≤ (размер_данных - 1)
3. **Наличие данных**: Проверка загруженности данных

### Сообщения об ошибках
- "No data loaded" - если данные не загружены
- "'From' value must be less than 'To' value" - логическая ошибка
- "X Range must be between 0 and [max]" - выход за границы данных

## Интеграция с существующим функционалом

### Совместимость с zoom мышью
- X Range и zoom мышью работают независимо
- Оба метода используют одну и ту же систему ZoomRange
- Последний применённый метод имеет приоритет

### Синхронизация с скроллбарами
- При применении X Range автоматически обновляются скроллбары
- Скроллбары показываются только при активном zoom/range

### Обновление при изменениях
- Загрузка новых данных → сброс и очистка полей
- Изменение layout → обновление состояния кнопок
- Применение/сброс → обновление всего UI

## Тестирование

### Основные сценарии
1. **Применение корректного диапазона**
   - Ввести From: 100, To: 500
   - Нажать Apply

2. **Валидация ошибок**

   - Применить X Range, затем zoom мышью
   - Загрузить новые данные после установки диапазона
   - Переключить Dual Mode с активным диапазоном
