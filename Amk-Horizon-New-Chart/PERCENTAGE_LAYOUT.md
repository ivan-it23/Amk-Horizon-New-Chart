# Процентное распределение пространства - Version 2.9.0

**Дата:** 18 ноября 2025

## 🎯 Концепция

Переход от фиксированных пикселей к **процентному распределению** высоты окна для графиков. Это делает приложение адаптивным к разным разрешениям экрана и устройствам.

## 📊 Структура распределения

### Single Mode (один график)

```
┌─────────────────────────────────────────┐
│ Меню (20px фиксированно)                │
├─────────────────────────────────────────┤
│ Панель управления (25px фиксированно)   │
├─────────────────────────────────────────┤
│                                         │
│                                         │
│         График Chart 1                  │
│      (~95% доступной высоты)            │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│ Статусная строка (25px фиксированно)    │
└─────────────────────────────────────────┘
```

### Dual Mode (два графика)

```
┌─────────────────────────────────────────┐
│ Меню (20px фиксированно)                │
├─────────────────────────────────────────┤
│ Панель управления Chart 1 (25px)        │
├─────────────────────────────────────────┤
│                                         │
│      График Chart 1 (47%)               │
│                                         │
├─────────────────────────────────────────┤
│ Панель управления Chart 2 (25px)        │
├─────────────────────────────────────────┤
│                                         │
│      График Chart 2 (47%)               │
│                                         │
├─────────────────────────────────────────┤
│ Статусная строка (25px фиксированно)    │
└─────────────────────────────────────────┘
```

## 🔧 Константы

### Фиксированные размеры (в пикселях)
```cpp
MENU_HEIGHT = 18           // Высота главного меню
PANEL_HEIGHT = 25          // Высота панели управления
STATUSBAR_HEIGHT = 25      // Высота статусной строки
MARGIN = 5                 // Боковые отступы
ELEMENT_SPACING = 2        // Минимальный отступ между элементами
MIN_CHART_HEIGHT = 100     // Минимальная высота графика
```

### Процентное распределение
```cpp
CHART1_HEIGHT_PERCENT = 0.48f  // 48% для первого графика
CHART2_HEIGHT_PERCENT = 0.48f  // 48% для второго графика
// Оставшиеся ~4% на панели управления и отступы
```

## 📐 Формула расчёта

### Dual Mode:
```cpp
// 1. Вычисляем фиксированные элементы
totalFixedHeight = MENU_HEIGHT + (2 * PANEL_HEIGHT) + STATUSBAR_HEIGHT + (4 * ELEMENT_SPACING)

// 2. Доступная высота для графиков
availableHeight = windowHeight - totalFixedHeight

// 3. Высота каждого графика
chart1Height = availableHeight * 0.48
chart2Height = availableHeight * 0.48
```

### Single Mode:
```cpp
// График занимает всё пространство между панелью и статусной строкой
chartHeight = windowHeight - MENU_HEIGHT - PANEL_HEIGHT - STATUSBAR_HEIGHT - отступы
```

## ✅ Преимущества

1. **Адаптивность** - графики автоматически масштабируются при изменении размера окна
2. **Универсальность** - корректная работа на любых разрешениях экрана
3. **Пропорциональность** - соотношение размеров сохраняется
4. **Минимальные отступы** - всего 2px между элементами
5. **Предсказуемость** - поведение layout понятно и стабильно

## 🔄 Изменённые файлы

### LayoutModule.h
- Новые константы: `MENU_HEIGHT`, `ELEMENT_SPACING`
- Процентные константы: `CHART1_HEIGHT_PERCENT`, `CHART2_HEIGHT_PERCENT`
- Удалены устаревшие: `MENU_AND_PANEL1_HEIGHT`, `PANEL_SPACING`

### LayoutModule.cpp
- `CalculateSingleChartLayout()` - использует фиксированные отступы
- `CalculateDualChartLayout()` - использует процентное распределение
- `GetChart2PanelY()` - использует `ELEMENT_SPACING`

## 📈 Примеры расчёта

