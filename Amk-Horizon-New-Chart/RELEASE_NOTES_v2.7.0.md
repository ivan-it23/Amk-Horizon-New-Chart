# Release Notes - Version 2.7.0

**Дата релиза:** 10 ноября 2025

## 🎯 Основные изменения

### 1. Изменение расположения осей Y для двойных графиков

В версии 2.7.0 изменена логика расположения осей Y при одновременном отображении амплитуд и фаз на одном графике.

### 2. Упрощение интерфейса

Удалено избыточное меню "Вид" с дублирующими функциями.

### 3. Улучшение сообщений пользователю

Добавлены логичные подсказки в зависимости от состояния приложения.

## 📊 Что изменилось

### Было (v2.6.5 и ранее):
- **Левая ось Y**: Амплитуды (мВ)
- **Правая ось Y**: Фазы (мдег)

### Стало (v2.7.0):
- **Левая ось Y**: Фазы (мдег) ← **ИЗМЕНЕНО**
- **Правая ось Y**: Амплитуды (мВ) ← **ИЗМЕНЕНО**

## 💡 Преимущества

1. **Фазы на основной оси** - фазовые данные (более важные для анализа) теперь на привычной левой оси
2. **Логичное расположение** - основные данные слева, дополнительные справа
3. **Улучшенная читаемость** - фазы легче анализировать на левой оси

## 🔄 Обратная совместимость

При отображении **однородных данных** (только фазы ИЛИ только амплитуды) логика остаётся прежней:
- Одна ось Y отображается **слева** с соответствующими единицами измерения

## 🔧 Технические детали

### Изменённые файлы:
- `CurveSelectionModule.cpp` - изменено назначение `yAxisGroup` для кривых
- `ChartModule.cpp` - обновлены методы отрисовки двойных осей (без изменений, работает автоматически)
- `Amk-Horizon-New-Chart.cpp` - удалены обработчики команд `IDM_TOGGLE_DUAL` и `IDM_TEST_REFRESH`
- `Amk-Horizon-New-Chart.rc` - удалено меню "Вид" с пунктами "Переключить режим графиков" и "Тест обновления графиков"
- `Resource.h` - удалены определения `IDM_TOGGLE_DUAL` и `IDM_TEST_REFRESH`

### Изменённые методы (CurveSelectionModule):
- `CreateAmplitudeCurve()` - `yAxisGroup = 1` (правая ось)
- `CreatePhaseCurve()` - `yAxisGroup = 0` (левая ось)
- `CreateRatioCurve()` - `yAxisGroup = 1` (правая ось)
- `CreateDifferenceCurve()` - `yAxisGroup = 0` (левая ось)
- `AddSingleReceiverCurves()` - обновлена логика назначения осей
- `AddTwoReceiversCurves()` - обновлена логика назначения осей
- `AddTransmitterCurves()` - обновлена логика назначения осей
- `AddSilentTransmitterCurves()` - обновлена логика назначения осей

### Удалённые элементы:
- Меню "Вид" полностью удалено
- Пункт меню "Переключить режим графиков" (IDM_TOGGLE_DUAL)
- Пункт меню "Тест обновления графиков" (IDM_TEST_REFRESH)
- Обработчики команд в WndProc

### Улучшенные сообщения (ChartManager):
- `DrawChartLegacy()` - добавлена проверка наличия данных
- **Без данных**: "Please open a data file first" (без сетки)

## ✅ Тестирование

Рекомендуется протестировать следующие сценарии:

1. **Двойные оси** (амплитуды + фазы):
   - Выбрать один приёмник (R1 или R2) в Device Schematic
   - Убедиться, что фазы отображаются на левой оси (мдег)
   - Убедиться, что амплитуды отображаются на правой оси (мВ)

2. **Только фазы**:
   - Отключить все амплитуды
   - Убедиться, что фазы отображаются на левой оси (мдег)

3. **Только амплитуды**:
   - Отключить все фазы
   - Убедиться, что амплитуды отображаются на левой оси (мВ)

4. **Два приёмника** (R1+R2):
   - Разности фаз на левой оси (мдег)
   - Отношения амплитуд на правой оси (V/V)

5. **Передатчики**:
   - Фазы для R1 и R2 на левой оси (мдег)
   - Амплитуды для R1 и R2 на правой оси (мВ)

6. **Сообщения пользователю**:
   - При запуске без данных: "Please open a data file first"
   - После загрузки данных: "Click 'Device Schematic' to configure this chart"
