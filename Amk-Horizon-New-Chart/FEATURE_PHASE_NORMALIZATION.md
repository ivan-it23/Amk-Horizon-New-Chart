# 🔄 Нормализация фазовых данных - Версия 2.3.0

## 📋 Обзор

Данный документ описывает реализацию нормализации фазовых данных в диапазон (-π, π] для корректного отображения циклических фазовых сигналов в приложении AMK-Horizon-New-Chart.

## 🎯 Назначение

### Проблема
Фазовые данные, получаемые от геофизических приборов индукционного каротажа, могут выходить за пределы стандартного диапазона (-π, π], что приводит к:
- Резким скачкам на графиках при переходе через границы ±π
- Некорректному отображению циклических фазовых сигналов
- Затруднению анализа данных

### Решение
Реализована нормализация фазовых данных в стандартный диапазон (-π, π] с использованием алгоритма:
```cpp
while (phase > π) phase -= 2π;
while (phase ≤ -π) phase += 2π;
```

## 🔧 Техническая реализация

### Метод нормализации

#### Сигнатура
```cpp
float DataModule::NormalizePhase(float phaseRadians) const;
```

#### Реализация
```cpp
float DataModule::NormalizePhase(float phaseRadians) const {
    const float PI = 3.14159265358979323846f;
    
    // Приводим фазу к диапазону (-π, π]
    while (phaseRadians > PI) {
        phaseRadians -= 2.0f * PI;
    }
    while (phaseRadians <= -PI) {
        phaseRadians += 2.0f * PI;
    }
    
    return phaseRadians;
}
```

#### Параметры
- **phaseRadians** - значение фазы в радианах (может быть любым числом)

#### Возвращаемое значение
- Нормализованное значение фазы в диапазоне (-π, π]

### Применение нормализации

#### 3. CalculatePhaseData() - фазы приемников для кривых

```cpp
void DataModule::CalculatePhaseData(int transmitterIndex, int receiverIndex, 
                                   FrequencyBand frequency, std::vector<float>& outData,
                                   double minX, double maxX) const {
    // ... получение индексов ...
    
    for (size_t i = startIndex; i < endIndex; ++i) {
        const GP_TOOL_DATA& record = data[i];
        float phase = (receiverIndex == 0) ? record.PH_RX_1[rxIdx] : record.PH_RX_2[rxIdx];
        phase = NormalizePhase(phase); // Нормализация
        outData.push_back(phase * 57295.7795f); // Преобразование рад -> мдег
    }
}
```

## 📊 Порядок обработки фазовых данных

### Полный цикл обработки

```
1. Чтение данных из файла
   ↓
   Сырые данные фазы в радианах (может быть любое значение)
   Пример: 4.5 рад, -5.2 рад, 0.5 рад
   
2. Нормализация (NormalizePhase)
   ↓
   Фаза в диапазоне (-π, π]
   Пример: 4.5 → -1.78 рад, -5.2 → 1.08 рад, 0.5 → 0.5 рад
   
3. Преобразование в миллиградусы
   ↓
   Фаза в миллиградусах (* 57295.7795)
   Пример: -1.78 → -102000 мдег, 1.08 → 62000 мдег, 0.5 → 28648 мдег
   
4. Отображение на графике
   ↓
   График с корректными значениями в диапазоне [-180000, +180000] мдег
```

## 🔬 Физический смысл

### Циклическая природа фазы

Фаза является циклической величиной:
- **360° = 0°** (полный оборот возвращается к началу)
- **370° = 10°** (370° - 360° = 10°)
- **-370° = -10°** (-370° + 360° = -10°)

В радианах:
- **2π = 0** (полный оборот)
- **4.5 рад ≈ 1.36π** → нормализуется к **-0.64π ≈ -1.78 рад**
- **-5.2 рад ≈ -1.65π** → нормализуется к **0.35π ≈ 1.08 рад**

### Примеры нормализации

|---------------------|-------------------|----------------------|---------------------|------------------------|
| 0.5                 | 28.6°             | 0.5                  | 28.6°               | 28648                  |
| 3.5                 | 200.5°            | -2.78                | -159.5°             | -159352                |

| 6.28 (≈2π)          | 360°              | 0.0                  | 0°                  | 0                      |

## 🎯 Применение к типам данных

### PHASE_DIFFERENCE (разности фаз)
- **Формула**: `PH_RX_2[idx] - PH_RX_1[idx]`
- **Нормализация**: Применяется к результату вычитания
- **Диапазон**: (-π, π] → (-180000, +180000] мдег
- **Использование**: Анализ фазовых сдвигов между приемниками

### PHASE_RX1 (фазы приемника 1)
- **Источник**: `PH_RX_1[idx]` для передатчиков T1-T4
- **Нормализация**: Применяется к каждому значению
- **Частоты**: 400 kHz (индексы 2-5), 2000 kHz (индексы 6-9)
- **Использование**: Анализ фазовых характеристик приемника 1

### PHASE_RX2 (фазы приемника 2)
- **Источник**: `PH_RX_2[idx]` для передатчиков T1-T4
- **Нормализация**: Применяется к каждому значению
- **Частоты**: 400 kHz (индексы 2-5), 2000 kHz (индексы 6-9)
- **Использование**: Анализ фазовых характеристик приемника 2

## ✅ Преимущества

### 1. Корректное отображение
- Устранение резких скачков на графиках
- Плавные переходы между значениями
- Корректная визуализация циклических сигналов

### 2. Соответствие стандартам
- Стандартный диапазон (-π, π] для фазовых данных
- Соответствие практике обработки данных индукционного каротажа
- Совместимость с другими системами анализа

### 3. Сохранение данных
- Нормализация сохраняет информацию (в отличие от обнуления)
- Обратимая операция (можно восстановить исходное значение)
- Не теряется точность измерений

### 4. Обратная совместимость
- Не изменяет формат файлов данных
- Работает с существующими данными
- Не требует переконвертации старых файлов

## 🧪 Тестирование

### Тестовые сценарии

#### Сценарий 1: Фаза в пределах диапазона
```
Вход: 0.5 рад
Ожидаемый результат: 0.5 рад (без изменений)
Результат в мдег: 28648 мдег
```

#### Сценарий 2: Фаза больше π
```
Вход: 4.5 рад (≈ 1.43π)
Нормализация: 4.5 - 2π ≈ -1.78 рад
Результат в мдег: -102204 мдег
```

#### Сценарий 3: Фаза меньше -π
```
Вход: -5.2 рад (≈ -1.65π)
Нормализация: -5.2 + 2π ≈ 1.08 рад
Результат в мдег: 62096 мдег
```

#### Сценарий 4: Разность фаз
```
PH_RX_2 = 3.0 рад, PH_RX_1 = -2.0 рад
Разность: 3.0 - (-2.0) = 5.0 рад
Нормализация: 5.0 - 2π ≈ -1.28 рад
Результат в мдег: -73379 мдег
```

### Проверка корректности

Для проверки корректности нормализации можно использовать следующие критерии:
1. **Диапазон**: Все значения должны быть в диапазоне (-π, π]
2. **Непрерывность**: Нет резких скачков между соседними точками
3. **Цикличность**: Значения ±π должны быть эквивалентны
