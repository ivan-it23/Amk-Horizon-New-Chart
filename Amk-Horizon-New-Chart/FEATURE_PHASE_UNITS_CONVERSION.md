# Улучшение: Преобразование единиц измерения фаз из радианов в миллиградусы

## Дата
2 ноября 2025

## Описание
Изменены единицы измерения для фазовых данных с радианов (rad) на миллиградусы (mdeg) для улучшения читаемости графиков и удобства анализа.

## Проблема
При отображении фазовых данных на графиках:
- Значения отображались в **радианах (rad)**
- Радианы менее интуитивны для анализа
- Значения в радианах требуют дополнительных вычислений для интерпретации

## Решение
Преобразование отображения фаз из радианов в миллиградусы:
- **Формула**: `значение_в_mdeg = значение_в_rad * 57295.7795f`
- **Математика**: 1 радиан = 180/π градусов ≈ 57.2957795 градусов, 1 градус = 1000 миллиградусов
- **Коэффициент**: 180/π * 1000 ≈ 57295.7795

### Что изменено:

1. **Единицы измерения в интерфейсе**: "deg" → "mdeg"
2. **Преобразование данных**: Умножение на 57295.7795f при вычислении
3. **Применено к типам данных**:
   - ✅ `PHASE_RX1` - фазы приемника 1
   - ✅ `PHASE_RX2` - фазы приемника 2
   - ✅ `PHASE_DIFFERENCE` - разности фаз
   - ❌ Амплитуды - НЕ изменены

## Математика преобразования

### Формула
```
значение_в_mdeg = значение_в_rad * 57295.7795f
```

### Вывод формулы
1. **Радианы в градусы**: `градусы = радианы * (180 / π)`
2. **Градусы в миллиградусы**: `миллиградусы = градусы * 1000`
3. **Объединённая формула**: `миллиградусы = радианы * (180 / π) * 1000`
4. **Численное значение**: `180 / π * 1000 ≈ 57295.7795`

### Примеры преобразования

| Значение в радианах (rad) | Вычисление | Значение в миллиградусах (mdeg) |
|---------------------------|------------|----------------------------------|
| 0 rad                     | 0 * 57295.7795 | 0 mdeg |
| π/6 rad (30°)             | 0.5236 * 57295.7795 | ≈ 30000 mdeg (30°) |
| π/4 rad (45°)             | 0.7854 * 57295.7795 | ≈ 45000 mdeg (45°) |
| π/2 rad (90°)             | 1.5708 * 57295.7795 | ≈ 90000 mdeg (90°) |
| π rad (180°)              | 3.1416 * 57295.7795 | ≈ 180000 mdeg (180°) |
| 2π rad (360°)             | 6.2832 * 57295.7795 | ≈ 360000 mdeg (360°) |

## Дополнительные улучшения

### Увеличены отступы для осей Y
После преобразования в миллиградусы значения стали длиннее (например, -180000 вместо -3.14), что требовало увеличения отступов для корректного отображения подписей осей.

**Изменённый файл: ChartModule.cpp**

**Метод `CalculatePlotRect()` (обычный график):**
```cpp
// Было:
plotRect.left += 50;   // Отступ для Y-оси
plotRect.right -= 20;  // Отступ справа

// Стало:
plotRect.left += 80;   // Увеличенный отступ для Y-оси (для длинных значений мВ и мдег)
plotRect.right -= 30;  // Увеличенный отступ справа
```

**Метод `CalculateDualAxisPlotRect()` (график с двойными осями):**
```cpp
// Было:
plotRect.left += 50;   // Отступ для левой Y-оси
plotRect.right -= 80;  // Увеличенный отступ для правой Y-оси

// Стало:
plotRect.left += 80;   // Увеличенный отступ для левой Y-оси (для длинных значений мВ)
plotRect.right -= 120; // Увеличенный отступ для правой Y-оси (для длинных значений мдег)
```

**Результат:**
- ✅ Подписи левой оси Y (амплитуды в мВ) полностью помещаются
- ✅ Подписи правой оси Y (фазы в мдег) полностью помещаются
- ✅ Интерфейс выглядит аккуратно и профессионально
- ✅ Нет обрезания или наложения текста
