# 📖 Руководство пользователя AMK-Horizon-New-Chart

## 🎯 Введение

AMK-Horizon-New-Chart - приложение для визуализации данных геофизических приборов. Версия 2.12.5 включает пошаговый откат zoom (история zoom), исправление кроссплота для амплитудных функций, полностью исправленный zoom и скроллинг по обеим осям (X и Y), автоматический сброс X Range при смене функции, целочисленные подписи оси X, ограничение минимального zoom, полную поддержку кроссплота, статусную строку с координатами курсора и отображение данных в физических единицах.

## 🚀 Первые шаги

### Запуск и загрузка данных
1. Запустите `Amk-Horizon-New-Chart.exe`
2. Выберите **File → Open Data File**
3. Выберите бинарный файл (*.bin)
4. Данные автоматически отобразятся на графике

## 🎛️ Основной интерфейс

### Панель управления
- **☑️ Dual Mode** - переключение между одним и двумя графиками
- **📊 Data Type** - выбор типа отображаемых данных
- **📡 Frequency** - выбор частоты (400 kHz / 2000 kHz)
- **🔄 Refresh** - обновление графика
- **⚙️ Device Schematic** - открытие схемы прибора
- **🎯 X Range Controls** - точное задание диапазона отображения

### Типы данных
- **Phase Difference** - разности фаз между приемниками (R2-R1) в миллиградусах (мдег)
- **Amplitude Ratio** - отношения амплитуд (R2/R1), безразмерная величина (V/V)
- **Amplitude RX1/RX2** - амплитуды для конкретного приемника в милливольтах (мВ)
- **Phase RX1/RX2** - фазы для конкретного приемника в миллиградусах (мдег)
- **Silent Amplitude RX1/RX2** - амплитуды молчащих передатчиков в милливольтах (мВ)
- **Temperature** - температурные данные

### Единицы измерения
- **Амплитуды (мВ)**: Значения в милливольтах после преобразования из сырых данных АЦП
  - Формула: `значение * 4000.0 / 2^24`
  - Пример: 0.5 мВ, 1.2 мВ, 2.8 мВ
- **Фазы (мдег)**: Значения в миллиградусах после нормализации и преобразования
  - Нормализация: Приведение к диапазону (-π, π] для устранения скачков
  - Преобразование: `нормализованная_фаза * 57295.7795`
  - Диапазон: от -180000 мдег до +180000 мдег (-180° до +180°)
  - Пример: -90000 мдег (-90°), 0 мдег (0°), 90000 мдег (+90°)

## 📊 Работа с графиками

### Интерактивность
- **🔍 Масштабирование**: Выделите область мышью для увеличения по X и Y (оранжевая рамка без штриховки)
- **⚠️ Ограничение zoom**: Минимальный диапазон 10 точек по X и 10 единиц по Y
- **🔄 Сброс масштаба**: Щелкните правой кнопкой мыши на графике (сбрасывает X и Y)
- **📜 Прокрутка**: Используйте горизонтальный и вертикальный scrollbar при масштабировании
- **↕️ Вертикальный scrollbar**: Прокрутка графика по оси Y (справа от графика)
- **🎯 X Range Controls**: Точное задание диапазона отображения (минимум 10 точек)
- **📍 Координаты курсора**: Наведите мышь на график для отображения координат в статусной строке

### Легенда
- **🎨 Цветные индикаторы** для каждого канала (T1-T4)
- **☑️ Чекбоксы** для включения/выключения каналов
- **📝 Названия каналов** с единицами измерения
- **📊 Двойные оси**: [Left Axis (mdeg)] для фаз, [Right Axis (mV)] для амплитуд

### Умное назначение цветов
- **Приоритетные цвета** для T1-T4: Зелёный, Жёлтый, Красный, Синий
- **Расширенная палитра** из 12 цветов для сложных конфигураций
- **Автоматическое избежание конфликтов** цветов

## 🎯 X Range Controls

### Использование
1. **Введите начальное значение** в первое поле (From) - целое число
2. **Введите конечное значение** во второе поле (To) - целое число
3. **Убедитесь, что диапазон >= 10** (To - From >= 10)
4. **Нажмите Apply** для применения диапазона
5. **Нажмите Reset** для возврата к полному диапазону

### Ограничения (v2.11.0)
- **Минимальный диапазон**: 10 точек
- **Целые числа**: Подписи оси X отображаются как целые числа
- **Примеры допустимых диапазонов**:
  - ✅ From: 0, To: 10 (диапазон = 10)
  - ✅ From: 100, To: 150 (диапазон = 50)
  - ❌ From: 0, To: 5 (диапазон = 5, слишком мал)
  - ❌ From: 100, To: 108 (диапазон = 8, слишком мал)

### Автоматический сброс X Range (v2.12.3)
- **При смене функции/пресета**: При нажатии Apply в Device Schematic поля X Range автоматически сбрасываются к полному диапазону (From = 0, To = максимум)
- **При открытии нового файла**: При загрузке новых данных X Range сбрасывается для обоих графиков
- **Сброс zoom**: При смене функции zoom также сбрасывается к полному виду

### В Dual Mode
- **Chart 1**: Элементы управления в панели инструментов
- **Chart 2**: Отдельные элементы управления рядом с Device Schematic
- **Независимые диапазоны**: Каждый график может показывать свой участок данных

## 📍 Статусная строка с координатами

### Отображение координат
Статусная строка расположена внизу окна и автоматически отображает координаты курсора при наведении на график.

### Формат отображения

**Для одной оси:**
```
X: 245  │  Y: 1250.5 mV  │  │  Points: 1244  │  data.bin
```

**Для двойных осей:**
```
X: 245  │  Y₁: -85000 mdeg  │  Y₂: 1.25 mV  │  Points: 1244  │  data.bin
```

### Части статусной строки
1. **X координата**: Номер точки данных (0, 1, 2, ... N)
2. **Y₁ координата**: Значение на левой оси (фазы в мдег)
3. **Y₂ координата**: Значение на правой оси (амплитуды в мВ) - только для двойных осей
4. **Информация о файле**: Количество точек и имя файла

### Форматирование значений
- **Фазы (mdeg)**: Целые числа (например, -85000 mdeg)
- **Амплитуды (mV)**: 3 знака после запятой (например, 1.250 mV)
- **Отношения (V/V)**: 4 знака после запятой (например, 0.9876 V/V)
- **Температура (°C)**: 2 знака после запятой (например, 25.50 °C)

### Поведение
- **При наведении на график**: Координаты обновляются в реальном времени
- **Вне графика**: Отображается "Ready"
- **Без загруженных данных**: Отображается "No file loaded"

## ⚙️ Схема прибора (Device Schematic)

### Выбор типа оси X (v2.10.0)
В Device Schematic доступен выпадающий список "X-Axis" для выбора данных оси X:
- **Frame Number** (по умолчанию) - номер кадра (0, 1, 2, ... N)
- **Temperature** - температура прибора в градусах Цельсия

**Кроссплот режим**: При выборе "Temperature" график отображает зависимость данных от температуры, что позволяет анализировать температурные зависимости измерений.

### Элементы схемы
- **🔴 Transmitters (T1-T4)** - передатчики (красные)
- **🟢 Receivers (R1-R2)** - приемники (зеленые)
- **⚫ Silent Transmitters** - молчащие передатчики (серые)

### Правила выбора
- Нельзя одновременно выбирать передатчики и приемники
- Молчащие передатчики можно комбинировать с активными элементами
- Запрещена только комбинация: оба приемника (R1+R2) + молчащие передатчики

### Примеры разрешенных комбинаций
- ✅ **T1 + Silent R1** - активный передатчик + молчащий
- ✅ **R1 + Silent R1 + Silent R2** - один приемник + молчащие
- ✅ **T1 + T2 + Silent R1** - несколько передатчиков + молчащий
- ✅ **Silent R1 + Silent R2** - только молчащие передатчики

### Порядок отображения кривых
- **Для приёмников**: Сначала все фазы (T1-T4 Phase), затем все амплитуды (T1-T4 Amplitude)
- **Для передатчиков**: Для каждого передатчика сначала фазы, затем амплитуды
- **Преимущество**: Фазы (более важные) в начале списка для удобства анализа

## 🎨 Быстрые пресеты

### Доступные пресеты
- **All Ampl R1/R2** - все амплитуды для приемника
- **All Phase R1/R2** - все фазы для приемника
- **Ampl Ratios** - отношения амплитуд для всех передатчиков
- **Phase Diff** - разности фаз для всех передатчиков

### Использование
1. Нажмите на нужный пресет
2. Автоматически выберутся соответствующие элементы
3. Нажмите **Apply** для применения настроек

## 🔬 Кроссплот: Анализ зависимостей от температуры (v2.10.0, обновлено v2.10.1)

### Что такое кроссплот?
Кроссплот - это режим отображения, при котором на оси X отображается не номер кадра, а температура прибора. Это позволяет анализировать зависимость измерений от температуры.

### Как использовать кроссплот
1. Откройте Device Schematic для нужного графика
2. В выпадающем списке "X-Axis" выберите "Temperature"
3. Настройте кривые (выберите элементы или используйте пресеты)
4. Нажмите "Apply"
5. График отобразится с температурой на оси X

### Примеры использования
- **Температурная стабильность**: Анализ изменения амплитуд при изменении температуры
- **Температурный дрейф фаз**: Отслеживание фазовых сдвигов от температуры
- **Калибровка**: Определение температурных коэффициентов для компенсации
- **Контроль качества**: Проверка стабильности измерений в температурном диапазоне

### Особенности кроссплота (v2.10.1)
- **Автоматическое масштабирование**: Диапазон температур определяется автоматически
- **Подписи в °C**: Ось X подписана в градусах Цельсия (символ отображается корректно)
- **Расположение подписи**: Подпись "°C" размещена в правом углу графика
- **Zoom полностью поддерживается**: Можно увеличивать участки графика мышью
- **Корректное преобразование координат**: Выделение области правильно работает с температурой
- **Независимые настройки**: Каждый график может иметь свой тип оси X

### Использование Zoom в кроссплоте (v2.10.1)
1. Переключитесь в режим Temperature (X-Axis: Temperature)
2. Выделите область на графике мышью (левая кнопка + перетаскивание)
3. График автоматически увеличит выбранный участок
4. Zoom работает корректно - учитывает нелинейное распределение температуры
5. Правая кнопка мыши сбрасывает zoom к полному диапазону

### Технические детали
- **Преобразование координат**: Экранная X координата → Температура → Поиск ближайшего кадра
- **Точность**: Система находит ближайший кадр с выбранной температурой
- **Производительность**: Быстрый поиск даже для больших массивов данных

## 🔍 Zoom и скроллинг по осям X и Y (v2.12.3)

### Как использовать zoom по обеим осям
1. **Выделите область мышью** (левая кнопка + перетаскивание)
2. **График автоматически увеличит** выбранный участок по X и Y
3. **Если диапазон < 10**, появится сообщение о достижении предела

### Горизонтальный scrollbar (ось X)
**Появляется:** Только при активном zoom  
**Расположение:** Внизу графика  
**Управление:**
- Перетаскивание ползунка для плавной прокрутки
- Клик по стрелкам для точной настройки
- **Полный диапазон**: Можно прокрутить до начала (0) и до конца данных (максимум)

### Вертикальный scrollbar (ось Y)
**Появляется:** Только при активном zoom  
**Расположение:** Справа от графика  
**Управление:**
- Перетаскивание ползунка для плавной прокрутки
- Клик по стрелкам для точной настройки
- Page Up/Page Down для быстрой прокрутки
- **Полный диапазон**: Можно прокрутить до нижней и верхней границы данных

### Двойные оси
**Поведение:** Zoom и scroll применяются к обеим осям Y одновременно  
**Особенности:**
- Левая ось (фазы) и правая ось (амплитуды) масштабируются пропорционально
- Вертикальный scrollbar управляет обеими осями
- Сохраняется соотношение между осями

### Ограничения zoom
- **Минимальный диапазон X**: 10 точек
- **Минимальный диапазон Y**: 10 единиц
- **Примеры**:
  - ✅ Диапазон Y: 100 - 150 (диапазон = 50)
  - ✅ Диапазон Y: 0 - 10 (диапазон = 10)
  - ❌ Диапазон Y: 0 - 5 (диапазон = 5, слишком мал)

### Сброс zoom (v2.12.5 - пошаговый откат)
**Правая кнопка мыши** — пошаговый откат zoom:
- Каждый zoom сохраняется в историю (стек)
- ПКМ откатывает на один шаг назад к предыдущему zoom
- Когда история пуста — сброс к полному виду

**Пример:**
1. Исходный вид → Zoom 1 → Zoom 2 → Zoom 3
2. ПКМ → возврат к Zoom 2
3. ПКМ → возврат к Zoom 1
4. ПКМ → возврат к исходному виду

**Кнопка Reset Zoom** — полный сброс:
- Сбрасывает zoom к полному диапазону данных
- Очищает всю историю zoom
- Scrollbar автоматически скрываются

### Исправления в v2.12.3
- **Горизонтальный скроллинг**: Теперь можно прокрутить до конца данных (до максимального значения X)
- **Вертикальный скроллинг**: Полный доступ к верхней и нижней границам графика
- **Равномерный padding**: Одинаковый отступ 5% сверху и снизу

### Примеры использования
- **Анализ шумов**: Приблизьте участок с малыми амплитудами для детального изучения
- **Фазовые переходы**: Увеличьте область с резкими изменениями фаз
- **Сравнение каналов**: Приблизьте участок для точного сравнения разных передатчиков
- **Температурные зависимости**: В режиме кроссплота увеличьте интересующий диапазон

## ❗ Устранение проблем

### Частые проблемы

**График не отображается**
- Убедитесь, что данные загружены и выбран правильный тип данных

**Нет доступных кривых в схеме прибора**
- Выберите элементы на схеме согласно правилам выбора

**Медленная отрисовка**
- Отключите неиспользуемые каналы, используйте масштабирование

**Не могу приблизить график дальше (v2.11.0, v2.12.0)**
- Минимальный диапазон zoom по X: 10 точек
- Минимальный диапазон zoom по Y: 10 единиц
- Это обеспечивает читаемость подписей осей
- Сообщение: "Zoom Limit Reached"

**Ошибка при применении X Range (v2.11.0)**
- Убедитесь, что диапазон (To - From) >= 10
- Используйте только целые числа
- Пример: From: 0, To: 10 (минимально допустимый диапазон)

**Вертикальный scrollbar не появляется (v2.12.0)**
- Scrollbar появляется только при активном zoom
- Выделите область мышью для активации zoom
- После сброса zoom (правая кнопка) scrollbar скрывается
