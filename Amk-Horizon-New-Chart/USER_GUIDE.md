# 📖 Руководство пользователя AMK-Horizon-New-Chart v2.2.0

## 🎯 Введение

AMK-Horizon-New-Chart - это приложение для визуализации данных геофизических приборов. Версия 2.2.0 включает новые функции независимого управления диапазоном X для каждого графика. Это руководство поможет вам быстро освоить все возможности программы.

## 🚀 Первые шаги

### Запуск приложения
1. Запустите `Amk-Horizon-New-Chart.exe`
2. Откроется главное окно с панелью управления сверху
3. По умолчанию отображается один график в режиме "Phase Difference"

### Загрузка данных
1. Выберите **File → Open Data File** в меню
2. Выберите бинарный файл с данными (*.bin)
3. После загрузки данные автоматически отобразятся на графике

## 🎛️ Основной интерфейс

### Панель управления
В верхней части окна расположены элементы управления:

- **☑️ Dual Mode** - переключение между одним и двумя графиками
- **📊 Data Type** - выбор типа отображаемых данных
- **📡 Frequency** - выбор частоты (400 kHz / 2000 kHz)
- **🔄 Refresh** - обновление графика
- **⚙️ Device Schematic** - открытие схемы прибора
- **🎯 X Range Controls** - точное задание диапазона отображения (НОВОЕ v2.2.0)

### Типы данных
- **Phase Difference** - разности фаз между приемниками (R2-R1)
- **Amplitude Ratio** - отношения амплитуд (R2/R1)
- **Amplitude RX1/RX2** - амплитуды для конкретного приемника
- **Phase RX1/RX2** - фазы для конкретного приемника
- **Silent Amplitude RX1/RX2** - амплитуды молчащих передатчиков
- **Temperature** - температурные данные

## 📊 Работа с графиками

### Интерактивность
- **🔍 Масштабирование**: Выделите область мышью для увеличения
  - **УЛУЧШЕНО v2.2.0**: Оранжевое выделение с диагональной штриховкой для лучшей видимости
- **🔄 Сброс масштаба**: Щелкните правой кнопкой мыши на графике
- **📜 Прокрутка**: Используйте горизонтальный скроллбар (появляется при масштабировании)
- **🎯 X Range Controls**: Точное задание диапазона отображения (НОВОЕ v2.2.0)

### Легенда
В правой части графика отображается легенда с:
- **🎨 Цветными индикаторами** для каждого канала (T1-T4)
- **☑️ Чекбоксами** для включения/выключения каналов
- **📝 Названиями каналов** (T1, T2, T3, T4)

#### Умное назначение цветов
Система автоматически назначает цвета кривым для максимальной различимости:
- **Приоритетные цвета** для T1-T4 на левой оси:
  - T1 → Зелёный
  - T2 → Жёлтый
  - T3 → Красный
  - T4 → Синий
- **Расширенная палитра** из 12 цветов для сложных конфигураций
- **Автоматическое избежание конфликтов** - если приоритетный цвет занят, выбирается следующий свободный
- **Независимость осей** - цвета назначаются отдельно для левой и правой осей

### Двойной режим
1. Установите флажок **Dual Mode**
2. Появится второй график с независимыми настройками
3. Каждый график можно настроить отдельно
4. **НОВОЕ v2.2.0**: Каждый график имеет свои независимые X Range Controls

## 🎯 X Range Controls (НОВОЕ v2.2.0)

### Назначение
X Range Controls позволяют точно задать диапазон отображения по оси X для каждого графика независимо.

### Расположение элементов управления

#### Single Mode (один график)
- **Панель инструментов**: Все элементы управления X Range расположены в верхней панели
- **Элементы**: X Range: [поле ввода] to [поле ввода] [Apply] [Reset]

#### Dual Mode (два графика)
- **Chart 1**: Элементы управления в панели инструментов (всегда видны)
- **Chart 2**: Отдельные элементы управления рядом с кнопкой Device Schematic (показываются только в Dual Mode)

### Использование X Range Controls

#### Задание диапазона
1. **Введите начальное значение** в первое поле (From)
2. **Введите конечное значение** во второе поле (To)
3. **Нажмите Apply** для применения диапазона
4. График отобразит только данные в указанном диапазоне

#### Сброс диапазона
1. **Нажмите Reset** для возврата к полному диапазону данных
2. Поля ввода очистятся
3. График покажет все доступные данные

#### Валидация данных
- **Проверка корректности**: Начальное значение должно быть меньше конечного
- **Сообщения об ошибках**: При некорректном вводе появится сообщение с указанием номера графика
- **Автоматическая коррекция**: Пустые поля игнорируются

### Преимущества независимых X Range Controls
- **Сравнение разных участков**: Chart 1 может показывать начало данных, Chart 2 - конец
- **Детальный анализ**: Каждый график может фокусироваться на своем участке
- **Гибкость настройки**: Полная независимость диапазонов
- **Сохранение состояния**: Диапазоны сохраняются при переключении режимов

## ⚙️ Схема прибора (Device Schematic)

### Открытие схемы
1. Нажмите кнопку **Device Schematic** для нужного графика
2. Откроется диалоговое окно с визуальной схемой прибора

### Элементы схемы
- **🔴 Transmitters (T1-T4)** - передатчики (красные)
- **🟢 Receivers (R1-R2)** - приемники (зеленые)
- **⚫ Silent Transmitters** - молчащие передатчики (серые)

### Выбор элементов
1. **Кликните** на элементы схемы для их выбора/отмены
2. **Правила выбора**:
   - Нельзя одновременно выбирать передатчики и приемники
   - **ОБНОВЛЕНО**: Молчащие передатчики можно комбинировать с активными элементами
   - Запрещена только комбинация: оба приемника (R1+R2) + молчащие передатчики
   - Должен быть выбран хотя бы один элемент

### Примеры разрешенных комбинаций:
- ✅ **T1 + Silent R1** - активный передатчик + молчащий
- ✅ **R1 + Silent R1 + Silent R2** - один приемник + молчащие
- ✅ **T1 + T2 + Silent R1** - несколько передатчиков + молчащий
- ✅ **Silent R1 + Silent R2** - только молчащие передатчики

### Настройка частоты
- Выберите частоту в выпадающем списке **Frequency**
- Доступны: **400 kHz** и **2000 kHz**

### Доступные кривые (Available Curves)
После выбора элементов отображается список доступных кривых:
- **☑️ Чекбоксы** для включения/выключения кривых
- **📊 Названия кривых** с единицами измерения
- **📍 Индикаторы осей** [Left Axis] / [Right Axis]

## 🎨 Быстрые пресеты (Quick Presets)

### Доступные пресеты
- **All Ampl R1** - все амплитуды для приемника R1
- **All Ampl R2** - все амплитуды для приемника R2
- **All Phase R1** - все фазы для приемника R1
- **All Phase R2** - все фазы для приемника R2
- **Ampl Ratios** - отношения амплитуд для всех передатчиков
- **Phase Diff** - разности фаз для всех передатчиков

### Использование пресетов
1. Нажмите на нужный пресет
2. Автоматически выберутся соответствующие элементы схемы
3. Обновится список доступных кривых
4. Нажмите **Apply** для применения настроек

## 🔄 Копирование настроек

### Copy from...
1. Нажмите кнопку **Copy from...**
2. Настройки скопируются с другого графика
3. Подтвердите копирование в диалоговом окне

## 📈 Система двойных осей

### Когда используется
- При выборе **двух приемников** (R1 и R2)
- Автоматически создаются кривые для левой и правой осей
- **Левая ось**: отношения амплитуд (V/V)
- **Правая ось**: разности фаз (deg)

### Отображение
- **Сплошные линии** - кривые левой оси
- **Пунктирные линии** - кривые правой оси
- **Отдельные легенды** для каждой оси

## 💡 Советы по использованию

### Эффективная работа
1. **Начните с пресетов** - они настроят оптимальные конфигурации
2. **Используйте масштабирование** для детального анализа участков
3. **Отключайте ненужные каналы** для лучшей читаемости
4. **Копируйте настройки** между графиками для сравнения
5. **НОВОЕ v2.2.0**: Используйте X Range Controls для точного задания диапазонов
6. **НОВОЕ v2.2.0**: В Dual Mode настраивайте разные диапазоны для сравнения участков

### Анализ данных
- **Phase Difference** - для анализа фазовых сдвигов
- **Amplitude Ratio** - для сравнения чувствительности приемников
- **Single Receiver** - для детального анализа конкретного приемника
- **Temperature** - для контроля температурного режима

### Оптимизация производительности
- **Загружайте только нужные данные**
- **Используйте масштабирование** вместо прокрутки всего массива
- **Отключайте неиспользуемые каналы**

## ❗ Устранение проблем

### Частые проблемы

**Проблема**: График не отображается
- **Решение**: Убедитесь, что данные загружены и выбран правильный тип данных

**Проблема**: Нет доступных кривых в схеме прибора
- **Решение**: Выберите элементы на схеме согласно правилам выбора

**Проблема**: Странные символы в интерфейсе
- **Решение**: Перезапустите приложение (проблема кодировки исправлена)

**Проблема**: Медленная отрисовка
- **Решение**: Отключите неиспользуемые каналы, используйте масштабирование

### Ограничения
- **Максимум 8 кривых** на одном графике
- **Только бинарные файлы** формата GP_TOOL_DATA
- **Windows-платформа** только

## 🔧 Горячие клавиши

- **Ctrl+O** - открыть файл данных
- **F5** - обновить график
- **Правая кнопка мыши** - сброс масштаба
- **Левая кнопка мыши + перетаскивание** - масштабирование области
