# Release Notes - Version 2.9.0

**Дата релиза:** 18 ноября 2025

## 🎯 Основные изменения

### Процентное распределение пространства для графиков

В версии 2.9.0 реализован переход от фиксированных пикселей к **процентному распределению** высоты окна для графиков. Это делает приложение адаптивным к разным разрешениям экрана.

## 📊 Что изменилось

### Было (v2.8.1 и ранее):
- Фиксированные размеры в пикселях для всех элементов
- Проблемы с адаптацией к разным разрешениям
- Отступы 3-5 пикселей между элементами

### Стало (v2.9.0):
- **Процентное распределение** для графиков (47% каждый в Dual Mode)
- **Минимальные отступы** между элементами (2px)
- **Адаптивность** к любым разрешениям экрана
- **Максимальное использование** доступного пространства

## 💡 Новая структура

### Single Mode
```
Меню (18px) → Панель (25px) → График (~96%) → Статусная строка (25px)
```

### Dual Mode
```
Меню (18px) → Панель 1 (25px) → График 1 (48%) → 
Панель 2 (25px) → График 2 (48%) → Статусная строка (25px)
```

## 🔧 Технические детали

### Новые константы (LayoutModule.h)

```cpp
// Фиксированные размеры
MENU_HEIGHT = 18           // Высота главного меню
PANEL_HEIGHT = 25          // Высота панели управления
STATUSBAR_HEIGHT = 25      // Высота статусной строки
MARGIN = 5                 // Боковые отступы
ELEMENT_SPACING = 2        // Минимальный отступ между элементами
MIN_CHART_HEIGHT = 100     // Минимальная высота графика

// Процентное распределение
CHART1_HEIGHT_PERCENT = 0.48f  // 48% для первого графика
CHART2_HEIGHT_PERCENT = 0.48f  // 48% для второго графика
```

### Удалённые константы
```cpp
MENU_AND_PANEL1_HEIGHT  // Заменено на MENU_HEIGHT + PANEL_HEIGHT
PANEL_SPACING           // Заменено на ELEMENT_SPACING
```

### Изменённые методы (LayoutModule.cpp)

**CalculateSingleChartLayout():**
- График занимает всё пространство между панелью и статусной строкой
- Минимальные отступы (2px)

**CalculateDualChartLayout():**
- Вычисляется доступная высота после вычета фиксированных элементов
- Каждый график получает 48% от доступной высоты (оптимизировано)
- Пропорции сохраняются при изменении размера окна

**GetChart2PanelY():**
- Использует `ELEMENT_SPACING` вместо `MARGIN`

## ✅ Преимущества

1. **Адаптивность к разрешениям**
   - Корректная работа на мониторах 1280x720, 1920x1080, 2560x1440 и выше
   - Автоматическое масштабирование при изменении размера окна

2. **Максимальное использование пространства**
   - Графики занимают 96% доступной высоты в Dual Mode
   - График занимает ~96% в Single Mode

3. **Минимальные отступы**
   - Всего 2px между элементами
   - Больше места для отображения данных

4. **Пропорциональность**
   - Соотношение размеров графиков сохраняется
   - Предсказуемое поведение на любых экранах

5. **Стабильность**
   - Устранены проблемы с перекрытием элементов
   - Надёжная работа на разных устройствах

## 🧪 Тестирование

Рекомендуется протестировать следующие сценарии:

1. **Изменение размера окна**:
   - Увеличение/уменьшение окна в Single Mode
   - Увеличение/уменьшение окна в Dual Mode
   - Убедиться, что графики масштабируются пропорционально

2. **Разные разрешения**:
   - 1280x720 (HD)
   - 1920x1080 (Full HD)
   - 2560x1440 (2K)
   - Убедиться, что интерфейс выглядит корректно

3. **Минимальный размер окна**:
   - Уменьшить окно до минимума (600x400)
   - Убедиться, что применяется MIN_CHART_HEIGHT

4. **Максимизация окна**:
   - Максимизировать окно
   - Убедиться, что графики занимают максимум пространства

5. **Переключение режимов**:
   - Single Mode → Dual Mode
   - Dual Mode → Single Mode
   - Убедиться в корректном пересчёте layout
