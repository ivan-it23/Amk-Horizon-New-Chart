# Release Notes - Version 2.7.1

**Дата релиза:** 17 ноября 2025

## 🎯 Основные изменения

### Упрощение интерфейса сохранения диапазона

В версии 2.7.1 удалена кнопка "Save Range" для второго графика (Chart 2) для устранения путаницы пользователей.

## 📊 Что изменилось

### Было (v2.7.0 и ранее):
- **Chart 1**: Кнопка "Save Range" в панели инструментов
- **Chart 2**: Кнопка "Save Range" рядом с элементами управления X Range

### Стало (v2.7.1):
- **Chart 1**: Кнопка "Save Range" в панели инструментов ← **БЕЗ ИЗМЕНЕНИЙ**
- **Chart 2**: Кнопка "Save Range" удалена ← **ИЗМЕНЕНО**

## 💡 Преимущества

1. **Устранение путаницы** - пользователи больше не нажимают случайно на кнопку другого графика
2. **Упрощение интерфейса** - меньше элементов управления для Chart 2
3. **Сохранение функциональности** - возможность сохранения диапазона для Chart 1 осталась без изменений

## 🔧 Технические детали

### Изменённые файлы:
- `UIModule.h` - удалено объявление `hSaveRange2Btn`
- `UIModule.cpp` - удалено создание, позиционирование и управление видимостью кнопки для Chart 2
- `Amk-Horizon-New-Chart.cpp` - удален обработчик команды `IDC_SAVE_RANGE2_BTN`
- `Resource.h` - ID 1037 зарезервирован (ранее использовался для `IDC_SAVE_RANGE2_BTN`)

### Удалённые элементы:
- Кнопка "Save Range" для Chart 2 (`hSaveRange2Btn`)
- Обработчик команды `IDC_SAVE_RANGE2_BTN` в главном цикле сообщений
- Вызовы `ShowWindow` и `SetWindowPos` для кнопки Chart 2

### Сохранённая функциональность:
- Кнопка "Save Range" для Chart 1 работает без изменений
- Метод `ChartManager::HandleSaveRange(hWnd, 1)` не затронут
- Логика сохранения диапазона данных полностью сохранена

## 📝 Обновлённая документация

- `README.md` - обновлена версия до 2.7.1, добавлена запись в историю изменений

## ✅ Тестирование

Рекомендуется протестировать следующие сценарии:

1. **Сохранение диапазона для Chart 1**:
   - Загрузить данные
   - Настроить X Range для Chart 1
   - Нажать "Save Range"
   - Убедиться, что файл сохраняется корректно

2. **Dual Mode**:
   - Включить Dual Mode
   - Убедиться, что кнопка "Save Range" отображается только для Chart 1
   - Убедиться, что для Chart 2 кнопка отсутствует

3. **Интерфейс Chart 2**:
   - Проверить, что элементы управления X Range для Chart 2 работают корректно
   - Убедиться, что отсутствие кнопки "Save Range" не влияет на другие элементы
