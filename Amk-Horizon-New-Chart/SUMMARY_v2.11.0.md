# 📋 Краткая сводка изменений v2.11.0

## Что изменилось?

### 1. Целочисленные подписи оси X
**Было:** 0.0, 12.5, 25.0, 37.5, 50.0  
**Стало:** 0, 13, 25, 38, 50

Все подписи оси X теперь отображаются как целые числа без дробной части.

**Устранение дубликатов:**
- **Было:** 415 416 416 417 417 418 418 419 (дубликаты при zoom)
- **Стало:** 415 416 417 418 419 (каждое значение один раз)
- Используется `std::set<int>` для отслеживания уже отрисованных значений

### 2. Ограничение минимального zoom
**Новое правило:** Нельзя приближать график больше, чем до диапазона в 10 точек

**Почему 10?**
- Обеспечивает, что подписи осей остаются целыми числами
- Гарантирует минимальный шаг между подписями = 1
- Предотвращает перекрытие подписей

### 3. Проверка в X Range Controls
При ручном вводе диапазона также проверяется минимум 10 точек.

**Примеры:**
- ✅ From: 0, To: 10 → OK (диапазон = 10)
- ✅ From: 100, To: 150 → OK (диапазон = 50)
- ❌ From: 0, To: 5 → Ошибка (диапазон = 5)
- ❌ From: 100, To: 108 → Ошибка (диапазон = 8)

## Где применяется?

- ✅ Frame Number режим (номера кадров)
- ✅ Temperature режим (температура)
- ✅ X Range Controls (поля ввода)
- ✅ Статусная строка (координата X)
- ✅ Zoom мышью
- ✅ Сообщения об ошибках

## Сообщения пользователю

### При zoom мышью (диапазон < 10):
```
Zoom Limit Reached

Cannot zoom further: X-axis labels must be integers with minimum spacing of 1.
Minimum range is 10 points.
```

### При X Range Apply (диапазон < 10):
```
X Range Error

Chart 1: X Range must be at least 10 points.
X-axis labels must be integers with minimum spacing of 1.
```

## Обоснование изменений

Эти изменения были внесены на основе обратной связи от сотрудников компании:

1. **Требование:** Ось X должна показывать только целые значения
2. **Требование:** Нельзя приближать больше, чем до уровня где подписи отличаются на 1
3. **Реализация:** Минимальный диапазон 10 точек обеспечивает оба требования
