# Улучшение: Изменение цвета выделения области при Zoom

## Дата
23 октября 2025

## Описание
Изменён цвет прямоугольника выделения области при использовании функции zoom на графиках с синего на оранжевый для улучшения видимости.

## Проблема
При выделении области курсором для увеличения (zoom) использовался синий цвет `RGB(0, 0, 255)`, который недостаточно контрастен и плохо виден на графиках, особенно когда на графике присутствуют синие кривые (например, T4).

## Решение
Изменён цвет и стиль прямоугольника выделения с добавлением диагональной штриховки:
- Цвет изменён на яркий оранжевый `RGB(255, 140, 0)` для рамки
- Добавлен пунктирный стиль линии для рамки
- Добавлена диагональная оранжевая штриховка для лучшей визуализации области
- Использован режим `R2_NOTXORPEN` для XOR эффекта без скрытия сетки графика
- Сохранён XOR подход для избежания мигания графиков

### Преимущества нового подхода
- Более яркий и контрастный оранжевый цвет
- Пунктирная рамка хорошо видна на любом фоне
- Диагональная штриховка четко показывает выделенную область
- Создаёт эффект полупрозрачности, не перекрывая данные полностью
- Не скрывает сетку графика внутри выделения
- Не конфликтует с цветами кривых T1-T4 (зелёный, жёлтый, красный, синий)
- Отсутствие мигания графиков при выделении (XOR режим)
- Плавная отрисовка без перерисовки всего графика
- Профессиональный внешний вид

## Технические детали

### Изменённые методы

#### ChartModule::DrawZoomRectangle()
**Было:**
```cpp
// R2_XORPEN режим с синим цветом, сплошная линия, без сетки
int oldROP = SetROP2(hdc, R2_XORPEN);
HPEN hPen = CreatePen(PS_SOLID, 2, RGB(0, 0, 255));
Rectangle(hdc, zoomRect.left, zoomRect.top, zoomRect.right, zoomRect.bottom);
```

**Стало:**
```cpp
// R2_NOTXORPEN режим с оранжевым цветом, пунктирная рамка + внутренняя сетка
int oldROP = SetROP2(hdc, R2_NOTXORPEN);

// Рамка
DWORD penStyle[2] = {8, 4}; // Пунктир: 8px линия, 4px пробел
HPEN hPen = ExtCreatePen(PS_GEOMETRIC | PS_USERSTYLE, 2, &lb, 2, penStyle);
Rectangle(hdc, zoomRect.left, zoomRect.top, zoomRect.right, zoomRect.bottom);

// Диагональная штриховка
HPEN hHatchPen = CreatePen(PS_DOT, 1, RGB(255, 165, 0));
int hatchSpacing = 15; // Расстояние между линиями
// Рисуем диагональные линии с шагом 15 пикселей
```

#### ChartManager::HandleMouseMove()
Восстановлен XOR подход для избежания мигания:
```cpp
// Стираем предыдущий прямоугольник через R2_NOT
chartModule->DrawZoomRectangle(hdc, oldZoomRect);
// Рисуем новый прямоугольник
chartModule->DrawZoomRectangle(hdc, newZoomRect);
```

#### ChartManager::HandleMouseUp()
Добавлено стирание последнего прямоугольника:
```cpp
// Стираем последний прямоугольник перед завершением
chartModule->DrawZoomRectangle(hdc, lastZoomRect);
```

### Характеристики

#### Рамка выделения
- **Толщина линии**: 2 пикселя
- **Цвет**: Яркий оранжевый `RGB(255, 140, 0)`
- **Стиль линии**: Пунктирная (8 пикселей линия, 4 пикселя пробел)

#### Диагональная штриховка
- **Толщина линии**: 1 пиксель
- **Цвет**: Светло-оранжевый `RGB(255, 165, 0)`
- **Стиль линии**: Точечная (`PS_DOT`)
- **Направление**: Диагональные линии слева-направо сверху-вниз (╱)
- **Шаг штриховки**: 15 пикселей между линиями
- **Условие отрисовки**: Только если область больше 40×40 пикселей

#### Общие параметры
- **Заливка**: Прозрачная (`NULL_BRUSH`)
- **Режим отрисовки**: `R2_NOTXORPEN` (XOR с инверсией для лучшей видимости)
- **Преимущества**: Отсутствие мигания, видна сетка графика, лучшая визуализация области

## Изменённые файлы
- **ChartModule.cpp** - метод `DrawZoomRectangle()` (изменён режим на `R2_NOT` и цвет на оранжевый)
- **ChartManager.cpp** - методы `HandleMouseMove()`, `HandleMouseUp()` (восстановлен XOR подход)

## Преимущества
1. **Улучшенная видимость** - оранжевый цвет более заметен на графиках
2. **Лучший контраст** - не конфликтует с цветами кривых
3. **Стандартизация** - соответствует общепринятым UI паттернам Windows
4. **Удобство использования** - пользователь чётко видит выделяемую область

## Визуальное сравнение

### До изменения
- Цвет: Синий `RGB(0, 0, 255)`
- Проблема: Плохо виден, особенно при наличии синих кривых

### После изменения
- Цвет: Оранжевый `RGB(255, 165, 0)`
- Результат: Яркий, контрастный, хорошо виден на любом фоне
