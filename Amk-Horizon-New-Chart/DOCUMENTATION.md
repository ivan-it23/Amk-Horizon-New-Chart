# 📚 Документация AMK-Horizon-New-Chart

## Структура документации

Проект содержит 5 основных документов, которые покрывают все аспекты работы с приложением:

### 1. 📖 [README.md](README.md)
**Главная документация проекта**

Содержит:
- Описание проекта и его назначение
- Архитектура приложения
- Основные возможности
- Краткую историю изменений
- Быстрый старт

**Для кого:** Все пользователи и разработчики

---

### 2. 📝 [CHANGELOG.md](CHANGELOG.md)
**Полная история изменений**

Содержит:
- Детальную историю всех версий
- Описание новых функций
- Исправления ошибок
- Улучшения интерфейса
- Технические изменения

**Для кого:** Пользователи, желающие узнать о новых возможностях

---

### 3. 👥 [USER_GUIDE.md](USER_GUIDE.md)
**Руководство пользователя**

Содержит:
- Подробное описание интерфейса
- Инструкции по работе с графиками
- Работа с Device Schematic
- Использование пресетов
- Советы по эффективной работе
- Устранение проблем

**Для кого:** Конечные пользователи приложения

---

### 4. 👨‍💻 [DEVELOPMENT_GUIDE.md](DEVELOPMENT_GUIDE.md)
**Руководство разработчика**

Содержит:
- Настройка среды разработки
- Архитектурные принципы
- Добавление новых функций
- Тестирование
- Отладка
- Процесс разработки
- Стандарты кодирования

**Для кого:** Разработчики, расширяющие функциональность

---

### 5. 🔧 [TECHNICAL_REFERENCE.md](TECHNICAL_REFERENCE.md)
**Техническая документация**

Содержит:
- Структуры данных
- API модулей
- Формулы преобразования
- Константы и параметры
- Форматы файлов
- Технические детали реализации

**Для кого:** Разработчики, работающие с кодом
