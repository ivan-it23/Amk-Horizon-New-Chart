# Исправления ошибок компиляции для Visual Studio 2017

## Проблема
При компиляции в Visual Studio 2017 возникали ошибки синтаксиса в ChartModule.cpp на строках 156-157, связанные с использованием `std::min` и `std::max`.

## Причина
Конфликт между макросами `min` и `max`, определенными в Windows.h, и функциями `std::min` и `std::max` из стандартной библиотеки C++.

## Исправления

### 1. Улучшен framework.h
```cpp
#ifndef NOMINMAX
#define NOMINMAX                        // Отключаем макросы min/max из Windows
#endif
```

### 2. Добавлен framework.h во все модули
- ChartModule.h/cpp
- DataModule.h/cpp  
- UIModule.h/cpp
- LayoutModule.h/cpp
- Amk-Horizon-New-Chart.h

### 3. Использованы безопасные вызовы функций
```cpp
// Вместо:
minVal = std::min(minVal, val);
maxVal = std::max(maxVal, val);

// Используется:
minVal = (std::min)(minVal, val);
maxVal = (std::max)(maxVal, val);
```

Скобки вокруг имени функции предотвращают их интерпретацию как макросы.

### 4. Правильный порядок подключения заголовков
1. framework.h (первым)
2. Заголовки модулей
3. Стандартные заголовки C++

## Результат
Все ошибки компиляции должны быть устранены. Проект должен успешно компилироваться в Visual Studio 2017.

## Рекомендации на будущее
- Всегда подключать framework.h первым в новых файлах
- Использовать скобки вокруг std::min/std::max при необходимости
- Проверять совместимость с макросами Windows при использовании стандартной библиотеки
