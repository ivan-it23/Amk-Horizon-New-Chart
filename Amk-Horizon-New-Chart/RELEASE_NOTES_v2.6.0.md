# 🚀 Релиз AMK-Horizon-New-Chart v2.6.0

**Дата релиза:** 3 ноября 2025

## 🎯 Основные изменения

### ✨ Частота в заголовке графика

Реализовано отображение частоты в заголовке графика вместо общей подписи "(Custom Curves)" для улучшения информативности и удобства анализа данных.

#### Что это значит для пользователей?

- **Информативные заголовки** - сразу видно на какой частоте (400 kHz или 2000 kHz) отображаются данные
- **Удобство в Dual Mode** - легко различать графики с разными частотами
- **Чистый интерфейс** - убрана избыточная подпись, заголовок содержит только полезную информацию
- **Быстрая идентификация** - не нужно открывать Device Schematic для проверки частоты

#### Примеры отображения

**До изменений:**
```
Chart 1 (Custom Curves)
Chart 2 (Custom Curves)
```

**После изменений:**
```
Chart 1 (400 kHz)
Chart 2 (2000 kHz)
```

**Без конфигурации:**
```
Chart 1
Chart 2
```

#### Технические детали

- **Источник данных**: Частота берется из конфигурации кривых, выбранной в Device Schematic
- **Автоматическое обновление**: Заголовок обновляется при изменении частоты в Device Schematic
- **Логика отображения**: 
  - Если есть кривые → показывается частота в скобках
  - Если нет кривых → показывается только номер графика без скобок

## 📊 Примеры использования

### Сценарий 1: Сравнение частот в Dual Mode
```
1. Включить Dual Mode
2. Chart 1: настроить на 400 kHz через Device Schematic
3. Chart 2: настроить на 2000 kHz через Device Schematic
4. Результат: Заголовки четко показывают "Chart 1 (400 kHz)" и "Chart 2 (2000 kHz)"
```

### Сценарий 2: Смена частоты
```
1. График настроен на 400 kHz
2. Открыть Device Schematic
3. Изменить частоту на 2000 kHz
4. Нажать Apply
5. Результат: Заголовок автоматически обновляется с "(400 kHz)" на "(2000 kHz)"
```

### Сценарий 3: Экспорт скриншотов
```
1. Настроить график на нужную частоту
2. Сделать скриншот
3. Результат: На скриншоте сразу видно частоту данных без дополнительных пометок
```
