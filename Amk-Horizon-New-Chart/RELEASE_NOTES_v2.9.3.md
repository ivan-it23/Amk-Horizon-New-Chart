# Release Notes - Version 2.9.3

**Дата релиза:** 19 ноября 2025

## 🎯 Основные изменения

### Максимальная компактность диалога Device Schematic

В версии 2.9.3 достигнута **максимальная компактность** диалогового окна Device Schematic через оптимизацию всех элементов интерфейса.

## 📊 Эволюция размеров


## 💡 Ключевые улучшения

### 1. Ультра-компактные элементы схемы
- **Размер кнопок**: 70×45 → 60×35 (экономия 29% площади)
- **Отступы между элементами**: 12px → 10px
- **Отступ до Silent**: 25px → 8px (68% уменьшение)
- **Все элементы остаются кликабельными**

### 2. Минимальные отступы рамки
- **FRAME_PADDING**: 15px → 4px (73% уменьшение)
- **Рамка плотно облегает элементы**
- **Современный минималистичный вид**

### 3. Оптимизированный список кривых
- **Размер**: 280×145 DLU (оптимальный баланс)
- **Высота ListView**: 130px (достаточно для 6-8 кривых)
- **Компактное расположение**

### 4. Компактные пресеты
- **Размер кнопок**: 55×16 DLU
- **Плотное расположение**: 6 кнопок в 125×90 DLU
- **Все функции доступны**

### 5. Максимальная экономия пространства
- **Окно**: 420×280 DLU (56% меньше оригинала)
- **Идеально для небольших мониторов**
- **Не перекрывает основное окно**
