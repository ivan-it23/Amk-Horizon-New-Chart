# Release Notes - Version 2.8.0

**Дата релиза:** 18 ноября 2025

## 🎯 Основные изменения

### Статусная строка с координатами курсора

В версии 2.8.0 добавлена статусная строка, которая отображает координаты курсора в реальном времени при наведении на график.

## 📊 Что нового

### Было (v2.7.1 и ранее):
- Координаты курсора не отображались
- Невозможно было точно определить значения на графике
- Приходилось визуально оценивать положение точек

### Стало (v2.8.0):
- **Статусная строка внизу окна** с 4 частями информации
- **X координата**: Номер точки данных
- **Y₁ координата**: Значение на левой оси (фазы в мдег)
- **Y₂ координата**: Значение на правой оси (амплитуды в мВ) - для двойных осей
- **Информация о файле**: Количество точек и имя файла

## 💡 Преимущества

1. **Точное определение координат** - не нужно визуально оценивать значения
2. **Поддержка двойных осей** - одновременное отображение Y₁ и Y₂
3. **Автоматическое форматирование** - координаты в физических единицах
4. **Информация о файле** - всегда видно количество точек и имя файла
5. **Не перекрывает графики** - корректное позиционирование с учётом layout

### Структура статусной строки:
```cpp
int statusBarParts[4] = { 150, 350, 550, -1 };
// Часть 0: X координата (0-150 пикселей)
// Часть 1: Y₁ координата (150-350 пикселей)
// Часть 2: Y₂ координата (350-550 пикселей)
// Часть 3: Информация о файле (550-конец)
```

### Формулы преобразования координат:
```cpp
// Экранные координаты → Координаты данных
dataX = minX + (double)relX / plotWidth * (maxX - minX);
dataY = maxY - (double)relY / plotHeight * (maxY - minY);
```

### Форматирование значений:
- **Фазы (mdeg)**: Целые числа - `%.0f mdeg`
- **Амплитуды (mV)**: 3 знака после запятой - `%.3f mV`
- **Отношения (V/V)**: 4 знака после запятой - `%.4f V/V`
- **Температура (°C)**: 2 знака после запятой - `%.2f °C`

## ✅ Тестирование

Рекомендуется протестировать следующие сценарии:

1. **Отображение координат для одной оси**:
   - Загрузить данные
   - Настроить график с одним типом данных (только фазы или только амплитуды)
   - Навести курсор на график
   - Убедиться, что координаты отображаются корректно

2. **Отображение координат для двойных осей**:
   - Настроить график с фазами и амплитудами
   - Навести курсор на график
   - Убедиться, что отображаются Y₁ (фазы) и Y₂ (амплитуды)

3. **Dual Mode**:
   - Включить Dual Mode
   - Навести курсор на Chart 1
   - Убедиться, что координаты обновляются
   - Навести курсор на Chart 2
   - Убедиться, что координаты обновляются для второго графика

4. **Информация о файле**:
   - Загрузить файл данных
   - Убедиться, что в статусной строке отображается количество точек и имя файла

5. **Изменение размера окна**:
   - Изменить размер окна
   - Убедиться, что статусная строка корректно позиционируется
   - Убедиться, что графики не перекрываются со статусной строкой

6. **Zoom и прокрутка**:
   - Применить zoom к графику
   - Навести курсор на увеличенную область
   - Убедиться, что координаты соответствуют увеличенному масштабу
