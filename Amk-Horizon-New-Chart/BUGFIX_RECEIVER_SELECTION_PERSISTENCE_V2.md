# Исправление: Сохранение выбора приёмников R1/R2 в Device Schematic

## Дата
23 октября 2025

## Проблема
При выборе приёмников R1 или R2 (по отдельности или вместе R1+R2) на схеме Device Schematic, они корректно выделялись как активные элементы. Однако при повторном открытии диалога Device Schematic приёмники R1/R2 не выделялись как активные, вместо них выделялись передатчики T1-T4.

### Причина проблемы
Когда пользователь выбирает приёмник R1 или R2, система генерирует кривые для **всех 4 передатчиков** (T1-T4) с данными для выбранного приёмника. При восстановлении конфигурации код анализировал кривые и видел:
- `sourceElement = TRANSMITTER` (для всех 4 передатчиков)
- Типы данных `AMPLITUDE_RX1/RX2` и `PHASE_RX1/RX2`

Старая логика ошибочно интерпретировала это как выбор передатчиков, а не приёмников.

### Ключевое отличие
- **Выбор приёмника R1/R2**: генерируются кривые для **ВСЕХ 4 передатчиков** (T1-T4)
- **Выбор передатчиков**: генерируются кривые только для **ВЫБРАННЫХ передатчиков**

## Решение

### Улучшенная логика восстановления выбора
В методе `SchematicModule::InitializeDialogControls()` добавлен подсчёт уникальных передатчиков в кривых:

```cpp
// Подсчитываем уникальные передатчики в кривых
std::set<int> uniqueTransmitters;

for (const auto& curve : existingConfig.curves) {
    if (curve.sourceElement == ElementType::TRANSMITTER) {
        uniqueTransmitters.insert(curve.elementIndex);
    }
}
```

### Правила определения выбора

1. **R1 + R2 (оба приёмника)**:
   - Есть кривые с типами `AMPLITUDE_RATIO` или `PHASE_DIFFERENCE`
   - Восстанавливаются оба приёмника

2. **Только R1**:
   - Есть только типы `AMPLITUDE_RX1` и `PHASE_RX1`
   - Кривые для **всех 4 передатчиков** (`uniqueTransmitters.size() == 4`)
   - Восстанавливается только R1

3. **Только R2**:
   - Есть только типы `AMPLITUDE_RX2` и `PHASE_RX2`
   - Кривые для **всех 4 передатчиков** (`uniqueTransmitters.size() == 4`)
   - Восстанавливается только R2

4. **Выбранные передатчики**:
   - Есть типы для обоих приёмников (`RX1` и `RX2`)
   - Кривые **не для всех 4 передатчиков** (`uniqueTransmitters.size() < 4`)
   - Восстанавливаются только выбранные передатчики

5. **Все 4 передатчика**:
   - Есть типы для обоих приёмников
   - Кривые для всех 4 передатчиков
   - Количество кривых >= 16 (4 передатчика × 2 приёмника × 2 типа данных)
   - Восстанавливаются все передатчики

## Изменённые файлы

### SchematicModule.cpp
- Добавлен `#include <set>` для использования `std::set`
- Улучшена логика в методе `InitializeDialogControls()`:
  - Добавлен подсчёт уникальных передатчиков
  - Добавлена проверка `uniqueTransmitters.size() == 4` для определения выбора приёмников
  - Добавлена обработка особого случая с 16+ кривыми

## Тестирование

### Сценарий 1: Выбор R1
1. Открыть Device Schematic
2. Выбрать приёмник R1
3. Отметить несколько кривых
4. Нажать Apply
5. Повторно открыть Device Schematic
6. **Ожидаемый результат**: R1 выделен как активный элемент

### Сценарий 2: Выбор R2
1. Открыть Device Schematic
2. Выбрать приёмник R2
3. Отметить несколько кривых
4. Нажать Apply
5. Повторно открыть Device Schematic
6. **Ожидаемый результат**: R2 выделен как активный элемент

### Сценарий 3: Выбор R1+R2
1. Открыть Device Schematic
2. Выбрать оба приёмника R1 и R2
3. Отметить несколько кривых (отношения/разности)
4. Нажать Apply
5. Повторно открыть Device Schematic
6. **Ожидаемый результат**: R1 и R2 выделены как активные элементы

### Сценарий 4: Выбор передатчиков (для проверки регрессии)
1. Открыть Device Schematic
2. Выбрать передатчики T1 и T3
3. Отметить несколько кривых
4. Нажать Apply
5. Повторно открыть Device Schematic
6. **Ожидаемый результат**: T1 и T3 выделены как активные элементы
