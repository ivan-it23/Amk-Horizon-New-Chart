# 🚀 Релиз AMK-Horizon-New-Chart v2.3.0

**Дата релиза:** 2 ноября 2025

## 🎯 Основные изменения

### ✨ Нормализация фазовых данных

Реализована нормализация фазовых данных в стандартный диапазон (-π, π] для корректного отображения циклических фазовых сигналов индукционного каротажа.

#### Что это значит для пользователей?

- **Плавные графики фаз** - больше нет резких скачков при переходе через границы ±180°
- **Корректное отображение** - циклические фазовые сигналы отображаются правильно
- **Улучшенный анализ** - легче анализировать фазовые характеристики приборов

#### Технические детали

- **Алгоритм**: `while (phase > π) phase -= 2π; while (phase ≤ -π) phase += 2π;`
- **Применено к**:
  - Phase Difference (разности фаз R2-R1)
  - Phase RX1 (фазы приемника 1)
  - Phase RX2 (фазы приемника 2)
- **Для всех передатчиков**: T1, T2, T3, T4
- **Для обеих частот**: 400 kHz и 2000 kHz

#### Физический смысл

Фаза является циклической величиной:
- 370° = 10° (370° - 360° = 10°)
- -370° = -10° (-370° + 360° = -10°)

Нормализация приводит все значения к стандартному диапазону (-180°, +180°], что устраняет артефакты на графиках.

## 📊 Примеры

### До нормализации
```
Исходные данные: 4.5 рад, -5.2 рад, 0.5 рад
Отображение: 257800 мдег, -297900 мдег, 28648 мдег
Проблема: Резкие скачки на графике
```

### После нормализации
```
Исходные данные: 4.5 рад, -5.2 рад, 0.5 рад
Нормализация: -1.78 рад, 1.08 рад, 0.5 рад
Отображение: -102204 мдег, 62096 мдег, 28648 мдег
Результат: Плавный график без скачков
```

## 🔧 Изменения в коде

### Новые методы
- `DataModule::NormalizePhase(float phaseRadians)` - нормализация фазы в диапазон (-π, π]

### Модифицированные методы
- `DataModule::CalculateChartData()` - применена нормализация для PHASE_DIFFERENCE, PHASE_RX1, PHASE_RX2
- `DataModule::CalculateDifferenceData()` - применена нормализация для разностей фаз
- `DataModule::CalculatePhaseData()` - применена нормализация для фаз приемников
