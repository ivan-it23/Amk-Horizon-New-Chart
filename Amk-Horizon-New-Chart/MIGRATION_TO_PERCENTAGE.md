# Миграция на процентное распределение - v2.9.0

## 📋 Краткая сводка изменений

### Что было изменено

**LayoutModule.h:**
- ✅ Добавлены новые константы: `MENU_HEIGHT`, `ELEMENT_SPACING`
- ✅ Добавлены процентные константы: `CHART1_HEIGHT_PERCENT`, `CHART2_HEIGHT_PERCENT`
- ❌ Удалены: `MENU_AND_PANEL1_HEIGHT`, `PANEL_SPACING`
- 🔄 Изменены: `PANEL_HEIGHT` (40 → 25px)

**LayoutModule.cpp:**
- 🔄 `CalculateSingleChartLayout()` - новая логика с минимальными отступами
- 🔄 `CalculateDualChartLayout()` - процентное распределение высоты
- 🔄 `GetChart2PanelY()` - использует `ELEMENT_SPACING`

**UIModule.cpp:**
- 🔄 Y-координаты элементов управления: 30 → 20px

## 🎯 Ключевые улучшения

### 1. Адаптивность
Графики автоматически масштабируются при изменении размера окна.

### 2. Универсальность
Корректная работа на любых разрешениях экрана (от 1280x720 до 4K).

### 3. Минимальные отступы
Всего 2px между элементами вместо 3-5px.

### 4. Максимальное использование пространства
- Single Mode: ~95% высоты для графика
- Dual Mode: 47% + 47% = 94% для графиков

## 📊 Сравнение подходов

### Старый подход (v2.8.1)
```cpp
// Фиксированные пиксели
MENU_AND_PANEL1_HEIGHT = 48px
PANEL_HEIGHT = 40px
PANEL_SPACING = 3px

// Расчёт
chartHeight = (windowHeight - fixed) / 2
```

### Новый подход (v2.9.0)
```cpp
// Фиксированные + проценты
MENU_HEIGHT = 20px
PANEL_HEIGHT = 25px
ELEMENT_SPACING = 2px
CHART_HEIGHT_PERCENT = 0.47

// Расчёт
availableHeight = windowHeight - fixed
chartHeight = availableHeight * 0.47
```
