# Release Notes - Version 2.9.4

**Дата релиза:** 19 ноября 2025

## 🎯 Основные изменения

### Немодальное окно Device Schematic

В версии 2.9.4 окно Device Schematic преобразовано из **модального** в **немодальное**, что значительно улучшает удобство работы при частом переключении между комбинациями кривых.

## 📊 Что изменилось

### Было (v2.9.3 и ранее):
- **Модальное окно** - блокировало основное окно
- **Закрывалось после Apply** - нужно было заново открывать
- **Нет иконки в панели задач** - только основное окно
- **Нельзя свернуть** - только закрыть

### Стало (v2.9.4):
- **Немодальное окно** - не блокирует основное окно
- **Остаётся открытым после Apply** - можно сразу менять настройки
- **Иконка в панели задач** - отдельная иконка рядом с основным окном
- **Можно свернуть** - сворачивается в панель задач

## 💡 Ключевые улучшения

### 1. Окно не закрывается после Apply
**Проблема:** Раньше после нажатия "Apply" окно закрывалось, и для выбора другой комбинации кривых нужно было заново открывать Device Schematic.

**Решение:** Окно теперь остаётся открытым после применения настроек.

**Преимущества:**
- Быстрое переключение между комбинациями кривых
- Не нужно постоянно открывать/закрывать окно
- Экономия времени при анализе данных

### 2. Возможность сворачивания
**Новая функция:** Окно Device Schematic можно свернуть в панель задач Windows.

**Как использовать:**
- Нажмите кнопку "Свернуть" (минимизировать) в заголовке окна
- Окно свернётся в панель задач
- Кликните на иконку в панели задач для разворачивания

**Преимущества:**
- Освобождение места на экране
- Быстрый доступ к окну через панель задач
- Удобная работа на небольших мониторах

### 3. Иконка в панели задач
**Новая функция:** Device Schematic отображается как отдельное окно в панели задач.

**Что видно:**
```
[Основное окно] [Device Schematic - Chart 1]
```

**Преимущества:**
- Наглядность - видно оба окна
- Быстрое переключение через Alt+Tab
- Удобная навигация между окнами

### 4. Свободное переключение между окнами
**Новая функция:** Можно работать с обоими окнами одновременно.

**Возможности:**
- Настраивать кривые в Device Schematic
- Одновременно смотреть на график в основном окне
- Переключаться между окнами без ограничений

### 5. Кнопка Cancel скрывает окно
**Изменение:** Кнопка "Cancel" теперь скрывает окно вместо закрытия.

**Преимущества:**
- Быстрое возвращение к окну
- Сохранение текущих настроек
- Не нужно заново инициализировать окно

## 🔧 Технические детали

### Архитектурные изменения

#### 1. Переход на немодальное окно

**Было (модальное):**
```cpp
INT_PTR result = DialogBoxParam(hInst, MAKEINTRESOURCE(IDD_SCHEMATIC_DIALOG), 
                               parent, SchematicDialogProc, (LPARAM)this);
```

**Стало (немодальное):**
```cpp
hSchematicDialog = CreateDialogParam(hInst, MAKEINTRESOURCE(IDD_SCHEMATIC_DIALOG), 
                                    parent, SchematicDialogProc, (LPARAM)this);
ShowWindow(hSchematicDialog, SW_SHOW);
```

#### 2. Новые методы управления окном

**SchematicModule.h:**
```cpp
class SchematicModule {
private:
    HWND hSchematicDialog;    // Handle немодального окна
    HWND hParentWindow;       // Handle родительского окна
    
public:
    void ShowSchematicDialog(HWND parent, int chartNumber);  // Показать/активировать
    void HideSchematicDialog();                              // Скрыть окно
    void CloseSchematicDialog();                             // Закрыть окно
    bool IsSchematicDialogVisible() const;                   // Проверка видимости
    HWND GetSchematicDialogHandle() const;                   // Получить handle
};
```

#### 3. Изменения в стиле окна

**Amk-Horizon-New-Chart.rc:**
```cpp
// Было:
STYLE DS_SETFONT | DS_MODALFRAME | DS_FIXEDSYS | WS_POPUP | WS_CAPTION | WS_SYSMENU

// Стало:
STYLE DS_SETFONT | DS_FIXEDSYS | WS_POPUP | WS_CAPTION | WS_SYSMENU | WS_MINIMIZEBOX | WS_VISIBLE
EXSTYLE WS_EX_APPWINDOW
```

**Изменения:**
- Удалён `DS_MODALFRAME` - окно больше не модальное
- Добавлен `WS_MINIMIZEBOX` - кнопка сворачивания
- Добавлен `WS_VISIBLE` - окно видимо при создании
- Добавлен `WS_EX_APPWINDOW` - иконка в панели задач

#### 4. Обработка событий

**SchematicDialogProc:**
```cpp
case WM_CLOSE:
    // Скрываем окно вместо закрытия
    if (pSchematic) {
        pSchematic->HideSchematicDialog();
    }
    return (INT_PTR)TRUE;

case WM_DESTROY:
    // Очищаем указатель при уничтожении
    SetWindowLongPtr(hDlg, GWLP_USERDATA, 0);
    return (INT_PTR)TRUE;

case IDC_APPLY_SETTINGS:
    // НЕ закрываем окно после Apply
    if (pSchematic->ApplyCurrentCurveConfiguration()) {
        // Окно остаётся открытым
    }
    return (INT_PTR)TRUE;

case IDCANCEL:
    // Скрываем окно вместо закрытия
    if (pSchematic) {
        pSchematic->HideSchematicDialog();
    }
    return (INT_PTR)TRUE;
```

## 🎨 Сценарии использования

### Сценарий 1: Быстрое переключение кривых
```
1. Открыть Device Schematic
2. Выбрать комбинацию кривых #1
3. Нажать Apply → график обновился, окно осталось открытым
4. Выбрать комбинацию кривых #2
5. Нажать Apply → график обновился, окно осталось открытым
6. Повторить для других комбинаций
```

### Сценарий 2: Работа с двумя окнами
```
1. Открыть Device Schematic
2. Расположить окна рядом (основное + Device Schematic)
3. Настраивать кривые и сразу видеть результат на графике
4. Переключаться между окнами по необходимости
```

### Сценарий 3: Сворачивание окна
```
1. Открыть Device Schematic
2. Настроить кривые и применить
3. Свернуть Device Schematic в панель задач
4. Работать с основным окном
5. При необходимости развернуть Device Schematic из панели задач
```

## 🧪 Тестирование

Рекомендуется протестировать:

1. **Открытие окна**:
   - Нажать "Device Schematic"
   - Убедиться, что окно открылось
   - Проверить иконку в панели задач

2. **Применение настроек**:
   - Выбрать кривые
   - Нажать "Apply"
   - Убедиться, что окно НЕ закрылось
   - Проверить, что график обновился

3. **Сворачивание**:
   - Нажать кнопку "Свернуть"
   - Убедиться, что окно свернулось в панель задач
   - Кликнуть на иконку для разворачивания

4. **Кнопка Cancel**:
   - Нажать "Cancel"
   - Убедиться, что окно скрылось
   - Открыть снова - настройки сохранились

5. **Переключение между окнами**:
   - Открыть Device Schematic
   - Переключиться на основное окно
   - Вернуться к Device Schematic
   - Убедиться в корректной работе

6. **Alt+Tab**:
   - Открыть Device Schematic
   - Нажать Alt+Tab
   - Убедиться, что видны оба окна
