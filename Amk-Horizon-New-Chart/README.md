# AMK-Horizon-New-Chart

**Версия:** 2.9.3  
**Дата релиза:** 19 ноября 2025

## 📋 Описание проекта

AMK-Horizon-New-Chart - это Windows-приложение для визуализации и анализа данных геофизических приборов. Приложение предназначено для отображения многоканальных данных в виде интерактивных графиков с поддержкой различных типов измерений (амплитуды в милливольтах, фазы в миллиградусах, отношения, разности).

## 🎯 Назначение

Приложение используется для:
- **Визуализации данных** с геофизических приборов в реальном времени
- **Анализа многоканальных измерений** (T1-T4 передатчики, R1-R2 приемники)
- **Сравнения различных типов данных** (амплитуды, фазы, отношения, разности)
- **Интерактивного масштабирования** и навигации по данным
- **Настройки отображения** через схему прибора

## 🏗️ Архитектура

Проект построен на **модульной архитектуре** с четким разделением ответственности:


### Основные модули:

- **DataModule** - управление данными прибора
- **ChartModule** - отрисовка графиков и визуализация
- **UIModule** - пользовательский интерфейс

- **SchematicModule** - схема прибора и выбор элементов
- **CurveSelectionModule** - управление кривыми и пресетами

## 🚀 Основные возможности

### 📊 Визуализация данных
- **Одиночный и двойной режимы** отображения графиков
- **Многоканальные данные** (T1-T4 передатчики)
- **Различные типы измерений**:
  - Phase Difference (разности фаз в миллиградусах, мдег)
  - Amplitude Ratio (отношения амплитуд, безразмерные)
  - Amplitude RX1/RX2 (амплитуды приемников в милливольтах, мВ)
  - Phase RX1/RX2 (фазы приемников в миллиградусах, мдег)
  - Silent Amplitude (амплитуды молчащих передатчиков в мВ)
  - Temperature (температура)
- **Физические единицы измерения**:
  - Амплитуды: милливольты (мВ) - преобразование из сырых данных АЦП
  - Фазы: миллиградусы (мдег) - преобразование из радианов для удобства анализа

### 🎛️ Интерактивность
- **Масштабирование** областей графика (zoom)
- **Прокрутка** по горизонтали
- **Переключение каналов** через чекбоксы в легенде
- **Сброс масштаба** правой кнопкой мыши

### ⚙️ Настройка через схему прибора
- **Визуальная схема** с элементами T1-T4, R1-R2, Silent
- **Быстрые пресеты**:
  - All Ampl R1/R2 - все амплитуды для приемника
  - All Phase R1/R2 - все фазы для приемника
  - Ampl Ratios - отношения амплитуд
  - Phase Diff - разности фаз
- **Копирование настроек** между графиками
- **Выбор частоты** (400 kHz / 2000 kHz)

### 📈 Система кривых
- **Автоматическое определение** доступных кривых
- **Двойные оси** для разных типов данных
- **Цветовое кодирование** каналов
- **Легенда** с единицами измерения

## 🔧 Технические детали

### Платформа
- **Windows API** (Win32)
- **Visual C++** (MSVC)
- **GDI** для отрисовки графиков

### Форматы данных
- **Бинарные файлы** с структурой `GP_TOOL_DATA`
- **Многоканальные измерения** (10 каналов)
- **Поддержка двух частот** (400 kHz, 2000 kHz)

### Структура данных
```cpp
struct GP_TOOL_DATA {
    float AM_RX_1[10];    // Амплитуды приемника 1
    float AM_RX_2[10];    // Амплитуды приемника 2
    float PH_RX_1[10];    // Фазы приемника 1
    float PH_RX_2[10];    // Фазы приемника 2
    float temperature;    // Температура
};
```

## 🚀 Быстрый старт

### Сборка проекта
1. Откройте `Amk-Horizon-New-Chart.vcxproj` в Visual Studio
2. Выберите конфигурацию Debug/Release x64
3. Соберите проект (Build → Build Solution)

### Запуск
1. Запустите `Amk-Horizon-New-Chart.exe`
2. Загрузите файл данных (File → Open Data File)
3. Настройте отображение через Device Schematic
4. Используйте быстрые пресеты или настройте кривые вручную
