# ✨ Все кривые включены по умолчанию - Версия 2.6.4

**Дата**: 6 ноября 2025  
**Версия**: 2.6.4

## 📋 Описание улучшения

### Проблема
При первоначальном выборе элемента на схеме прибора (например, передатчика T1) в Device Schematic включались только амплитудные кривые, а фазовые кривые были выключены. Пользователю приходилось вручную включать фазы, что было неудобно.

**Пример (до изменений):**
При выборе передатчика T1:
- ☑ T1 Amplitude R1 (mV) [Left Axis] - включено
- ☐ T1 Phase R1 (mdeg) [Right Axis] - **выключено** ❌
- ☑ T1 Amplitude R2 (mV) [Left Axis] - включено
- ☐ T1 Phase R2 (mdeg) [Right Axis] - **выключено** ❌

### Решение
Изменено значение по умолчанию для фазовых кривых с `enabled = false` на `enabled = true`. Теперь при первоначальном выборе элемента **все кривые** (и амплитуды, и фазы) включены по умолчанию.

**Пример (после изменений):**
При выборе передатчика T1:
- ☑ T1 Amplitude R1 (mV) [Left Axis] - включено
- ☑ T1 Phase R1 (mdeg) [Right Axis] - **включено** ✅
- ☑ T1 Amplitude R2 (mV) [Left Axis] - включено
- ☑ T1 Phase R2 (mdeg) [Right Axis] - **включено** ✅

## 🔧 Техническая реализация

### Изменённый метод

#### AddTransmitterCurves()
**Было:**
```cpp
phaseCurve.enabled = false; // По умолчанию отключена
```

**Стало:**
```cpp
phaseCurve.enabled = true; // По умолчанию включена (как и амплитуды)
```

### Применяется к
- **Передатчики** (T1-T4) - при выборе передатчика все его кривые (амплитуды и фазы для R1 и R2) включены
- **Приёмники** (R1, R2) - при выборе приёмника все кривые (амплитуды и фазы для T1-T4) уже были включены
- **Молчащие передатчики** - только амплитуды (фаз нет)

### Сохранение выбора
**Важно**: Сохранение выбора кривых работает корректно и не изменено:
- Если пользователь отключил какие-то кривые и нажал Apply
- При повторном открытии Device Schematic восстанавливаются его настройки
- Изменение применяется **только при первоначальном выборе** элемента

## ✅ Преимущества

### 1. Удобство использования
- Не нужно вручную включать фазы при каждом новом выборе
- Все данные доступны сразу
- Меньше кликов для настройки

### 2. Логичное поведение
- Фазы так же важны, как и амплитуды
- Все кривые равноценны по умолчанию
- Пользователь сам решает, что отключить

### 3. Согласованность
- Приёмники (R1, R2) уже включали все кривые по умолчанию
- Теперь передатчики (T1-T4) ведут себя так же
- Единообразное поведение для всех элементов

### 4. Сохранение гибкости
- Пользователь может отключить ненужные кривые
- Настройки сохраняются при повторном открытии
- Полный контроль над отображением
