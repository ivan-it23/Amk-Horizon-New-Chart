## 🔧 Технические изменения:

### 1. UIModule.h
**Удалено:**
- Поля для хранения HWND комбобоксов и кнопок Refresh
- Поля для хранения `chart1DataType`, `chart2DataType`, `chart1Frequency`, `chart2Frequency`
- Методы для работы с комбобоксами

**Оставлено:**
- Поля для `hDualModeCheck`, `hChart1SchematicBtn`, `hChart2SchematicBtn`
- Методы для работы со скроллбарами
- Поля `chart1EnabledTransmitters` и `chart2EnabledTransmitters` (для совместимости)

### 2. UIModule.cpp
**Изменено:**
- Конструктор: удалена инициализация ненужных полей
- `CreateControls()`: создаются только Dual Mode и кнопки Device Schematic
- `UpdateControlsVisibility()`: управляет только видимостью кнопки Device Schematic для Chart 2
- `PositionChart2Controls()`: позиционирует только кнопку Device Schematic для Chart 2
- `HandleCommand()`: удалена обработка комбобоксов и кнопок Refresh

**Удалено:**
- Методы `PopulateComboBoxes()`, `SetInitialValues()`
- Методы `RefreshChart1Settings()`, `RefreshChart2Settings()`
- Методы `SetChart1DataType()`, `SetChart1Frequency()`, `SetChart2DataType()`, `SetChart2Frequency()`

### 3. ChartManager.cpp
**Изменено:**
- `HandleCommand()`: удалена обработка `IDC_CHART1_DATA_COMBO`, `IDC_CHART1_FREQ_COMBO`, `IDC_CHART1_REFRESH_BTN`
- `HandleCommand()`: удалена обработка `IDC_CHART2_DATA_COMBO`, `IDC_CHART2_FREQ_COMBO`, `IDC_CHART2_REFRESH_BTN`
- Удалены вызовы `HandleLegacyUIChange()` (метод больше не нужен)

### 4. Resource.h
**Изменено:**
- Закомментированы ID удаленных элементов управления:
  - `IDC_CHART1_DATA_COMBO` (1002)
  - `IDC_CHART1_FREQ_COMBO` (1003)
  - `IDC_CHART1_REFRESH_BTN` (1004)
  - `IDC_CHART2_DATA_COMBO` (1005)
  - `IDC_CHART2_FREQ_COMBO` (1006)
  - `IDC_CHART2_REFRESH_BTN` (1007)
