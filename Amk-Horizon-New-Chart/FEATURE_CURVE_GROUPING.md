# ✨ Новая функция: Группировка кривых по элементам

## 📅 Дата реализации
16 октября 2025

---

## 🎯 Цель

Улучшить визуальное представление кривых в Device Schematic путём группировки по элементам (T1-T4, R1-R2, Silent) для лучшей читаемости и удобства выбора.

---

## 📋 Описание проблемы

### До изменений:
Когда выбрано несколько элементов (например, T2 + T4), все кривые отображались в одной колонке без визуального разделения:

```
Available Curves
☑ T2 Amplitude R1 (V) [Left Axis]
☑ T2 Amplitude R2 (V) [Left Axis]
☑ T2 Phase R1 (deg) [Right Axis]
☑ T2 Phase R2 (deg) [Right Axis]
☑ T4 Amplitude R1 (V) [Left Axis]
☑ T4 Amplitude R2 (V) [Left Axis]
☑ T4 Phase R1 (deg) [Right Axis]
☑ T4 Phase R2 (deg) [Right Axis]
```

**Проблемы:**
- ❌ Сложно различить кривые разных элементов
- ❌ Нет визуального разделения между T2 и T4
- ❌ Неудобно выбирать кривые для конкретного элемента

---

## ✅ Решение

Использование **ListView Groups** (группировка Windows ListView) для визуального разделения кривых по элементам.

### После изменений:

```
Available Curves
├─ ▼ T2
│  ☑ Amplitude R1 (V) [Left Axis]
│  ☑ Amplitude R2 (V) [Left Axis]
│  ☑ Phase R1 (deg) [Right Axis]
│  ☑ Phase R2 (deg) [Right Axis]
│
└─ ▼ T4
   ☑ Amplitude R1 (V) [Left Axis]
   ☑ Amplitude R2 (V) [Left Axis]
   ☑ Phase R1 (deg) [Right Axis]
   ☑ Phase R2 (deg) [Right Axis]
```

**Преимущества:**
- ✅ Чёткое визуальное разделение между элементами
- ✅ Каждая кривая имеет свой чекбокс
- ✅ Группы можно сворачивать/разворачивать
- ✅ Легко найти нужные кривые

---

## 🔧 Технические детали

### Логика группировки

#### Случай 1: Несколько передатчиков (T1-T4)
**Выбраны T2 + T4:**
- Группа "T2" с 4 кривыми (2 амплитуды + 2 фазы)
- Группа "T4" с 4 кривыми (2 амплитуды + 2 фазы)
- **Итого:** 2 группы, 8 чекбоксов

#### Случай 2: Один приемник (R1 или R2)
**Выбран R1:**
- Без группировки (одна колонка)
- 8 кривых (4 амплитуды T1-T4 + 4 фазы T1-T4)
- **Итого:** 8 чекбоксов

#### Случай 3: Два приемника (R1 + R2)
**Выбраны R1 + R2:**
- Без группировки (одна колонка)
- 8 кривых (4 Ratios + 4 Differences)
- **Итого:** 8 чекбоксов

#### Случай 4: Несколько приемников с передатчиками
**Выбраны T1 + T2 + T3:**
- Группа "T1" с кривыми
- Группа "T2" с кривыми
- Группа "T3" с кривыми
- **Итого:** 3 группы

## 📝 Изменения в коде

### Файл: `SchematicModule.cpp`

#### Метод `UpdateAvailableCurves()`

**Добавлено:**
1. Включение группировки ListView:
```cpp
ListView_EnableGroupView(hCurveList, TRUE);
```

2. Создание групп для каждого элемента:
```cpp
LVGROUP group = {};
group.cbSize = sizeof(LVGROUP);
group.mask = LVGF_HEADER | LVGF_GROUPID | LVGF_STATE;
group.pszHeader = groupHeader.c_str(); // "T1", "T2", "R1" и т.д.
group.iGroupId = groupIndex;
group.state = LVGS_NORMAL | LVGS_COLLAPSIBLE;

ListView_InsertGroup(hCurveList, groupIndex, &group);
```

3. Добавление кривых в группы:
```cpp
LVITEM item = {};
item.mask = LVIF_TEXT | LVIF_PARAM | LVIF_GROUPID;
item.iGroupId = groupIndex; // Привязка к группе
item.pszText = displayText.c_str();
item.lParam = curveIdx;

ListView_InsertItem(hCurveList, &item);
ListView_SetCheckState(hCurveList, itemIndex, curve.enabled);
```

**Логика:**
- Если выбран 1 элемент → без группировки
- Если выбраны R1 + R2 → без группировки (Ratios & Differences)
- Если выбрано 2+ элемента → с группировкой
