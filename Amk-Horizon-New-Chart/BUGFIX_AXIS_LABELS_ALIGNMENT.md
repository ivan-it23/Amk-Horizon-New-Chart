# Исправление: Выравнивание подписей левой оси Y

## Дата
2 ноября 2025

## Описание
Исправлена проблема с отображением подписей левой оси Y после преобразования единиц измерения в милливольты и миллиградусы. Длинные числовые значения теперь корректно помещаются в отведённую область.

## Проблема
После преобразования единиц измерения:
- Амплитуды: В → мВ (значения стали меньше, но всё равно могут быть длинными)
- Фазы: рад → мдег (значения стали очень большими: -180000, -90000, 90000, 180000)

**Проблема с левой осью Y:**
- Подписи отрисовывались с фиксированным отступом `-40` от `plotRect.left`
- При увеличении `plotRect.left` с 50 до 80 пикселей, подписи остались на том же месте
- Длинные значения не использовали всё доступное пространство (80 пикселей)
- Подписи располагались слишком близко к оси Y и обрезались

### Визуализация проблемы:
```
[Граница chart] <----80px отступ----> [Ось Y] [График]
                              ^
                              |
                    Подписи здесь (слишком близко)
                    "-180000" обрезается
```

## Решение

### Оптимальный подход: Вычисление ширины текста
Использование `GetTextExtentPoint32()` для вычисления ширины текста и ручного позиционирования.

**Преимущества:**
- ✅ Текст прижимается к оси Y справа (заканчивается в 5 пикселях от оси)
- ✅ Длинные числа используют всё доступное пространство слева
- ✅ Универсальное решение для любых значений
- ✅ Профессиональный внешний вид
- ✅ Не зависит от состояния контекста устройства (DC)

### Визуализация решения:
```
[Граница chart] <----80px отступ----> [Ось Y] [График]
    ^
    |
Подписи используют всё пространство
"-180000" полностью помещается
```

## Технические детали

### Изменённые файлы

#### ChartModule.cpp

**Метод `DrawGridAndAxes()` - подписи левой оси Y:**
```cpp
// Было:
std::wstringstream ssY;
ssY << std::fixed << std::setprecision(1) << currentYVal;
std::wstring yLabel = ssY.str();
TextOut(hdc, plotRect.left - 40, screenY - 7, yLabel.c_str(), (int)yLabel.length());

// Стало:
std::wstringstream ssY;
ssY << std::fixed << std::setprecision(1) << currentYVal;
std::wstring yLabel = ssY.str();

// Вычисляем ширину текста для правильного выравнивания
SIZE textSize;
GetTextExtentPoint32(hdc, yLabel.c_str(), (int)yLabel.length(), &textSize);

// Рисуем текст так, чтобы он заканчивался в 5 пикселях от оси
int textX = plotRect.left - 5 - textSize.cx;
TextOut(hdc, textX, screenY - 7, yLabel.c_str(), (int)yLabel.length());
```

**Метод `DrawLeftAxis()` - подписи левой оси для двойных осей:**

### Изменения позиции отрисовки:

| Метод | Было | Стало | Изменение |
|-------|------|-------|-----------|
| `DrawGridAndAxes()` | `plotRect.left - 40` | `plotRect.left - 5 - textWidth` | Вычисление ширины текста |
| `DrawLeftAxis()` | `plotRect.left - 45` | `plotRect.left - 5 - textWidth` | Вычисление ширины текста |

### Как работает GetTextExtentPoint32:

```cpp
SIZE textSize;
GetTextExtentPoint32(hdc, label.c_str(), (int)label.length(), &textSize);
int textX = plotRect.left - 5 - textSize.cx;
TextOut(hdc, textX, screenY - 7, label.c_str(), (int)label.length());
```

- **GetTextExtentPoint32()** - вычисляет размеры текста в пикселях
- **textSize.cx** - ширина текста в пикселях
- **textSize.cy** - высота текста в пикселях
- **Результат**: Текст рисуется так, что его правый край находится в 5 пикселях от оси

### Пример:
```cpp
// Текст "-180000" имеет ширину, например, 50 пикселей
SIZE textSize;
GetTextExtentPoint32(hdc, L"-180000", 7, &textSize); // textSize.cx = 50

// Ось Y находится в позиции plotRect.left = 100
// Хотим, чтобы текст заканчивался в 5 пикселях от оси (X = 95)
int textX = 100 - 5 - 50 = 45; // Текст начинается с X=45

TextOut(hdc, 45, 50, L"-180000", 7);
// Результат: "-180000" начинается с X=45 и заканчивается в X=95 (5 пикселей от оси)
```
