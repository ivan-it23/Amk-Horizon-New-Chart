# 📊 Горизонтальная легенда графиков - Версия 2.4.0

## 📋 Обзор

Данный документ описывает реализацию горизонтального расположения легенды графиков с выравниванием по центру для улучшения читаемости и предотвращения перекрытия данных.

## 🎯 Назначение

### Проблема
При отображении графиков с большим количеством кривых (особенно при использовании Device Schematic с несколькими передатчиками и приемниками) вертикальная легенда в правом верхнем углу:
- **Перекрывала данные графика** - легенда закрывала важные участки кривых
- **Затрудняла чтение** - трудно было различить, какой цвет к какой кривой относится
- **Занимала много места** - вертикальный список требовал значительного пространства

### Решение
Реализовано горизонтальное расположение легенды с выравниванием по центру:
- Легенда размещается **вверху графика** между заголовком и областью данных
- Элементы располагаются **горизонтально** (в строку)
- **Центрирование** - подписи равномерно распределены по ширине графика
- **Автоматический перенос** - при необходимости элементы переносятся на следующую строку

## 🔧 Техническая реализация

### Изменения в методах

#### 1. DrawChartLegend() - обычные графики

**Было (вертикально справа):**
```cpp
int legendX = rect.right - 200; // Справа
int legendY = rect.top + 10;
int currentX = legendX;

// Элементы в одну строку справа
for (channelIdx...) {
    // Рисуем элемент
    currentX += elementWidth + spacing;
}
```

**Стало (горизонтально по центру):**
```cpp
// Вычисляем общую ширину всех элементов
int totalWidth = 0;
for (channelIdx...) {
    totalWidth += elementWidth + spacing;
}

// Центрируем
int chartWidth = rect.right - rect.left;
int startX = rect.left + (chartWidth - totalWidth) / 2;
int legendY = rect.top + 35; // Под заголовком

// Рисуем элементы горизонтально
int currentX = startX;
for (elem...) {
    // Рисуем элемент
    currentX += elem.width + spacing;
}
```

#### 2. DrawDualAxisLegend() - графики с двойными осями

**Было (вертикально справа с группировкой):**
```cpp
int legendX = rect.right - 250;
int currentY = legendY;

// Группа "Left Axis"
TextOut("Left Axis:");
for (leftCurve...) {
    // Рисуем элемент
    currentY += lineHeight;
}

// Группа "Right Axis"
TextOut("Right Axis:");
for (rightCurve...) {
    // Рисуем элемент
    currentY += lineHeight;
}
```

**Стало (горизонтально по центру с разделителями и подписями осей):**
```cpp
// Получаем единицы измерения для каждой оси
std::string leftUnits = leftAxisCurves[0]->units;  // "mV"
std::string rightUnits = rightAxisCurves[0]->units; // "mdeg"

// Формируем подписи осей
std::wstring leftAxisLabel = L"[Left Axis (" + leftUnits + L")]";
std::wstring rightAxisLabel = L"[Right Axis (" + rightUnits + L")]";

// Вычисляем ширину каждой группы
int leftGroupWidth = leftLabelWidth + leftCurvesWidth;
int rightGroupWidth = rightLabelWidth + rightCurvesWidth;
int separatorWidth = 20; // " | "

// Общая ширина с разделителем
int totalWidth = leftGroupWidth + separatorSpacing + separatorWidth + separatorSpacing + rightGroupWidth;

// Центрируем и рисуем
int startX = rect.left + (chartWidth - totalWidth) / 2;

// Рисуем подпись левой оси
TextOut(startX, legendY, leftAxisLabel);

// Рисуем элементы левой оси
for (leftCurve...) {
    // Рисуем элемент (сплошная линия)
}

// Рисуем разделитель " | "
TextOut(currentX, legendY, L"|");

// Рисуем подпись правой оси
TextOut(currentX, legendY, rightAxisLabel);

// Рисуем элементы правой оси
for (rightCurve...) {
    // Рисуем элемент (пунктирная линия)
}
```

#### 3. HitTestLegendCheckbox() - определение кликов

**Обновлена логика:**
- Вычисляются позиции чекбоксов с учетом центрирования
- Используется `GetTextExtentPoint32()` для точного определения ширины текста
- Создается временный DC для вычислений размеров

```cpp
// Вычисляем позиции элементов
int startX = rect.left + (chartWidth - totalWidth) / 2;
int currentX = startX;

for (elem...) {
    elem.checkboxX = currentX + colorBoxSize + 2;
    currentX += elem.width + spacing;
}

// Проверяем попадание
for (elem...) {
    RECT checkboxRect = {elem.checkboxX, ...};
    if (PtInRect(&checkboxRect, pt)) {
        return elem.channelIdx;
    }
}
```

#### 4. CalculatePlotRect() и CalculateDualAxisPlotRect()

**Увеличен верхний отступ для легенды:**
```cpp
// Было
plotRect.top += 40; // Только заголовок

// Стало
plotRect.top += 65; // Заголовок + горизонтальная легенда
```

## 🎨 Параметры легенды

### Размеры элементов
```cpp
int checkboxSize = 12;      // Размер чекбокса (для обычных графиков)
int lineLength = 15;        // Длина цветной линии
int elementSpacing = 15;    // Промежуток между элементами
int separatorSpacing = 25;  // Дополнительный отступ для разделителя (для двойных осей)
int separatorWidth = 20;    // Ширина разделителя " | " (для двойных осей)
int lineHeight = 20;        // Высота строки легенды
```

**Изменение (v2.4.0):**
- Удален `colorBoxSize` - цветные квадраты больше не используются
- Линия используется для всех типов графиков

### Позиционирование
```cpp
int legendY = rect.top + 35; // Позиция Y (под заголовком)

// Центрирование по X
int chartWidth = rect.right - rect.left;
int startX = rect.left + (chartWidth - totalWidth) / 2;
```

### Структура элемента легенды

**Обычный график (с чекбоксом):**
```
[Чекбокс] [Цветная линия] [Название]
   12px        15px         ~20-40px

Пример: ☑ ━ T1  ☑ ━ T2  ☑ ━ T3
```

**Двойные оси (с линией и разделителями):**
```
[Подпись оси] [Цветная линия] [Название] ... | [Подпись оси] [Цветная линия] [Название] ...
  ~80-120px        15px         ~40-80px        ~80-120px        15px         ~40-80px

Пример:
[Left Axis (mV)] ━ T1 Ampl ━ T2 Ampl  |  [Right Axis (mdeg)] ┄ T1 Phase ┄ T2 Phase
```

**Изменение (v2.4.0):**
- Убраны цветные квадраты - оставлены только линии
- Линия показывает И цвет, И стиль (сплошная/пунктирная)
- Более компактная и понятная легенда

## 🎯 Разделители и подписи осей (для двойных осей)

### Назначение
При отображении графиков с двойными осями (например, амплитуды на левой оси и фазы на правой) важно четко показать, какие кривые к какой оси относятся.

### Реализация
```
[Left Axis (mV)]  ━ T1 Ampl  ━ T2 Ampl  |  [Right Axis (mdeg)]  ┄ T1 Phase  ┄ T2 Phase
     ↑                                   ↑                ↑
  Подпись оси                      Разделитель      Подпись оси
```

### Элементы
1. **Подписи осей** - `[Left Axis (mV)]` и `[Right Axis (mdeg)]`
   - Показывают, к какой оси относятся следующие кривые
   - Включают единицы измерения в скобках
   - Отображаются черным цветом

2. **Разделитель** - `|`
   - Визуально разделяет группы кривых
   - Отображается серым цветом RGB(128, 128, 128)
   - Дополнительные отступы по 25px с каждой стороны

3. **Группировка кривых**
   - Сначала все кривые левой оси (сплошные линии)
   - Затем разделитель
   - Затем все кривые правой оси (пунктирные линии)

### Преимущества
- **Полная ясность** - сразу видно, какие кривые к какой оси относятся
- **Единицы измерения** - показаны для каждой оси
- **Визуальное разделение** - разделитель четко отделяет группы
- **Соответствие графику** - сплошные/пунктирные линии соответствуют отображению на графике

## 🎨 Упрощение легенды - только линии (v2.4.0)

### Проблема
Дублирование информации о цвете кривой:
- Цветной квадрат показывал цвет
- Цветная линия также показывала цвет
- Избыточность визуальных элементов

### Решение
Убраны цветные квадраты, оставлены только цветные линии:
```
Было:  ■ ━ T1 Ampl  ■ ━ T2 Ampl
Стало:   ━ T1 Ampl    ━ T2 Ampl
```

### Преимущества
1. **Больше информации** - линия показывает И цвет, И стиль (сплошная/пунктирная)
2. **Визуальное соответствие** - линия в легенде выглядит как линия на графике
3. **Компактность** - меньше элементов, больше места для названий
4. **Меньше шума** - проще воспринимать легенду
5. **Логичность** - линия = кривая на графике

### Применение
- **Обычные графики**: `☑ ━ T1  ☑ ━ T2` (все линии сплошные)
- **Двойные оси**: `━ T1 Ampl | ┄ T1 Phase` (сплошная для левой, пунктирная для правой)

## ✅ Преимущества

### 1. Улучшенная читаемость
- Легенда не перекрывает данные графика
- Все подписи видны одновременно
- Легко различать цвета и названия кривых
- Четкое разделение кривых по осям (для двойных осей)

### 2. Эффективное использование пространства
- Горизонтальное расположение использует ширину графика
- Освобождено место справа для данных
- Компактное представление при большом количестве кривых

### 3. Современный интерфейс
- Чистый и аккуратный вид
- Центрирование создает баланс
- Соответствует современным стандартам UI/UX

### 4. Сохранение функциональности
- Чекбоксы остаются интерактивными
- Клики по чекбоксам работают корректно
- Все существующие функции сохранены
