# 📝 История изменений AMK-Horizon-New-Chart

## ✨ Версия 2.9.6 - Оптимизация интерфейса Device Schematic

### Улучшения интерфейса
- **Удалена кнопка "Copy from..."**: Упрощение интерфейса за счёт удаления редко используемой функции
- **Перемещены кнопки управления**: Apply и Cancel размещены отдельно справа, вне группы Quick Presets
- **Уменьшен размер окна**: С 420×280 до 420×230 DLU (экономия 18% высоты)
- **Оптимизирована компоновка**: Более компактное и логичное расположение элементов
- **Чёткое разделение областей**: Quick Presets и кнопки управления визуально разделены

### Технические изменения
- Удалён метод `HandleCopyFromChart()` и связанная логика
- Удалена константа `IDC_COPY_FROM_CHART` из Resource.h
- Обновлены координаты элементов в ресурсном файле
- Уменьшена высота Available Curves: 145 → 120 DLU
- Уменьшена высота Quick Presets: 90 → 70 DLU (только пресеты)
- Кнопки Apply и Cancel размещены вне группы Quick Presets (Y=180)

### Преимущества
- **Компактность**: Окно занимает меньше места на экране
- **Простота**: Убрана избыточная функциональность
- **Удобство**: Кнопки управления логично расположены справа
- **Визуальная ясность**: Чёткое разделение функциональных областей

## 🐛 Версия 2.9.5 - Исправление повторного открытия Device Schematic

### Исправления ошибок
- **Исправлено повторное открытие окна**: Device Schematic теперь корректно открывается после закрытия через Cancel или крестик
- **Проблема**: После закрытия окна через Cancel или крестик, повторное нажатие на кнопку Device Schematic не открывало окно
- **Решение**: Добавлен вызов `ShowWindow(hSchematicDialog, SW_SHOW)` для отображения скрытого окна

### Технические детали
- Метод `ShowSchematicDialog()` теперь явно показывает окно перед активацией
- Скрытое окно корректно восстанавливается при повторном вызове

## ✨ Версия 2.9.4 - Немодальное окно Device Schematic

### Улучшения функциональности
- **Немодальное окно**: Device Schematic теперь не закрывается после нажатия Apply
- **Быстрое переключение кривых**: Можно многократно применять разные комбинации без переоткрытия окна
- **Возможность сворачивания**: Окно можно свернуть в панель задач Windows
- **Иконка в панели задач**: Отдельная иконка рядом с основным окном приложения
- **Свободное переключение**: Работа с обоими окнами одновременно
- **Кнопка Cancel**: Скрывает окно вместо закрытия (можно быстро вернуть)
- **Автообновление графика**: График обновляется автоматически после Apply через callback

### Технические изменения
- **Архитектура**: Переход с модального (`DialogBoxParam`) на немодальное окно (`CreateDialogParam`)
- **Стиль окна**: Добавлены `WS_MINIMIZEBOX`, `WS_VISIBLE`, `WS_EX_APPWINDOW`
- **Управление окном**: Новые методы `HideSchematicDialog()`, `CloseSchematicDialog()`, `IsSchematicDialogVisible()`
- **Обработка событий**: `WM_CLOSE` скрывает окно, `WM_DESTROY` очищает ресурсы

### Преимущества
- **Удобство**: Не нужно постоянно открывать/закрывать окно
- **Скорость работы**: Быстрое переключение между комбинациями кривых
- **Наглядность**: Видно обе иконки в панели задач
- **Гибкость**: Можно работать с обоими окнами параллельно

## ✨ Версия 2.8.0 - Статусная строка с координатами курсора

### Новые возможности
- **Добавлена статусная строка**: Отображение координат курсора в реальном времени при наведении на график

- **Информация о файле**: Количество точек данных и имя загруженного файла в правой части статусной строки

- **Умное форматирование**: Разная точность для разных типов данных (фазы - целые числа, амплитуды - 3 знака)

### Технические детали

- **Интеграция с layout**: Высота статусной строки учитывается при расчёте размеров графиков
