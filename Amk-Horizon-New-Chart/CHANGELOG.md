# 📝 История изменений AMK-Horizon-New-Chart

## ✨ Версия 2.7.1 - Упрощение интерфейса сохранения диапазона

### Улучшения интерфейса
- **Удалена кнопка "Save Range" для Chart 2**: Оставлена только кнопка для Chart 1
- **Причина**: Устранение путаницы пользователей при сохранении конкретного участка графика
- **Преимущества**: Пользователи больше не нажимают случайно на кнопку другого графика
- **Логика сохранения**: Функциональность для Chart 1 осталась без изменений

---

## ✨ Версия 2.7.0 - Изменение расположения осей Y для двойных графиков

### Улучшения интерфейса
- **Изменено расположение осей Y**: При отображении двух осей фазы теперь на левой оси, амплитуды на правой
- **Новая логика**: Левая ось Y - фазы (мдег), правая ось Y - амплитуды (мВ)
- **Преимущества**: Фазы (более важные) на основной левой оси, амплитуды на дополнительной правой оси
- **Обратная совместимость**: При отображении однородных данных (только фазы или только амплитуды) ось остаётся слева

### Упрощение интерфейса
- **Удалено меню "Вид"**: Убраны избыточные пункты меню "Переключить режим графиков" и "Тест обновления графиков"
- **Причина**: Функциональность уже реализована через другие элементы интерфейса (чекбокс Dual Mode, кнопки Device Schematic)

### Улучшение сообщений пользователю
- **Логичные подсказки**: При запуске приложения отображается "Please open a data file first"
- **После загрузки данных**: Отображается "Click 'Device Schematic' to configure this chart" с сеткой графика
- **Улучшенный UX**: Пользователь сразу понимает, что нужно сделать на каждом этапе

---

## ✨ Версия 2.6.5 - Улучшение порядка отображения кривых для передатчиков

### Улучшения интерфейса
- **Улучшен порядок кривых при выборе передатчиков**: Для каждого передатчика сначала все фазы, затем все амплитуды
- **Новый порядок**: T1 Phase R1, T1 Phase R2, T1 Amplitude R1, T1 Amplitude R2
- **Преимущества**: Логичная группировка, согласованность с приёмниками, удобство анализа

---

## ✨ Версия 2.6.4 - Все кривые включены по умолчанию

### Улучшения интерфейса
- **Все кривые включены при первоначальном выборе**: Фазы и амплитуды включены по умолчанию
- **Преимущества**: Не нужно вручную включать фазы, все данные доступны сразу

---

## 🐛 Версия 2.6.3 - Исправление отображения графиков только с фазами

### Критическое исправление
- **Проблема**: При выборе только фазовых кривых график оставался пустым
- **Решение**: Автоматическая нормализация осей - фазы перемещаются на левую ось при отсутствии амплитуд
- **Результат**: Фазовые кривые корректно отображаются даже без амплитуд

---

## ✨ Версия 2.6.2 - Улучшение порядка отображения кривых

### Улучшения интерфейса
- **Изменён порядок кривых в Device Schematic**: Сначала все фазы, затем все амплитуды
- **Для одного приёмника**: T1-T4 Phase, затем T1-T4 Amplitude
- **Для двух приёмников**: T1-T4 Phase Difference, затем T1-T4 Amplitude Ratio
- **Преимущества**: Фазы (более важные) в начале списка, логичная группировка

---

## 🐛 Версия 2.6.1 - Исправление координат кликов в Device Schematic

## ✨ Версия 2.3.0 - Нормализация фазовых данных

### Новые возможности

- **Применено к**: PHASE_DIFFERENCE, PHASE_RX1, PHASE_RX2
- **Результат**: Устранение скачков и разрывов на графиках

---

## ✨ Версия 2.2.3 - Преобразование единиц измерения фаз

### Улучшения отображения данных
- **Изменены единицы фаз**: Радианы → миллиградусы (mdeg)
- **Формула**: `значение * 57295.7795f` (180/π * 1000)
- **Преимущества**: Интуитивные единицы, высокая точность

---

## ✨ Версия 2.2.2 - Преобразование единиц измерения амплитуд

### Улучшения отображения данных
- **Изменены единицы амплитуд**: Сырые данные АЦП → милливольты (mV)
- **Формула**: `значение * 4000.0f / pow(2.0f, 24.0f)`
- **Преимущества**: Физические единицы, лучшая читаемость

---

## ✨ Версия 2.1.0 - Группировка кривых по элементам

## 🚀 Версия 2.0.0 - Модульная архитектура и новая система кривых

### Новые возможности
- **Модульная архитектура**: 7 специализированных модулей с четким разделением ответственности
- **Схема прибора (Device Schematic)**: Визуальный интерфейс для настройки отображения данных
- **Быстрые пресеты**: All Ampl R1/R2, All Phase R1/R2, Ampl Ratios, Phase Diff
- **Новая система кривых**: Гибкое управление, двойные оси, умное назначение цветов
- **Улучшенная интерактивность**: Zoom, прокрутка, переключение каналов

### Исправления ошибок
- **Исправлена кодировка**: Все текстовые элементы переведены на английский
- **Устранены дублированные методы** и предупреждения компилятора
- **Оптимизирована память** для больших массивов данных
