# 📝 История изменений AMK-Horizon-New-Chart

## ✨ Версия 2.13.0 - Режим реального времени (11 декабря 2025)

### 🆕 Новая функциональность
- **Чтение данных с прибора в реальном времени**: Подключение к геофизическому прибору через COM-порт
- **Новый модуль SerialModule**: Полная реализация протокола обмена данными с прибором
- **Поддержка метрологии**: Запрос и отображение метрологических данных прибора (серийный номер, диаметр зонда)
- **Автоматический опрос**: Периодический запрос данных каждые 2 секунды
- **Статистика подключения**: Отображение номера кадра, количества полученных пакетов и ошибок

### Меню "Прибор"
Управление подключением к прибору вынесено в отдельное меню:
- **Подключить...**: Открывает диалог подключения к прибору
- **Отключить**: Отключение от прибора
- **Старт опроса**: Начать периодический опрос данных
- **Стоп опроса**: Остановить опрос
- **Очистить данные**: Удалить накопленные данные

### Диалог подключения (IDD_SERIAL_STATUS)
- **COM-порт**: Выпадающий список доступных COM-портов
- **Обновить**: Обновление списка портов
- **Подключить/Отключить**: Управление подключением
- **Статус**: Текущее состояние (Отключено/Подключено/Опрос...)
- **Кадр**: Номер последнего полученного кадра
- **Пакеты**: Статистика (получено / ошибок)
- **Информация о приборе**: Серийный номер и диаметр зонда

### Протокол обмена
- **CMD_WORK (0x67)**: Запрос данных измерений
- **CMD_READ_EE (0x65)**: Запрос метрологии
- **CRC16 Modbus**: Проверка целостности данных
- **Скорость**: 125000 бод
- **Формат пакета**: [CMD:1] [Reserved:12] [GP_TOOL_DATA:240] [CRC:2]

### Технические изменения
- **SerialModule.h/cpp**: Новый модуль для работы с COM-портом
  - Подключение/отключение от COM-порта
  - Отправка команд и получение ответов
  - Проверка CRC16 и сигнатуры данных
  - Периодический опрос через Windows Timer
  - Callbacks для получения данных и изменения состояния
- **ChartManager**: Интеграция SerialModule
  - Методы HandleSerialConnect/Disconnect/Start/Stop/Clear
  - Callback для добавления данных в реальном времени
  - Автоматическое обновление графиков при получении данных
- **Amk-Horizon-New-Chart.cpp**: 
  - Обработчики команд меню "Прибор" (IDM_DEVICE_*)
  - Диалоговая процедура SerialStatusDialogProc
  - Обновление статистики в диалоге при получении данных
- **Amk-Horizon-New-Chart.rc**: 
  - Новое меню "Прибор" между "Файл" и "Справка"
  - Диалог IDD_SERIAL_STATUS для управления подключением
- **DataModule**: Метод AddData() для добавления данных в реальном времени
- **Resource.h**: Новые ID (IDM_DEVICE_*, IDD_SERIAL_STATUS, IDC_SERIAL_*)

### Использование
1. Откройте меню "Прибор" → "Подключить..."
2. Выберите COM-порт из списка
3. Нажмите "Подключить" для подключения к прибору
4. При успешном подключении отобразится информация о приборе
5. Опрос начнётся автоматически, данные будут добавляться на графики
6. Для остановки нажмите "Отключить" или закройте диалог
6. Нажмите "Stop" для остановки опроса
7. Нажмите "Clear" для очистки накопленных данных
8. Нажмите "Disconnect" для отключения от прибора

### Совместимость
- Совместим с эмулятором прибора (emul__1_.ino)
- Поддерживает сигнатуры 0x31443453 ("1D4S") и 0x31443454 ("1D4T")
- Структура данных GP_TOOL_DATA идентична файловому формату

## ✨ Версия 2.12.5 - Пошаговый откат zoom (8 декабря 2025)

### 🆕 Новая функциональность
- **Пошаговый откат zoom**: Правая кнопка мыши теперь откатывает zoom на один шаг назад, а не сбрасывает полностью
- **История zoom**: Каждый zoom сохраняется в историю (стек), позволяя последовательно возвращаться к предыдущим состояниям
- **Полный сброс**: Когда история пуста, правая кнопка мыши сбрасывает к полному виду (как раньше)
- **Кнопка Reset Zoom**: Выполняет полный сброс zoom и очищает историю

### Пример использования
1. Исходный вид (полные данные)
2. Zoom 1 → сохраняется в историю
3. Zoom 2 → сохраняется в историю
4. Zoom 3 → сохраняется в историю
5. ПКМ → возврат к Zoom 2
6. ПКМ → возврат к Zoom 1
7. ПКМ → возврат к исходному виду

### Технические изменения
- **ChartManager.h**:
  - Добавлены `chart1ZoomHistory` и `chart2ZoomHistory` (std::vector<ZoomRange>)
  - Добавлен `#include <vector>`
- **ChartManager.cpp**:
  - `HandleMouseUp`: Сохранение текущего состояния в историю перед применением нового zoom
  - `HandleRightClick`: Пошаговый откат из истории вместо полного сброса
  - `LoadDataFromFile`: Очистка истории при загрузке нового файла
  - `UpdateChartAfterConfigurationChange`: Очистка истории при смене конфигурации
  - `HandleResetZoom`: Очистка истории при полном сбросе через кнопку
  - Callback `onConfigurationApplied`: Очистка истории при смене функции/пресета

### Очистка истории zoom
История zoom автоматически очищается при:
- Загрузке нового файла данных
- Смене функции/пресета в Device Schematic
- Нажатии кнопки "Reset Zoom"

- **Разносортные данные**: Если выбраны и амплитуды, и фазы — фазы на левой оси, амплитуды на правой (как было раньше)
- **Преимущество**: Упрощённое отображение для односортных данных, нет необходимости в двойных осях

### Технические изменения
- **CurveSelectionModule.cpp**:
  - `AddTwoReceiversCurves`: Добавлена проверка `isSingleType` для определения односортных данных
  - `AddSingleReceiverCurves`: Аналогичная логика для пресетов All Ampl R1/R2 и All Phase R1/R2
  - Амплитудные кривые теперь получают `yAxisGroup = isSingleType ? 0 : 1`

### Затронутые пресеты
- ✅ **Ampl Ratios** — теперь работает в режиме кроссплота
- ✅ **All Ampl R1** — теперь работает в режиме кроссплота

## ✨ Версия 2.12.3 - Исправление скроллинга по осям X и Y (8 декабря 2025)

### 🔧 Исправления скроллинга по оси X
- **Исправлен горизонтальный скроллинг**: Теперь можно прокрутить график до конца данных (до максимального значения X)
- **Учёт nPage в Windows API**: Исправлена формула вычисления позиции скроллбара с учётом того, что реальный максимум = `nMax - nPage + 1`
- **Корректное вычисление координат**: Данные теперь отрисовываются с правильными координатами X при скроллинге

### 🔧 Исправления скроллинга по оси Y
- **Исправлен вертикальный скроллинг**: Теперь можно прокрутить график до нижней и верхней границы данных
- **Равномерный padding**: Одинаковый отступ 5% сверху и снизу для визуального комфорта
- **Учёт nPage для вертикального скроллбара**: Аналогичное исправление формулы для оси Y

### 🔧 Сброс X Range при смене функции
- **Автоматический сброс X Range**: При выборе новой функции/пресета в Device Schematic поля X Range сбрасываются к полному диапазону (0 до максимума)
- **Сброс при открытии файла**: При загрузке нового файла данных X Range сбрасывается для обоих графиков
- **Сброс zoom**: При смене функции zoom также сбрасывается

### Технические изменения
- **ChartManager.cpp**:
  - `HandleScrollEvent`: Исправлена формула горизонтального скроллинга с учётом `maxScrollPos = si.nMax - si.nPage + 1`
  - `HandleScrollEvent`: Исправлена формула вертикального скроллинга с учётом `maxScrollPos`
  - `UpdateScrollBars`: Исправлено вычисление позиции горизонтального скроллбара для Chart 1 и Chart 2
  - `UpdateScrollBars`: Исправлено вычисление позиции вертикального скроллбара для Chart 1 и Chart 2
  - `LoadDataFromFile`: Добавлен сброс X Range при загрузке нового файла
  - `onConfigurationApplied callback`: Добавлен сброс X Range и zoom при смене функции
- **ChartModule.cpp**:
  - `DrawDualAxisDataWithZoom`: Добавлены параметры `minXData` и `maxXData` для корректной отрисовки координат X
- **ChartModule.h**:
  - Обновлена сигнатура `DrawDualAxisDataWithZoom` с новыми параметрами

### Причина проблем
- В Windows API при установке `SCROLLINFO` с `nPage`, реальный максимум позиции скроллбара = `nMax - nPage + 1`, а не `nMax`
- Код использовал формулу `newPos / 100.0`, предполагая максимум = 100, но реальный максимум был меньше
- Координаты X при отрисовке вычислялись относительно размера массива данных, а не реальных индексов

### Формулы скроллинга (исправленные)

**Горизонтальный скроллинг:**
```cpp
int maxScrollPos = si.nMax - (int)si.nPage + 1;
double scrollRatio = (maxScrollPos > 0) ? (double)newPos / (double)maxScrollPos : 0.0;
double newMinX = scrollRatio * (totalRange - viewRange);
```

**Вертикальный скроллинг (инвертированный):**
```cpp
int maxScrollPos = si.nMax - (int)si.nPage + 1;
double scrollRatio = (maxScrollPos > 0) ? (double)(maxScrollPos - newPos) / (double)maxScrollPos : 0.0;
double newMinY = minYFull + scrollRatio * (totalYRange - viewYRange);
```
