## ✨ Версия 2.1.0 - Группировка кривых по элементам

### ✨ Новые возможности

#### Группировка кривых в Device Schematic
- **ListView Groups** - использование стандартной группировки Windows для визуального разделения кривых
- **Автоматическая группировка** - кривые автоматически группируются по элементам (T1-T4, R1-R2, Silent)
- **Сворачиваемые группы** - возможность сворачивать/разворачивать группы для удобства
- **Все чекбоксы работают** - каждая кривая имеет свой независимый чекбокс

#### Логика группировки
- **Несколько передатчиков** (T2 + T4) → 2 группы с кривыми
- **Один приемник** (R1) → без группировки, плоский список
- **Два приемника** (R1 + R2) → без группировки, Ratios & Differences
- **Несколько элементов** → каждый элемент в отдельной группе

#### Визуальное представление
```
Available Curves
├─ ▼ T2
│  ☑ Amplitude R1 (V) [Left Axis]
│  ☑ Amplitude R2 (V) [Left Axis]
│  ☑ Phase R1 (deg) [Right Axis]
│  ☑ Phase R2 (deg) [Right Axis]
│
└─ ▼ T4
   ☑ Amplitude R1 (V) [Left Axis]
   ☑ Amplitude R2 (V) [Left Axis]
   ☑ Phase R1 (deg) [Right Axis]
   ☑ Phase R2 (deg) [Right Axis]
```

### 🔧 Технические улучшения
- Использование `ListView_EnableGroupView()` для включения группировки
- Создание групп через `ListView_InsertGroup()` с заголовками элементов
- Привязка кривых к группам через `LVIF_GROUPID`
- Поддержка сворачивания групп (`LVGS_COLLAPSIBLE`)

### 📚 Документация
- **FEATURE_CURVE_GROUPING.md** - подробное описание функции с примерами и тестами

## 🐛 Версия 2.0.2 - Исправление фильтрации кривых в пресетах

### 🐛 Исправления ошибок

#### Фильтрация кривых в Quick Presets
- **Исправлена проблема** с отображением лишних кривых при выборе быстрых пресетов
- **"Ampl Ratios"** - теперь показывает только 4 кривые отношений амплитуд (было 8: 4 отношения + 4 разности фаз)
- **"Phase Diff"** - теперь показывает только 4 кривые разностей фаз (было 8: 4 разности + 4 отношения)
- **"All Phase R1/R2"** - теперь показывает только 4 кривые фаз (было 8: 4 фазы + 4 амплитуды)
- **"All Ampl R1/R2"** - теперь показывает только 4 кривые амплитуд (было 8: 4 амплитуды + 4 фазы)
- **Очистка старых кривых** - при переключении между пресетами старые кривые корректно удаляются
- **Сохранение фильтра пресета** - при повторном открытии Device Schematic восстанавливается выбранный пресет и его кривые

#### Технические детали
- Добавлен enum `DataTypeFilter` с типами: ALL, AMPLITUDE_ONLY, PHASE_ONLY, RATIO_ONLY, DIFFERENCE_ONLY
- Добавлено поле `dataFilter` в структуру `SchematicSelection`
- Метод `HandlePresetButton()` теперь устанавливает соответствующий фильтр для каждого пресета
- Методы `AddTwoReceiversCurves()` и `AddSingleReceiverCurves()` учитывают фильтр при генерации кривых
- При ручном выборе элементов фильтр сбрасывается на ALL для отображения всех доступных кривых
- Очистка `currentAvailableCurves` при смене пресета предотвращает накопление старых кривых
- Метод `DetermineDataFilterFromCurves()` автоматически определяет фильтр по типам кривых в конфигурации
- Метод `InitializeDialogControls()` восстанавливает фильтр при повторном открытии диалога

#### Воспроизведение проблемы (до исправления)
1. Открыть Device Schematic
2. Нажать "Ampl Ratios"
3. **Проблема**: Отображается 8 чекбоксов (4 отношения + 4 разности фаз)
4. Нажать "All Phase R1"
5. **Проблема**: Отображается 8 чекбоксов (4 фазы + 4 амплитуды)

#### После исправления
- ✅ "Ampl Ratios" показывает только 4 кривые отношений амплитуд
- ✅ "Phase Diff" показывает только 4 кривые разностей фаз
- ✅ "All Phase R1" показывает только 4 кривые фаз R1
- ✅ "All Ampl R1" показывает только 4 кривые амплитуд R1
- ✅ При переключении между пресетами старые кривые не остаются
- ✅ При повторном открытии Device Schematic восстанавливается выбранный пресет

## 🐛 Версия 2.0.1 - Исправление сохранения выбора кривых

### 🐛 Исправления ошибок

#### Сохранение конфигурации Device Schematic
- **Исправлена проблема** с сохранением выбора кривых при повторном открытии диалога
- **Восстановление частоты** - выбранная частота (400 kHz / 2000 kHz) теперь сохраняется
- **Восстановление чекбоксов** - состояние галочек кривых корректно восстанавливается
- **Восстановление выбора элементов** - выбор T1-T4, R1-R2, Silent сохраняется (уже работало)

#### Технические детали
- Метод `InitializeDialogControls()` теперь восстанавливает конфигурацию из `CurveSelectionModule`
- Метод `UpdateAvailableCurves()` синхронизирует состояние enabled кривых через карту ID
- Добавлена логика извлечения выбора элементов из существующих кривых
- Полная обратная совместимость - если конфигурации нет, используются дефолтные значения

#### Воспроизведение проблемы (до исправления)
1. Открыть Device Schematic, выбрать T3
2. Отметить только "T3 Amplitude R2" и "T3 Phase R2"
3. Нажать Apply - график отображается корректно
4. Повторно открыть Device Schematic
5. **Проблема**: Все 4 галочки включены вместо 2

#### После исправления
- ✅ T3 остаётся выбранным
- ✅ Частота сохраняется
- ✅ Только 2 галочки отмечены (как и было)

## 🚀 Версия 2.0.0 - Модульная архитектура и новая система кривых

### ✨ Новые возможности

#### 🏗️ Модульная архитектура
- **Полный рефакторинг** с монолитной архитектуры на модульную
- **7 специализированных модулей** с четким разделением ответственности
- **ChartManager** как главный координатор всех модулей
- **Слабая связанность** между модулями через четкие интерфейсы

#### ⚙️ Схема прибора (Device Schematic)
- **Визуальный интерфейс** для настройки отображения данных
- **Интерактивные элементы**: передатчики (T1-T4), приемники (R1-R2), молчащие передатчики
- **Правила валидации** выбора элементов
- **Цветовое кодирование** элементов схемы

#### 🎨 Быстрые пресеты (Quick Presets)
- **All Ampl R1/R2** - все амплитуды для конкретного приемника
- **All Phase R1/R2** - все фазы для конкретного приемника  
- **Ampl Ratios** - отношения амплитуд для всех передатчиков
- **Phase Diff** - разности фаз для всех передатчиков
- **Копирование настроек** между графиками

#### 📈 Новая система кривых
- **Гибкое управление** отображением кривых
- **Автоматическое определение** доступных кривых на основе выбора
- **Двойные оси** для отображения разных типов данных
- **Конфигурации кривых** с сохранением настроек
- **Умное назначение цветов** с расширенной палитрой из 12 цветов
  - Приоритетные цвета для T1-T4 на левой оси
  - Автоматическое избежание конфликтов цветов
  - Независимое назначение для левой и правой осей
  - Поддержка до 12 различимых кривых на одной оси

#### 🎛️ Улучшенная интерактивность
- **Масштабирование областей** графика (zoom in/out)
- **Горизонтальная прокрутка** при масштабировании

## 📋 Версия 1.0.0 - Базовая функциональность

### ✨ Первоначальная реализация
- **Загрузка бинарных данных** формата GP_TOOL_DATA

- **Temperature** - температурные данные

### 🎛️ Базовый интерфейс
- **Комбобоксы** для выбора типа данных и частоты
- **Кнопки обновления** графиков
- **Режим двух графиков** (Dual Mode)
