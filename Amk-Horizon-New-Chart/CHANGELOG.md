# 📝 История изменений AMK-Horizon-New-Chart

## 🐛 Версия 2.10.1 - Исправления кроссплота и подписей осей

### Исправления ошибок
- **Исправлена подпись оси X для кроссплота**: Символ градуса теперь отображается корректно как "°C" (использован Unicode `\u00B0C`)
- **Исправлено расположение подписи "°C"**: Перемещена в правый угол графика с отступом 5px (было: по центру)
- **Исправлена позиция подписи по вертикали**: Подпись размещена на 25px ниже числовых значений температуры (избегает наслоения)
- **Исправлен zoom для кроссплота**: Метод `ConvertScreenToDataCoords` теперь корректно обрабатывает температурный режим
- **Исправлено преобразование координат**: При выделении области в кроссплоте правильно преобразует экранные координаты → температура → индекс кадра

### Технические изменения
- **ChartModule.cpp**: 
  - Изменена подпись оси X с `L"°C"` на `L"\u00B0C"` для корректного отображения символа градуса
  - Изменена позиция подписи: `plotRect.right - xLabelSize.cx - 5` (справа) вместо центрирования
  - Увеличен отступ по вертикали: `plotRect.bottom + 25` вместо `plotRect.bottom + 5`
- **ChartManager.cpp**:
  - Обновлен метод `ConvertScreenToDataCoords()` для поддержки температурного режима
  - Добавлена проверка `config.xAxisType == XAxisType::TEMPERATURE`
  - Добавлено вычисление `plotRect` с учётом отступов для одной и двойных осей
  - Добавлена логика преобразования: экранная X координата → температура → поиск ближайшего индекса кадра
  - Добавлен `static_cast<float>` для устранения предупреждения компилятора C4244

### Преимущества
- **Корректное отображение**: Подпись "°C" отображается правильно без артефактов кодировки
- **Удобство чтения**: Подпись справа не мешает восприятию графика
- **Работающий zoom**: Выделение области мышью корректно увеличивает участок графика в режиме кроссплота
- **Точность**: Преобразование координат учитывает нелинейное распределение температуры

### Использование
Zoom в режиме кроссплота теперь работает полностью:
1. Выберите "Temperature" в Device Schematic
2. Выделите область на графике мышью (левая кнопка + перетаскивание)
3. График корректно увеличит выбранный участок по температуре
4. Правая кнопка мыши сбрасывает zoom

## ✨ Версия 2.10.0 - Кроссплот: Выбор данных для оси X

### Новые возможности
- **Выбор типа оси X**: Добавлен выпадающий список "X-Axis" в Device Schematic для выбора данных оси X
- **Два режима оси X**:
  - **Frame Number** (по умолчанию) - номер кадра (0, 1, 2, ... N)
  - **Temperature** - температура прибора
- **Кроссплот функциональность**: Возможность строить графики зависимости данных от температуры
- **Сохранение настроек**: Тип оси X сохраняется в конфигурации графика

### Технические изменения
- Добавлен enum `XAxisType` в SchematicModule.h (FRAME_NUMBER, TEMPERATURE)
- Добавлено поле `xAxisType` в структуру `ChartConfiguration`
- Добавлена константа `IDC_XAXIS_TYPE_COMBO` (1040) в Resource.h
- Добавлен combobox "X-Axis" в диалог Device Schematic (Amk-Horizon-New-Chart.rc)
- Добавлены методы в DataModule:
  - `GetTemperatureData()` - получение массива температур
  - `GetTemperatureData(minX, maxX)` - получение температур для диапазона
- Добавлен метод `HandleXAxisTypeChange()` в SchematicModule
- Обновлена инициализация и применение конфигурации для сохранения типа оси X

### Преимущества
- **Анализ зависимостей**: Возможность анализировать зависимость данных от температуры
- **Кроссплот**: Построение графиков типа "амплитуда vs температура", "фаза vs температура"
- **Гибкость**: Быстрое переключение между режимами отображения
- **Удобство**: Настройка в том же окне Device Schematic рядом с выбором частоты

### Реализация отрисовки
- Добавлены перегрузки методов в ChartModule для работы с температурой:
  - `DrawChart()` с параметром `xAxisData`
  - `DrawChartData()` с температурой на оси X
  - `DrawGridAndAxes()` с подписями температуры
- Автоматическое определение диапазона температур для отображаемого участка
- Подписи оси X в формате "°C" (градусы Цельсия)
- Корректное масштабирование графиков по температуре

### Интеграция с системой отрисовки
- Обновлен метод `ChartManager::DrawChartWithCurves()` для проверки `config.xAxisType`
- При `xAxisType == TEMPERATURE`:
  - Получение массива температур из DataModule
  - Вызов `ChartModule::DrawChart()` с параметром `xAxisData`
  - Отрисовка графика с температурой на оси X
- При `xAxisType == FRAME_NUMBER`:
  - Использование стандартной логики с номером кадра
  - Вызов `ChartModule::DrawDualAxisChart()` как обычно

### Использование
1. Откройте Device Schematic для нужного графика
2. Выберите "Temperature" в выпадающем списке "X-Axis"
3. Настройте кривые как обычно
4. Нажмите "Apply"
5. График отобразится с температурой на оси X вместо номера кадра

## ✨ Версия 2.2.3 - Преобразование единиц измерения фаз

## ✨ Версия 2.2.2 - Преобразование единиц измерения амплитуд

## 🚀 Версия 2.0.0 - Модульная архитектура и новая система кривых
