# Улучшение: Преобразование единиц измерения амплитуд из Вольтов в милливольты

## Дата
2 ноября 2025

## Описание
Изменены единицы измерения для амплитуд с Вольтов (V) на милливольты (mV) для улучшения читаемости графиков и масштабирования данных.

## Проблема
При отображении данных амплитуд на графиках:
- Значения отображались в **Вольтах (V)**
- Значения были **очень большими** (например, 1000 V, 2500 V, 10000 V)
- Это приводило к **плохому масштабированию** графика
- Большие числа затрудняли чтение и анализ данных

## Решение
Преобразование отображения амплитуд из Вольтов в милливольты с учётом специфики прибора:
- **Формула**: `значение_в_mV = значение_в_V * 4000.0f / pow(2.0f, 24.0f)`
- **Упрощённо**: `значение_в_mV = значение_в_V * 4000.0f / 16777216.0f`
- **Коэффициент**: ≈ 0.000238418579
- **Назначение**: Учитывает разрядность АЦП (24 бита) и диапазон измерения (4000 мВ)

### Что изменено:

1. **Единицы измерения в интерфейсе**: "V" → "mV"
2. **Преобразование данных**: Деление на 1000 при вычислении
3. **Применено к типам данных**:
   - ✅ `AMPLITUDE_RX1` - амплитуды приемника 1
   - ✅ `AMPLITUDE_RX2` - амплитуды приемника 2
   - ✅ `SILENT_AMPLITUDE_RX1` - амплитуды молчащих для R1
   - ✅ `SILENT_AMPLITUDE_RX2` - амплитуды молчащих для R2
   - ❌ `AMPLITUDE_RATIO` - НЕ изменено (безразмерная величина V/V)

## Математика преобразования

### Формула
```
значение_в_mV = значение_в_V * 4000.0f / pow(2.0f, 24.0f)
```

### Объяснение
- **4000.0f** - диапазон измерения в милливольтах (полная шкала АЦП)
- **pow(2.0f, 24.0f)** = 16777216 - максимальное значение 24-битного АЦП
- **Коэффициент** = 4000 / 16777216 ≈ 0.000238418579

### Примеры преобразования

| Значение в Вольтах (V) | Вычисление | Значение в милливольтах (mV) |
|------------------------|------------|-------------------------------|
| 4194304 V              | 4194304 * 4000 / 16777216 | 1.0 mV |
| 8388608 V              | 8388608 * 4000 / 16777216 | 2.0 mV |
| 16777216 V             | 16777216 * 4000 / 16777216 | 4.0 mV |

*Примечание: Значения в Вольтах представляют собой сырые данные АЦП, которые преобразуются в физические единицы (мВ) с помощью формулы.*

## Что НЕ изменилось

### AMPLITUDE_RATIO остался без изменений:
- **Причина**: Это безразмерная величина (V/V)
- **Формула**: R2/R1 = (амплитуда_R2 в V) / (амплитуда_R1 в V)
- **Результат**: Отношение остаётся тем же независимо от единиц измерения
- **Пример**: 2500V / 1000V = 2.5 (то же самое, что 2.5mV / 1mV = 2.5)

### Исходные данные в файлах:
- **Формат GP_TOOL_DATA** не изменился
- **Данные в файлах** остаются в Вольтах
- **Преобразование** происходит только при отображении
