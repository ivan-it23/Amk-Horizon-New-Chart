## 🎯 Цель проекта

Реализовать систему умного назначения цветов кривым с расширенной палитрой и приоритетами для передатчиков T1-T4, чтобы избежать конфликтов цветов в сложных конфигурациях.

---

## ✨ Что было сделано

### 1. 🎨 Расширенная палитра цветов

#### Добавлены константы в `CurveSelectionModule.h`:
```cpp
static const COLORREF LEFT_AXIS_COLORS[4];      // Приоритетные цвета T1-T4
static const COLORREF EXTENDED_PALETTE[12];     // Расширенная палитра
```

#### Реализованы в `CurveSelectionModule.cpp`:
- **LEFT_AXIS_COLORS**: 4 приоритетных цвета для T1-T4 на левой оси
- **EXTENDED_PALETTE**: 12 уникальных цветов для сложных конфигураций

### 2. 🧠 Алгоритм умного назначения

#### Добавлен метод `AssignSmartColor`:
```cpp
COLORREF AssignSmartColor(const std::vector<CurveDefinition>& existingCurves,
                         int transmitterIndex, int yAxisGroup) const;
```

#### Логика работы:
1. **Анализ использованных цветов** на текущей оси
2. **Приоритет для T1-T4** на левой оси (если цвет свободен)
3. **Поиск первого свободного** из расширенной палитры
4. **Fallback на чёрный** если все цвета заняты (крайний случай)

### 3. 🔄 Обновление методов создания кривых

#### Методы `Add*Curves` (4 метода):
- `AddTwoReceiversCurves` - добавлен вызов `AssignSmartColor`
- `AddSingleReceiverCurves` - добавлен вызов `AssignSmartColor`
- `AddTransmitterCurves` - добавлен вызов `AssignSmartColor`
- `AddSilentTransmitterCurves` - без изменений (специальный цвет)

#### Методы `Create*Curve` (5 методов):
- `CreateRatioCurve` - временный цвет RGB(0,0,0)
- `CreateDifferenceCurve` - временный цвет RGB(0,0,0)
- `CreateAmplitudeCurve` - временный цвет RGB(0,0,0)
- `CreatePhaseCurve` - временный цвет RGB(0,0,0)
- `CreateSilentAmplitudeCurve` - без изменений (GetSpecialDataColor)
