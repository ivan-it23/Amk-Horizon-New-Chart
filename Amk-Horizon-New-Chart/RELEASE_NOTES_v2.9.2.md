# Release Notes - Version 2.9.2

**Дата релиза:** 19 ноября 2025

## 🎯 Основные изменения

### Агрессивная оптимизация диалога Device Schematic

В версии 2.9.2 выполнена максимальная оптимизация размеров и отступов диалогового окна Device Schematic для создания максимально компактного интерфейса.

## 📊 Что изменилось

### Эволюция размеров окна:

```
v2.9.0:  600 × 450 DLU = 270,000 DLU²
v2.9.1:  550 × 420 DLU = 231,000 DLU² (-14.4%)
v2.9.2:  500 × 370 DLU = 185,000 DLU² (-31.5%)

Итоговая экономия: 85,000 DLU² (31.5% площади)
```

### Константы оптимизации:

| Константа | v2.9.0 | v2.9.1 | v2.9.2 | Экономия |
|-----------|--------|--------|--------|----------|
| FRAME_PADDING | 15px | 10px | **6px** | **60%** |
| frameToSilentSpacing | 25px | 15px | **10px** | **60%** |
| FRAME_CORNER_RADIUS | 8px | 8px | **6px** | 25% |
| spacing | 12px | 12px | **12px** | 0% (сохранено) |
| Размер окна | 600×450 | 550×420 | **500×370** | 31.5% |
| Список кривых | 120px | 140px | **167px** | +39% |

## 💡 Ключевые улучшения

### 1. Максимальная компактность
- Окно уменьшено с 600×450 до 500×370 DLU
- Экономия 31.5% площади экрана
- Идеально для работы на небольших мониторах

### 2. Адаптивность через Dialog Units
- **Dialog Units (DLU)** автоматически масштабируются
- Зависят от системного шрифта и DPI настроек
- Корректное отображение на всех устройствах
- Не требуется ручная настройка для разных экранов

### 3. Больше места для данных
- Список Available Curves увеличен до 167px
- На 39% больше места по сравнению с v2.9.0
- Больше кривых видно без прокрутки

### 4. Минимальные отступы
- FRAME_PADDING: 15px → 6px (60% уменьшение)
- frameToSilentSpacing: 25px → 10px (60% уменьшение)
- Чистый современный интерфейс

### 5. Сохранено удобство
- Отступы между элементами схемы (12px) не изменены
- Элементы T1-T4, R1-R2, Silent удобны для клика
- Все функции работают без изменений

## 📐 О Dialog Units (DLU)

### Что такое DLU?
Dialog Units - это единицы измерения, используемые в Win32 API для диалоговых окон. Они автоматически масштабируются в зависимости от:
- Системного шрифта
- DPI настроек Windows
- Размера экрана

### Преимущества DLU:
1. **Автоматическая адаптивность** - не нужно писать код для разных разрешений
2. **Консистентность** - одинаковый вид на всех устройствах
3. **Читаемость** - текст всегда читаем независимо от DPI
4. **Стандарт Windows** - рекомендуемый подход Microsoft

### Формула преобразования:
```
1 DLU по горизонтали ≈ 1/4 средней ширины символа шрифта
1 DLU по вертикали ≈ 1/8 высоты символа шрифта

Примерно:
- При стандартном шрифте 8pt: 1 DLU ≈ 1.5 пикселя
- При 100% DPI: 500 DLU ≈ 750 пикселей
- При 125% DPI: 500 DLU ≈ 937 пикселей (автоматически!)
```

## ✅ Тестирование

Рекомендуется протестировать на разных DPI настройках:

1. **100% DPI (стандарт)**:
   - Окно должно быть компактным
   - Все элементы читаемы

2. **125% DPI**:
   - Окно автоматически увеличится
   - Пропорции сохранятся

3. **150% DPI**:
   - Окно ещё больше
   - Читаемость отличная

4. **Функциональность**:
   - Клики на элементы схемы работают
   - Список кривых прокручивается
   - Пресеты применяются
