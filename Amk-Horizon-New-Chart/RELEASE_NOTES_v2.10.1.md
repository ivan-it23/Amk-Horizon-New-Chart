# 🎉 Release Notes - AMK-Horizon-New-Chart v2.10.1

**Дата релиза:** 20 ноября 2025  
**Тип релиза:** Bugfix Release

## 📝 Обзор

Версия 2.10.1 исправляет критические проблемы с кроссплотом, добавленным в версии 2.10.0. Теперь zoom полностью работает в режиме температуры на оси X, а подписи осей отображаются корректно.

## 🐛 Исправленные ошибки

### 1. Подпись оси X отображалась некорректно
**Проблема:** Символ градуса отображался как "В°C" вместо "°C"  
**Причина:** Проблема с кодировкой символа в исходном коде  
**Решение:** Использован Unicode escape-код `L"\u00B0C"`  
**Файл:** `ChartModule.cpp`, строка ~1479

### 2. Подпись "°C" наслаивалась на числовые значения
**Проблема:** Подпись размещалась на той же высоте, что и числа температуры  
**Причина:** Недостаточный отступ по вертикали (5px)  
**Решение:** Увеличен отступ до 25px  
**Файл:** `ChartModule.cpp`, строка ~1483

### 3. Подпись "°C" была по центру графика
**Проблема:** Подпись мешала восприятию данных  
**Причина:** Центрирование по ширине графика  
**Решение:** Перемещена в правый угол с отступом 5px  
**Файл:** `ChartModule.cpp`, строка ~1482

### 4. Zoom не работал в режиме кроссплота
**Проблема:** Выделение области мышью не увеличивало график  
**Причина:** Метод `ConvertScreenToDataCoords` не учитывал температурный режим  
**Решение:** Добавлена специальная логика для преобразования координат через температуру  
**Файл:** `ChartManager.cpp`, строка ~399

## ✨ Технические изменения

### ChartModule.cpp
```cpp
// Было:
const wchar_t* xAxisLabel = L"°C";
int xLabelX = plotRect.left + (plotRect.right - plotRect.left - xLabelSize.cx) / 2;
int xLabelY = plotRect.bottom + 5;

// Стало:
const wchar_t* xAxisLabel = L"\u00B0C";
int xLabelX = plotRect.right - xLabelSize.cx - 5;
int xLabelY = plotRect.bottom + 25;
```

### ChartManager.cpp - ConvertScreenToDataCoords
Добавлена логика для температурного режима:
1. Получение конфигурации графика (`config.xAxisType`)
2. Вычисление `plotRect` с учётом отступов
3. Для `XAxisType::TEMPERATURE`:
   - Получение температурных данных
   - Преобразование: экранная X → температура
   - Поиск ближайшего индекса кадра с этой температурой
   - Возврат индекса кадра (не температуры!)

## 🚀 Использование

### Zoom в режиме кроссплота
1. Откройте Device Schematic
2. Выберите "Temperature" в выпадающем списке "X-Axis"
3. Нажмите "Apply"
4. Выделите область на графике мышью (левая кнопка + перетаскивание)
5. График корректно увеличит выбранный участок
6. Правая кнопка мыши сбрасывает zoom

### Примеры анализа
- **Температурная стабильность амплитуд**: Выберите "All Ampl R1", установите X-Axis: Temperature
- **Температурный дрейф фаз**: Выберите "All Phase R1", установите X-Axis: Temperature
- **Детальный анализ участка**: Используйте zoom для увеличения интересующей области
