# Требования к проекту AMK-Horizon-Chart

## Обзор проекта

AMK-Horizon-Chart - это приложение для визуализации данных индукционного каротажа. Приложение отображает данные с прибора в виде графиков с возможностью переключения между режимами отображения одного или двух графиков одновременно.

## 1. Структура данных

### 1.1 Основная структура данных прибора

```cpp
struct GP_TOOL_DATA {
    uint32_t signature;      // Сигнатура для идентификации данных
    uint32_t condition;      // Состояние измерения (контроль качества)
    float Ro_smt[8];        // Симметризованное удельное сопротивление
    float PH_smt[8];        // Симметризованная разность фаз
    uint32_t frame;         // Номер кадра
    float temperature;      // Температура
    float AM_RX_1[10];      // Амплитуды приемника RX1
    float AM_RX_2[10];      // Амплитуды приемника RX2
    float PH_RX_1[10];      // Фазы приемника RX1
    float PH_RX_2[10];      // Фазы приемника RX2
};
```

### 1.2 Структура массивов данных

#### Массивы AM_RX_1, AM_RX_2, PH_RX_1, PH_RX_2 (по 10 элементов):

| Индекс | Описание | Частота | Тип передатчика |
|--------|----------|---------|-----------------|
| 0 | Молчащий передатчик | 400 кГц | Silent |
| 1 | Молчащий передатчик | 2000 кГц | Silent |
| 2 | Передатчик T1 | 400 кГц | Active |
| 3 | Передатчик T2 | 400 кГц | Active |
| 4 | Передатчик T3 | 400 кГц | Active |
| 5 | Передатчик T4 | 400 кГц | Active |
| 6 | Передатчик T1 | 2000 кГц | Active |
| 7 | Передатчик T2 | 2000 кГц | Active |
| 8 | Передатчик T3 | 2000 кГц | Active |
| 9 | Передатчик T4 | 2000 кГц | Active |

#### Массивы Ro_smt, PH_smt (по 8 элементов):

| Индекс | Описание | Частота |
|--------|----------|---------|
| 0 | Передатчик T1 | 400 кГц |
| 1 | Передатчик T2 | 400 кГц |
| 2 | Передатчик T3 | 400 кГц |
| 3 | Передатчик T4 | 400 кГц |
| 4 | Передатчик T1 | 2000 кГц |
| 5 | Передатчик T2 | 2000 кГц |
| 6 | Передатчик T3 | 2000 кГц |
| 7 | Передатчик T4 | 2000 кГц |

### 1.3 Типы данных для отображения

```cpp
enum class DataType {
    PHASE_DIFFERENCE,        // Разность фаз RX2-RX1 (4 канала T1-T4)
    AMPLITUDE_RATIO,         // Отношение амплитуд RX2/RX1 (4 канала T1-T4)
    AMPLITUDE_RX1,           // Амплитуды RX1 активных передатчиков (4 канала)
    AMPLITUDE_RX2,           // Амплитуды RX2 активных передатчиков (4 канала)
    PHASE_RX1,              // Фазы RX1 активных передатчиков (4 канала)
    PHASE_RX2,              // Фазы RX2 активных передатчиков (4 канала)
    SILENT_AMPLITUDE_RX1,    // Амплитуды молчащих передатчиков RX1 (1 канал)
    SILENT_AMPLITUDE_RX2,    // Амплитуды молчащих передатчиков RX2 (1 канал)
    TEMPERATURE             // Температура прибора (1 значение на запись)
};
```

### 1.4 Частотные диапазоны

```cpp
enum class FrequencyBand {
    FREQ_400_KHZ,    // 400 кГц
    FREQ_2000_KHZ    // 2000 кГц
};
```

### 1.5 Логика обработки данных

#### Основные вычисления (для активных передатчиков):
- **Разность фаз**: PH_RX_2[i] - PH_RX_1[i] для соответствующих индексов
- **Отношение амплитуд**: AM_RX_2[i] / AM_RX_1[i] для соответствующих индексов
- **Амплитуды RX1**: AM_RX_1[i] для соответствующих индексов
- **Амплитуды RX2**: AM_RX_2[i] для соответствующих индексов
- **Фазы RX1**: PH_RX_1[i] для соответствующих индексов
- **Фазы RX2**: PH_RX_2[i] для соответствующих индексов

#### Молчащие передатчики:
- **400 кГц**: индекс 0 в массивах AM_RX_1, AM_RX_2, PH_RX_1, PH_RX_2
- **2000 кГц**: индекс 1 в массивах AM_RX_1, AM_RX_2, PH_RX_1, PH_RX_2

#### Дополнительные данные:
- **Температура**: поле temperature (одно значение на запись)

## 2. Макет интерфейса

### 2.1 Общая структура окна

```
┌─────────────────────────────────────────────────────────────┐
│ Строка меню                                                 │
├─────────────────────────────────────────────────────────────┤
│ Панель управления первого графика (высота: 40px)           │
├─────────────────────────────────────────────────────────────┤
│ Отступ (высота: 5px)                                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ Первый график                                               │
│ (занимает всё доступное пространство в режиме одного       │
│  графика, или половину в режиме двух графиков)             │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ Панель управления второго графика (высота: 40px)           │

├─────────────────────────────────────────────────────────────┤
│                                                             │

└─────────────────────────────────────────────────────────────┘
```

### 2.2 Панель управления первого графика

**Расположение**: Верхняя часть окна, сразу под строкой меню
**Размеры**: Ширина = ширина окна - 10px (отступы по 5px), Высота = 40px
**Отступы**: 5px от левого и правого края окна

**Элементы управления (слева направо):**

1. **Чекбокс "Dual Mode"**
   - Позиция: 10px от левого края панели
   - Размер: 100px × 20px
   - Функция: Переключение между режимами одного и двух графиков

2. **Выпадающий список "Тип данных"**
   - Позиция: 120px от левого края панели
   - Размер: 180px × 25px
   - Содержимое: Все типы данных из enum DataType

3. **Выпадающий список "Частота"**
   - Позиция: 310px от левого края панели
   - Размер: 100px × 25px
   - Содержимое: "400 кГц", "2000 кГц"

4. **Кнопка "Refresh"**
   - Позиция: 420px от левого края панели
   - Размер: 80px × 25px
   - Функция: Обновление первого графика

### 2.3 Панель управления второго графика

**Расположение**: Между первым и вторым графиками (только в режиме двух графиков)
**Размеры**: Ширина = ширина окна - 10px (отступы по 5px), Высота = 40px
**Отступы**: 5px от левого и правого края окна
**Видимость**: Показывается только когда включен режим "Dual Mode"

**Элементы управления (слева направо):**

1. **Выпадающий список "Тип данных"**
   - Позиция: 10px от левого края панели
   - Размер: 180px × 25px
   - Содержимое: Все типы данных из enum DataType

2. **Выпадающий список "Частота"**
   - Позиция: 200px от левого края панели
   - Размер: 100px × 25px
   - Содержимое: "400 кГц", "2000 кГц"

3. **Кнопка "Refresh"**
   - Позиция: 310px от левого края панели
   - Размер: 80px × 25px
   - Функция: Обновление второго графика

### 2.4 Область графиков

#### Режим одного графика:
- **Первый график**: Занимает всё пространство под панелью управления первого графика
- **Второй график**: Скрыт
- **Панель управления второго графика**: Скрыта

#### Режим двух графиков:
- **Первый график**: Занимает верхнюю половину доступного пространства
- **Панель управления второго графика**: Располагается между графиками
- **Второй график**: Занимает нижнюю половину доступного пространства

### 2.5 Отступы и размеры

**Основные отступы:**
- От краёв окна до панелей управления: 5px
- Между панелью управления и графиком: 5px
- Между элементами на панели управления: 10px

**Высоты элементов:**
- Панель управления: 40px
- Элементы управления: 25px (кроме чекбокса - 20px)

**Минимальные размеры окна:**
- Ширина: 600px
- Высота: 400px

## 3. Поведение интерфейса

### 3.1 Переключение режимов отображения

**Режим одного графика (по умолчанию):**
- Чекбокс "Dual Mode" не отмечен
- Показывается только панель управления первого графика
- Первый график занимает всё доступное пространство
- Панель управления второго графика скрыта
- Второй график скрыт

**Режим двух графиков:**
- Чекбокс "Dual Mode" отмечен
- Показываются обе панели управления
- Доступное пространство делится поровну между двумя графиками
- Панель управления второго графика располагается между графиками

### 3.2 Отображение данных

**Типы данных с множественными рядами (T1-T4):**
- PHASE_DIFFERENCE
- AMPLITUDE_RATIO  
- AMPLITUDE_RX1
- AMPLITUDE_RX2
- PHASE_RX1
- PHASE_RX2

Для этих типов отображается 4 ряда данных (T1, T2, T3, T4) разными цветами с легендой.

**Типы данных с одним рядом:**
- SILENT_AMPLITUDE_RX1
- SILENT_AMPLITUDE_RX2
- TEMPERATURE

Для этих типов отображается один ряд данных.

### 3.3 Интерактивность

**Масштабирование:**
- Левая кнопка мыши: Выделение области для масштабирования
- Правая кнопка мыши: Сброс масштабирования

**Обновление данных:**
- Кнопки "Refresh" обновляют соответствующие графики
- При изменении типа данных или частоты требуется нажатие "Refresh"

## 4. Меню приложения

**Меню "Файл":**

**Меню "Справка":**
- "О программе..." - информация о приложении

## 5. Технические требования

### 5.1 Формат входных данных
- Бинарные файлы (.bin) содержащие массив структур GP_TOOL_DATA
- Каждая структура представляет одну запись измерений

### 5.2 Производительность
- Плавная отрисовка графиков при изменении размеров окна
- Быстрое переключение между режимами отображения
- Эффективное масштабирование больших объёмов данных

### 5.3 Совместимость
- Windows 10/11
- Поддержка высокого DPI
- Современный внешний вид элементов управления
