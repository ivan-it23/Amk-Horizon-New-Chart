# Техническое задание: Улучшение визуализации и интерактивности графиков

## 1. Обзор

Данный документ описывает план работ по улучшению пользовательского опыта при работе с графиками в приложении AMK-Horizon-Chart. Текущая реализация требует доработок в части визуального представления данных и интерактивности после масштабирования.

**Основные цели:**
1.  Улучшить читаемость графиков за счет увеличения толщины линий.
2.  Обеспечить корректное отображение меток на оси X в виде чисел с плавающей запятой для повышения точности при масштабировании.
3.  Добавить функцию панорамирования (скроллинга) для удобной навигации по увеличенному участку графика.

Все изменения будут выполнены с учетом существующей модульной архитектуры и совместимости со средой Visual Studio 2017.

## 2. Детальные задачи

### 2.1. Увеличение толщины линий графика

*   **Проблема:** Линии данных на графиках слишком тонкие (1 пиксель), что затрудняет их визуальный анализ, особенно при наличии четырех кривых.
*   **Решение:** Внести изменения в модуль `ChartModule`, отвечающий за отрисовку. При создании пера (`HPEN`) для отрисовки кривых данных будет установлена толщина в **2 пикселя**. Эта толщина является оптимальным компромиссом между хорошей видимостью и предотвращением слияния близко расположенных кривых.

### 2.2. Форматирование меток оси X как Float

*   **Проблема:** Метки на оси X в настоящее время отображаются как целые числа (`int`). При увеличении (zoom) участка графика, где деления сетки не совпадают с целыми значениями, это приводит к некорректной и неточной разметке. Ось Y уже использует числа с плавающей запятой (`float`), и ось X должна следовать тому же принципу.
*   **Решение:**
    1.  Проанализировать метод `DrawGridAndAxes` в `ChartModule.cpp`, чтобы понять текущую логику отрисовки меток для оси Y.
    2.  Применить аналогичный подход для оси X. Алгоритм расчета шага сетки и позиций меток будет оперировать значениями типа `double` или `float`.
    3.  Для преобразования числовых значений в строку будет использоваться функция `swprintf_s` с форматом, включающим один или два знака после запятой (например, `L"%.1f"`), чтобы обеспечить консистентность с осью Y.

### 2.3. Реализация панорамирования (скроллинга) осей

*   **Проблема:** После выполнения масштабирования (zoom) пользователь не может перемещаться по увеличенному участку. Отсутствует возможность сдвигать видимую область, что ограничивает анализ данных.
*   **Решение:** Будет реализована функция панорамирования (panning) с помощью перетаскивания правой кнопкой мыши.

    *   **Концепция взаимодействия:**
        *   **Перетаскивание правой кнопкой мыши (`WM_RBUTTONDOWN` + `WM_MOUSEMOVE`):** Сдвигает видимую область графика.
        *   **Одиночный клик правой кнопкой мыши (`WM_RBUTTONUP` без перемещения):** Сбрасывает масштаб к исходному (существующее поведение).

    *   **Техническая реализация:**
        1.  **`DataModule`:** Будет добавлен новый метод `PanVisibleRange(double deltaX, double deltaY)`, который будет сдвигать текущий видимый диапазон (`minVisibleX`, `maxVisibleX` и т.д.) на указанные дельты.
        2.  **`Amk-Horizon-New-Chart.cpp` (WndProc):**
            *   В обработчике `WM_RBUTTONDOWN` будет запоминаться начальная позиция курсора и устанавливаться флаг режима панорамирования.
            *   В `WM_MOUSEMOVE`, если флаг панорамирования активен, будет вычисляться смещение курсора относительно начальной точки. Это смещение (в пикселях) будет преобразовываться в смещение в координатах данных. Затем будет вызываться метод `DataModule::PanVisibleRange()`, после чего окно будет перерисовываться (`InvalidateRect`).
            *   В `WM_RBUTTONUP` будет сбрасываться флаг панорамирования. Также будет добавлена проверка: если смещение мыши было незначительным (т.е. это был клик, а не перетаскивание), будет вызвана функция сброса масштаба `DataModule::ResetVisibleRange()`.

## 3. План реализации

1.  **Этап 1: Увеличение толщины линий.**
    *   Модифицировать `ChartModule::DrawChartData`, изменив параметры создания `HPEN`.
2.  **Этап 2: Форматирование меток оси X.**
    *   Адаптировать логику в `ChartModule::DrawGridAndAxes` для корректного расчета и отображения float-меток на оси X.
3.  **Этап 3: Реализация панорамирования.**
    *   Добавить метод `PanVisibleRange` в `DataModule`.
    *   Обновить `WndProc` в главном файле для обработки событий мыши (`WM_RBUTTONDOWN`, `WM_MOUSEMOVE`, `WM_RBUTTONUP`) для реализации логики панорамирования.
4.  **Этап 4: Тестирование.**
    *   Проверить корректность отображения линий и меток.
    *   Протестировать функцию панорамирования в разных масштабах и на обоих графиках в режиме "Dual Mode".
    *   Убедиться, что сброс масштаба по правому клику по-прежнему работает корректно.

## 4. Ожидаемый результат

После завершения работ приложение будет предоставлять следующие улучшения:
*   Кривые на графиках станут более четкими и легко различимыми.
*   Разметка оси X будет точной и информативной даже при сильном увеличении.
*   Пользователи смогут легко перемещаться по увеличенным участкам графика, что значительно улучшит удобство анализа данных.
