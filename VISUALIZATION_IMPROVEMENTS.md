# Техническое задание: Улучшение визуализации графиков

## 1. Общее описание
Цель — модернизировать модуль отрисовки графиков (`ChartModule`) для повышения интерактивности и информативности. Будут реализованы три ключевые функции:
1.  **Отрисовка сетки**: На фон графика будет добавлена фоновая сетка для удобства визуального сопоставления данных.
2.  **Отрисовка числовых меток на осях**: По осям X (время/кадры) и Y (значения) будут добавлены числовые метки, отображающие текущий масштаб.
3.  **Функция масштабирования (Zoom)**: Пользователь сможет с помощью левой кнопки мыши выделить прямоугольную область на графике, которая будет увеличена для детального просмотра. Правый клик будет сбрасывать масштаб к исходному.

## 2. Изменения по модулям

### 2.1. `DataModule` (Модуль данных)
Хотя этот модуль не отвечает за отрисовку, его необходимо доработать для поддержки масштабирования.

-   **Хранение видимого диапазона**:
    -   Добавить внутренние переменные для хранения текущего видимого диапазона данных по осям X и Y (например, `minVisibleX`, `maxVisibleX`, `minVisibleY`, `maxVisibleY`).
    -   По умолчанию эти значения будут соответствовать полному диапазону загруженных данных.
-   **Новые методы**:
    -   `SetVisibleRange(double minX, double maxX, double minY, double maxY)`: Метод для установки нового видимого диапазона (после зума).
    -   `ResetVisibleRange()`: Метод для сброса диапазона к исходному (весь набор данных).
-   **Модификация существующих методов**:
    -   `CalculateChartData()` и другие методы, предоставляющие данные для отрисовки, должны будут учитывать текущий видимый диапазон и возвращать только те точки, которые в него попадают.

### 2.2. `ChartModule` (Модуль отрисовки)
Этот модуль понесет основные изменения.

-   **Новый приватный метод `DrawGridAndAxes(HDC hdc, RECT chartRect, ...)`**:
    -   **Расчет шага сетки**: Реализовать алгоритм для автоматического подбора "красивых" шагов для линий сетки и числовых меток на осях (например, 10, 20, 50, 100...). Шаг должен динамически изменяться в зависимости от текущего масштаба.
    -   **Отрисовка сетки**: Внутри `DrawChart()` перед отрисовкой данных будет вызываться этот метод, который нарисует на фоне графика светлые горизонтальные и вертикальные линии.
    -   **Отрисовка меток осей**: На основе рассчитанного шага и диапазона данных метод будет отрисовывать текстовые метки со значениями вдоль осей X и Y. Потребуется преобразование координат из мира данных в экранные координаты.
-   **Новый публичный метод `DrawZoomRectangle(HDC hdc, RECT zoomRect)`**:
    -   Этот метод будет рисовать полупрозрачный прямоугольник выделения поверх графика в процессе, когда пользователь зажимает левую кнопку мыши и тянет курсор.
-   **Модификация `DrawChartData()`**:
    -   Метод должен будет корректно отображать данные в любом заданном масштабе, преобразуя координаты точек из видимого диапазона данных в экранные координаты `chartRect`.

### 2.3. `Amk-Horizon-New-Chart.cpp` (Главное окно и обработка событий)
Здесь будет реализована логика взаимодействия пользователя с графиком.

-   **Обработка сообщений мыши**:
    -   `WM_LBUTTONDOWN`: Запомнить начальные координаты (пиксели) выделения и переключить приложение в режим "выделения области".
    -   `WM_MOUSEMOVE`: Если приложение в режиме "выделения", обновлять текущие координаты и перерисовывать прямоугольник выделения с помощью `ChartModule::DrawZoomRectangle()`.
    -   `WM_LBUTTONUP`: Завершить режим "выделения". Преобразовать конечные пиксельные координаты в координаты данных. Вызвать `DataModule::SetVisibleRange()` с новым диапазоном. После этого инициировать полную перерисовку графика (`InvalidateRect`).
    -   `WM_RBUTTONDOWN`: Вызвать `DataModule::ResetVisibleRange()` и инициировать полную перерисовку графика для сброса масштаба.
-   **Координация**: Главное окно будет координировать взаимодействие: получать события мыши, через `ChartManager` сообщать `DataModule` об изменении масштаба и запрашивать у `ChartModule` перерисовку.

## 3. План реализации

1.  **Этап 1: Модификация `DataModule`**
    -   Добавить переменные для хранения видимого диапазона.
    -   Реализовать публичные методы `SetVisibleRange()` и `ResetVisibleRange()`.
    -   Обновить логику `CalculateChartData` для работы с диапазоном.

2.  **Этап 2: Модификация `ChartModule`**
    -   Создать метод `DrawGridAndAxes` для отрисовки сетки и числовых меток.
    -   Интегрировать его в основной метод `DrawChart`.
    -   Обновить `DrawChartData` для корректной работы с масштабированием.

3.  **Этап 3: Реализация логики в главном окне**
    -   Добавить обработчики сообщений мыши (`WM_LBUTTONDOWN/UP`, `WM_MOUSEMOVE`, `WM_RBUTTONDOWN`) в `WndProc`.
    -   Реализовать логику преобразования экранных координат в координаты данных.
    -   Обеспечить вызов соответствующих методов `DataModule` и `ChartModule`.

4.  **Этап 4: Тестирование**
    -   Проверка корректности отображения сетки и осей при запуске.
    -   Тестирование функции масштабирования на разных участках графика.
    -   Тестирование сброса масштаба по правому клику.
    -   Проверка работы в режиме одного и двух графиков.
