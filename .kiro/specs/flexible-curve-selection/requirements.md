# Требования к системе гибкого выбора кривых

## Введение

Данная спецификация описывает реализацию гибкой системы выбора кривых для приложения AMK-Horizon-Chart с интерактивной схемой прибора, поддержкой двойных осей ординат и расширенными возможностями визуализации данных.

## Требования

### Требование 1: Интерактивная схема прибора

**Пользовательская история:** Как пользователь, я хочу видеть схему прибора и интерактивно выбирать элементы для построения графиков, чтобы иметь полный контроль над отображаемыми данными.

#### Критерии приемки

1. КОГДА пользователь нажимает кнопку "Схема прибора" ТО система ДОЛЖНА открыть модальное окно со схемой прибора
2. КОГДА пользователь кликает по элементу схемы (передатчик/приемник) ТО система ДОЛЖНА переключить состояние выбора этого элемента
3. КОГДА элемент выбран ТО система ДОЛЖНА визуально выделить его подсветкой
4. КОГДА отображается схема ТО передатчики T1-T4 ДОЛЖНЫ быть окрашены в красный цвет (не яркий)
5. КОГДА отображается схема ТО приемники R1-R2 ДОЛЖНЫ быть окрашены в зеленый цвет (не яркий)
6. КОГДА отображается схема ТО молчащие передатчики ДОЛЖНЫ быть окрашены в серый цвет

### Требование 2: Динамическое определение доступных кривых

**Пользовательская история:** Как пользователь, я хочу чтобы система автоматически определяла доступные типы данных на основе моего выбора элементов, чтобы не делать ошибочных комбинаций.

#### Критерии приемки

1. КОГДА выбраны два приемника (R1 и R2) ТО система ДОЛЖНА предложить "Отношение амплитуд" и "Разность фаз" с 4 кривыми T1-T4
2. КОГДА выбран один приемник ТО система ДОЛЖНА предложить "Амплитуда" и "Фаза" с 4 кривыми T1-T4
3. КОГДА выбран один передатчик ТО система ДОЛЖНА предложить "Амплитуда" и "Фаза" для R1 или R2 с 1 кривой
4. КОГДА выбран молчащий передатчик ТО система ДОЛЖНА предложить только "Амплитуда" для R1 или R2 с 1 кривой
5. КОГДА выбор некорректен ТО система ДОЛЖНА показать информационное сообщение об ошибке

### Требование 3: Поддержка двойных осей ординат

**Пользовательская история:** Как пользователь, я хочу отображать разнородные данные (амплитуды и фазы) на одном графике с разными осями, чтобы анализировать корреляции между различными параметрами.

#### Критерии приемки

1. КОГДА пользователь выбирает кривые с разными единицами измерения ТО система ДОЛЖНА предложить выбор оси (левая/правая)
2. КОГДА кривая назначена на левую ось ТО она ДОЛЖНА отображаться сплошной линией
3. КОГДА кривая назначена на правую ось ТО она ДОЛЖНА отображаться пунктирной линией
4. КОГДА используется левая ось ТО подпись ДОЛЖНА показывать единицы измерения амплитуд (Вольты)
5. КОГДА используется правая ось ТО подпись ДОЛЖНА показывать единицы измерения фаз (Градусы)
6. КОГДА график содержит две оси ТО каждая ось ДОЛЖНА масштабироваться независимо

### Требование 4: Быстрые пресеты и копирование настроек

**Пользовательская история:** Как пользователь, я хочу быстро применять часто используемые комбинации кривых и копировать настройки между графиками, чтобы ускорить работу с данными.

#### Критерии приемки

1. КОГДА пользователь нажимает "Все амплитуды R1" ТО система ДОЛЖНА автоматически выбрать все амплитуды для приемника R1
2. КОГДА пользователь нажимает "Все фазы R2" ТО система ДОЛЖНА автоматически выбрать все фазы для приемника R2
3. КОГДА пользователь нажимает "Отношения амплитуд" ТО система ДОЛЖНА автоматически настроить отображение отношений амплитуд
4. КОГДА пользователь нажимает "Разности фаз" ТО система ДОЛЖНА автоматически настроить отображение разностей фаз
5. КОГДА пользователь нажимает "Копировать настройки" ТО система ДОЛЖНА скопировать конфигурацию кривых с одного графика на другой

### Требование 5: Независимые настройки графиков

**Пользовательская история:** Как пользователь, я хочу настраивать каждый график независимо в режиме двух графиков, чтобы сравнивать разные наборы данных одновременно.

#### Критерии приемки

1. КОГДА включен режим двух графиков ТО каждый график ДОЛЖЕН иметь свою кнопку "Схема прибора"
2. КОГДА пользователь настраивает первый график ТО настройки второго графика НЕ ДОЛЖНЫ изменяться
3. КОГДА пользователь настраивает второй график ТО настройки первого графика НЕ ДОЛЖНЫ изменяться
4. КОГДА пользователь применяет настройки ТО изменения ДОЛЖНЫ затрагивать только соответствующий график

### Требование 6: Выбор частоты и валидация

**Пользовательская история:** Как пользователь, я хочу выбирать частотный диапазон для отображаемых данных и получать уведомления об ошибках, чтобы корректно настраивать параметры визуализации.

#### Критерии приемки

1. КОГДА пользователь настраивает кривые ТО система ДОЛЖНА предоставить выбор частоты: 400 кГц или 2000 кГц
2. КОГДА выбор элементов некорректен ТО система ДОЛЖНА показать сообщение с описанием ошибки
3. КОГДА пользователь пытается применить некорректные настройки ТО система ДОЛЖНА предотвратить применение и показать предупреждение
4. КОГДА все настройки корректны ТО кнопка "Применить" ДОЛЖНА быть активна

### Требование 7: Совместимость с существующим функционалом

**Пользовательская история:** Как пользователь, я хочу чтобы новая система работала совместно с существующими возможностями приложения, чтобы не потерять привычный функционал.

#### Критерии приемки

1. КОГДА используется новая система выбора кривых ТО существующие комбобоксы ДОЛЖНЫ оставаться функциональными
2. КОГДА применяются настройки через схему прибора ТО масштабирование графиков ДОЛЖНО работать корректно
3. КОГДА используется режим двух графиков ТО новая система ДОЛЖНА работать для каждого графика независимо
4. КОГДА загружаются новые данные ТО настройки кривых ДОЛЖНЫ сохраняться до следующего изменения пользователем
