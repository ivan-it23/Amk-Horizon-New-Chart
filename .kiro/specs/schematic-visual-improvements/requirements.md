# Requirements Document - Schematic Visual Improvements

## Introduction

Улучшение визуального представления схемы прибора (Device Schematic) для повышения удобства использования и профессионального внешнего вида. Текущая схема содержит избыточные подписи и имеет базовый визуальный дизайн, который можно значительно улучшить.

## Requirements

### Requirement 1: Удаление избыточных подписей

**User Story:** Как пользователь ИАТК, я хочу видеть только основные обозначения элементов (T1-T4, R1-R2, Silent R1-R2) без дополнительных подписей в скобках, чтобы схема была более компактной и не отвлекала внимание.

#### Acceptance Criteria

1. WHEN схема прибора отображается THEN подписи "(Transmitter)", "(Receiver)", "(Silent Tx)" НЕ отображаются
2. WHEN схема прибора отображается THEN отображаются только основные обозначения: T1, T2, T3, T4, R1, R2, Silent R1, Silent R2
3. WHEN пользователь наводит курсор на элемент THEN может отображаться всплывающая подсказка с полным названием (опционально)

### Requirement 2: Современный корпоративный дизайн элементов

**User Story:** Как пользователь, я хочу видеть схему с современным, аккуратным и корпоративным дизайном, чтобы работа с приложением была профессиональной и приятной.

#### Acceptance Criteria

1. WHEN элементы схемы отрисовываются THEN они имеют скруглённые углы (радиус 6-8 пикселей)
2. WHEN элементы схемы отрисовываются THEN они имеют тонкие тени для создания лёгкого эффекта объёма
3. WHEN элементы схемы отрисовываются THEN используются градиентные заливки для современного вида
4. WHEN элемент выбран (активное состояние) THEN он имеет яркую рамку и более насыщенный цвет
5. WHEN курсор наведён на элемент THEN элемент слегка подсвечивается с плавным переходом (hover эффект)
6. WHEN элемент не выбран (неактивное состояние) THEN он имеет приглушённый цвет с меньшей насыщенностью
7. WHEN элементы отрисовываются THEN используется корпоративная цветовая палитра (нейтральные, профессиональные цвета)

### Requirement 3: Рамка для основных элементов схемы

**User Story:** Как пользователь, я хочу видеть основные элементы схемы (передатчики и приемники) в отдельной рамке с нейтральным фоном, чтобы лучше ориентироваться в структуре прибора.

#### Acceptance Criteria

1. WHEN схема отрисовывается THEN передатчики (T1-T4) и приемники (R1-R2) находятся внутри общей рамки
2. WHEN рамка отрисовывается THEN она имеет нейтральный системный цвет фона (светло-серый)
3. WHEN рамка отрисовывается THEN она имеет тонкую границу (1-2px) тёмно-серого цвета
4. WHEN рамка отрисовывается THEN она имеет небольшие отступы (padding) от элементов внутри
5. WHEN молчащие передатчики отрисовываются THEN они находятся ВНЕ рамки и остаются неизменными

### Requirement 4: Улучшенная цветовая схема

**User Story:** Как пользователь, я хочу видеть более контрастные и профессиональные цвета элементов, чтобы схема была легко читаемой и приятной для глаз.

#### Acceptance Criteria

1. WHEN передатчики отрисовываются THEN используется градиент от светло-красного к тёмно-красному
2. WHEN приемники отрисовываются THEN используется градиент от светло-зелёного к тёмно-зелёному
3. WHEN молчащие передатчики отрисовываются THEN используется градиент от светло-серого к тёмно-серому
4. WHEN элемент выбран THEN его цвет становится более насыщенным
5. WHEN элемент не выбран THEN его цвет слегка приглушён (80% непрозрачности)

### Requirement 5: Горизонтальная компоновка элементов

**User Story:** Как пользователь, я хочу видеть все элементы схемы расположенными горизонтально в логическом порядке, чтобы быстро находить нужные компоненты.

#### Acceptance Criteria

1. WHEN схема отрисовывается THEN все элементы расположены горизонтально в одну линию
2. WHEN схема отрисовывается THEN порядок элементов: T1, T2, T3, T4, R1, R2 (в рамке), затем Silent R1, Silent R2 (вне рамки)
3. WHEN схема отрисовывается THEN между основными элементами (в рамке) и молчащими есть визуальный отступ
4. WHEN схема отрисовывается THEN элементы имеют одинаковые размеры и выравнивание
5. WHEN схема отрисовывается THEN расстояния между элементами одинаковые и пропорциональные

### Requirement 6: Адаптивность и масштабирование

**User Story:** Как пользователь, я хочу, чтобы схема корректно отображалась при разных размерах окна, чтобы работать с приложением на разных мониторах.

#### Acceptance Criteria

1. WHEN размер окна изменяется THEN элементы схемы масштабируются пропорционально
2. WHEN размер окна изменяется THEN текст остаётся читаемым (минимальный размер шрифта 10pt)
3. WHEN размер окна изменяется THEN расстояния между элементами сохраняют пропорции
4. WHEN окно слишком маленькое THEN появляется прокрутка вместо искажения элементов

### Requirement 7: Производительность отрисовки

**User Story:** Как пользователь, я хочу, чтобы схема отрисовывалась мгновенно, чтобы не было задержек при открытии диалога.

#### Acceptance Criteria

1. WHEN диалог схемы открывается THEN схема отрисовывается менее чем за 100 мс
2. WHEN элемент выбирается THEN визуальная обратная связь происходит мгновенно (< 16 мс)
3. WHEN курсор наводится на элемент THEN hover эффект применяется без задержек
4. WHEN схема перерисовывается THEN не происходит мерцания или артефактов

## Non-Functional Requirements

### Совместимость
- Схема должна корректно отображаться на Windows 10/11
- Поддержка различных DPI настроек (100%, 125%, 150%, 200%)
- Корректная работа с различными темами Windows

### Доступность
- Цвета должны иметь достаточный контраст для людей с нарушениями зрения
- Размер элементов должен быть достаточным для точного клика (минимум 40x40 пикселей)
- Текст должен быть читаемым при любом масштабе

### Поддерживаемость
- Код отрисовки должен быть хорошо структурирован и документирован
- Цвета и размеры должны быть вынесены в константы для лёгкой настройки
- Использование GDI+ для современной графики вместо старого GDI
