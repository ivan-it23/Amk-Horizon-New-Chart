# AMK Horizon New Chart — Project Status

## Текущее состояние (5Tx refactor)
- Приложение переведено на новый формат данных 5Tx (структура `GP_TOOL_DATA`, 240 байт).
- Обновлены парсер файлов, вычисления и типы данных (PHASE_SMT/RHO_SMT, DELTA_PH и т.д.).
- COM-протокол переведён на формат: `[CMD:1][LEN:2][PAYLOAD][CRC16:2]`.
- UI модули адаптированы к 5 передатчикам (T1–T5): ChartModule, CurveSelectionModule, SchematicModule, UIModule.
- Добавлен отдельный скетч эмулятора 5Tx: `arduino_5Tx_tools_emul_only.ino`.

## Последние правки
- Сделано более устойчивое чтение заголовка пакета COM (добавлено чтение заголовка с накоплением байтов) — это должно устранить потерю/таймауты и проблему отсутствия записи данных.

## Известные проблемы
- На реальной плате при опросе COM данные могут не фиксироваться в файле (до правки чтения заголовка). Нужно перепроверить после пересборки.

## Дальнейшие планы
1. Пересобрать приложение и проверить COM-обмен с платой/эмулятором:
   - рост счётчиков пакетов и кадров;
   - создание .bin файла в папке записи;
   - корректная отрисовка 5 каналов.
2. При необходимости добавить диагностику (логирование ошибок CRC/таймаутов).
3. Финальная проверка загрузки файлов `.bin/.biv/.DEV` в 5Tx формате.

## Как продолжить в новой сессии
1. Собрать решение `Amk-Horizon-New-Chart.sln` (Release или Debug).
2. Залить скетч `arduino_5Tx_tools_emul_only.ino` на плату.
3. Запустить приложение → «Прибор» → «Подключение» → выбрать COM → «Подключить».
4. Убедиться, что статус «Опрос...», счётчики кадров растут, и файл записи появляется в папке `Desktop/AMK_Data` (или выбранной).
