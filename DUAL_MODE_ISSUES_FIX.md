# Техническое задание: Исправление проблем интерфейса в режиме двух графиков

## Анализ проблем

### Проблема №1: Нарушение Z-порядка выпадающих списков

**Описание**: В режиме двух графиков при нажатии на выпадающие списки панели управления второго графика (выбор типа данных и частоты) выпадающие элементы отображаются **за** вторым графиком вместо того, чтобы отображаться **поверх** него. Это делает выпадающие опции невидимыми и неиспользуемыми.

**Анализ первопричин**:
- Выпадающие списки создаются с флагом `SWP_NOZORDER` в вызовах `SetWindowPos()`
- Отсутствует явное управление Z-порядком элементов управления относительно областей отрисовки графиков
- Отрисовка графиков происходит в `WM_PAINT`, что может влиять на рендеринг элементов управления

**Местоположение в коде**: 
- [ChartManager::UpdateLayout()](file://c:\Users\ivanb\source\repos\Amk-Horizon-New-Chart\Amk-Horizon-New-Chart\Amk-Horizon-New-Chart.cpp#L337-L383) строки 357-359 в [Amk-Horizon-New-Chart.cpp](file://c:\Users\ivanb\source\repos\Amk-Horizon-New-Chart\Amk-Horizon-New-Chart\Amk-Horizon-New-Chart.cpp)
- `SetWindowPos(hChart2DataCombo, NULL, 10, panel2Y, 180, 25, SWP_NOZORDER);`

### Проблема №2: Неравные размеры графиков в режиме двух графиков

**Описание**: В режиме двух графиков первый график выглядит меньше второго графика, создавая визуальную несогласованность. Графики должны иметь одинаковые высоты.

**Анализ первопричин**:
- **Расчет графика 1**: `chart1Rect.bottom = (height - 100) / 2;` (строка 352)
- **Расчет графика 2**: `chart2Rect.bottom = height - 5;` (строка 363)
- **Ошибка в расчете доступного пространства**: 
  - График 1 получает: `(height - 100) / 2 - 60` = эффективная высота
  - График 2 получает: `height - 5 - (panel2Y + 35)` = другая эффективная высота
- **Фиксированные расчеты на основе пикселей** вместо адаптивной компоновки на основе процентов

**Математический анализ**:
```
Высота окна = H
Высота графика1 = (H - 100) / 2 - 60 = (H - 220) / 2
Высота графика2 = H - 5 - ((H - 100) / 2 + 5 + 35) = H - 5 - (H - 100) / 2 - 40 
                 = H - (H - 100) / 2 - 45 = (H + 100) / 2 - 45 = (H + 10) / 2
```

## Технические требования

### Требование 1: Исправление проблемы Z-порядка выпадающих списков

**Цель**: Обеспечить отображение выпадающих списков панели управления второго графика поверх всех остальных элементов.

**Технический подход**:
1. **Удалить флаг SWP_NOZORDER** из вызовов `SetWindowPos()`
2. **Добавить параметр HWND_TOP** для перемещения элементов управления на передний план
3. **Реализовать правильное многослойное расположение элементов управления** в иерархии окон
4. **Рассмотреть расширенный стиль WS_EX_TOPMOST** при необходимости

**Критерии успеха**:
- Нажатие на выпадающие списки второго графика показывает выпадающие списки поверх графика
- Выпадающие списки остаются полностью видимыми и функциональными
- Отсутствие регрессии в поведении панели управления первого графика

### Требование 2: Реализация равного размера графиков

**Цель**: Создать абсолютно одинаковые по размеру графики в режиме двух графиков, используя расчеты на основе процентов.

**Технический подход**:
1. **Заменить фиксированные пиксельные расчеты** на компоновку на основе процентов
2. **Определить константы компоновки** для отступов, высот панелей и промежутков
3. **Реализовать симметричное распределение пространства**:
   - Доступное пространство = Общая высота - Фиксированные элементы (меню, панели, отступы)
   - Каждый график = Доступное пространство / 2
4. **Добавить адаптивный пересчет** при изменении размера окна

**Формула компоновки**:
```cpp
// Константы
const int MENU_HEIGHT = 30;
const int PANEL_HEIGHT = 40;
const int MARGIN = 5;
const int PANEL_SPACING = 5;

// Расчет доступного пространства
int totalAvailable = height - MENU_HEIGHT - (2 * PANEL_HEIGHT) - (4 * MARGIN) - PANEL_SPACING;
int chartHeight = totalAvailable / 2;

// Позиционирование графиков
chart1Rect.top = MENU_HEIGHT + PANEL_HEIGHT + MARGIN;
chart1Rect.bottom = chart1Rect.top + chartHeight;

chart2Rect.top = chart1Rect.bottom + PANEL_HEIGHT + (2 * MARGIN);
chart2Rect.bottom = chart2Rect.top + chartHeight;
```

**Критерии успеха**:
- Оба графика имеют одинаковые высоты в режиме двух графиков
- Компоновка пропорционально масштабируется при изменении размера окна
- Поддерживается правильное расстояние между элементами
- Отсутствует перекрытие между элементами интерфейса и графиками
